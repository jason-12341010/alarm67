## 可迭代物件與迭代器

`for` 迴圈可以走過串列、字串、字典、檔案… 它們都是**可迭代物件（iterable）**。`for` 背後其實做了這些事：

```python
nums = [10, 20, 30]
it = iter(nums)          # 1. 取得迭代器（iterator）
print(next(it))          # 2. 一直呼叫 next() 拿下一個值
print(next(it))
print(next(it))
try:
    next(it)             # 3. 沒有了就丟出 StopIteration，for 迴圈就停止
except StopIteration:
    print("結束")
```

> 💡 **可迭代物件**：可以用 `iter()` 取得迭代器的東西（有 `__iter__`）。**迭代器**：可以用 `next()` 一個一個拿值的東西（有 `__next__`），而且**只能走一次**。

```python
it = iter("abc")
print(list(it))          # 走完了
print(list(it))          # 再走一次是空的！
```

## 自己寫迭代器

```python
class Countdown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

for n in Countdown(5):
    print(n, end=" ")
```

要寫兩個魔術方法很麻煩。有更簡單的方法：**產生器**。

## 產生器函式：yield

函式裡只要有 `yield`，它就變成**產生器函式**。每次 `yield` 會**交出一個值並暫停**，下次從暫停的地方繼續：

```python
def countdown(start):
    print("開始倒數")
    while start > 0:
        yield start              # 交出值，暫停在這裡
        start -= 1
    print("倒數結束")

gen = countdown(3)
print(gen)                       # 呼叫時不會執行，只是建立產生器
print(next(gen))
print(next(gen))
print(next(gen))
print(list(gen))                 # 繼續執行到結束
```

## 為什麼要用產生器？省記憶體！

產生器是**惰性（lazy）** 的：需要時才計算，不會一次把所有結果放進記憶體：

```python
import sys

big_list = [x * x for x in range(1_000_000)]
big_gen = (x * x for x in range(1_000_000))        # 產生器運算式
print("串列：", sys.getsizeof(big_list), "bytes")
print("產生器：", sys.getsizeof(big_gen), "bytes")
print(sum(big_gen))
```

處理**大檔案、資料串流、無限序列**時，產生器是必備工具。

## 無限序列

```python
def fibonacci():
    a, b = 0, 1
    while True:                  # 無限迴圈也沒關係，因為一次只算一個
        yield a
        a, b = b, a + b

from itertools import islice
print(list(islice(fibonacci(), 15)))   # 只取前 15 個

for f in fibonacci():
    if f > 1000:
        break
    last = f
print("小於 1000 的最大費氏數：", last)
```

## 產生器管線（pipeline）

把多個產生器串起來，像工廠的生產線一樣處理資料。每一步都是惰性的：

```python
log = """INFO 啟動系統
ERROR 資料庫連線失敗
INFO 使用者登入
ERROR 磁碟空間不足
WARNING 記憶體使用率 85%
ERROR 逾時"""

def read_lines(text):
    for line in text.splitlines():
        yield line

def only(level, lines):
    for line in lines:
        if line.startswith(level):
            yield line

def strip_level(lines):
    for line in lines:
        yield line.split(" ", 1)[1]

pipeline = strip_level(only("ERROR", read_lines(log)))
for i, msg in enumerate(pipeline, 1):
    print(i, msg)
```

## yield from

把另一個可迭代物件的值**全部轉交**出去：

```python
def flatten(items):
    for x in items:
        if isinstance(x, list):
            yield from flatten(x)      # 遞迴處理巢狀串列
        else:
            yield x

print(list(flatten([1, [2, [3, 4], 5], [[6]], 7])))
```

例如 `list(batched(range(7), 3))` → `[[0, 1, 2], [3, 4, 5], [6]]`

def endless():
    n = 0
    while True:
        yield n
        n += 1
it = f(endless(), 4)

@@hint
用一個 `batch = []`，每加入一個就檢查 `len(batch) == size`，滿了就 `yield batch` 並重設成新的空串列。迴圈結束後，如果 batch 還有東西也要 yield。
@@solution
def batched(items, size):
    batch = []
    for x in items:
        batch.append(x)
        if len(batch) == size:
            yield batch
            batch = []
    if batch:
        yield batch


for batch in batched(range(7), 3):
    print(batch)
