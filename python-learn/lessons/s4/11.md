這一課是 Python 物件系統最深層的部分。平常寫程式很少直接用到，但**框架大量使用**它們：Django 的 Model、SQLAlchemy、Pydantic、dataclass 的背後都是這些機制。看懂之後，你就能理解這些「魔法」是怎麼做到的。

## 屬性查找：一切都是字典

```python
class Dog:
    species = "犬"
    def __init__(self, name):
        self.name = name

d = Dog("小白")
print(d.__dict__)                  # 物件自己的屬性
print({k: v for k, v in Dog.__dict__.items() if not k.startswith("__")})   # 類別的屬性
print(d.species)                   # 物件找不到，就往類別找
```

## getattr 系列：動態存取屬性

```python
class Config:
    debug = False
    lang = "zh-TW"

c = Config()
key = "lang"
print(getattr(c, key))                     # 用字串取得屬性
setattr(c, "theme", "dark")                # 用字串設定屬性
print(hasattr(c, "theme"), c.theme)
for name in ["debug", "lang", "theme", "font"]:
    print(name, "=", getattr(c, name, "（沒有設定）"))
```

### `__getattr__`：找不到屬性時的備案

```python
class AttrDict(dict):
    """可以用 d.key 存取的字典"""
    def __getattr__(self, name):           # 只有正常找不到時才會呼叫
        try:
            return self[name]
        except KeyError:
            raise AttributeError(name) from None

    def __setattr__(self, name, value):
        self[name] = value

cfg = AttrDict(host="localhost", port=8000)
print(cfg.host, cfg.port)
cfg.debug = True
print(cfg)
```

## 描述器（Descriptor）

描述器是一個**定義了 `__get__`、`__set__`** 的物件，當它被放在**類別屬性**裡時，存取該屬性就會呼叫這些方法。`@property` 其實就是描述器！

```python
class Positive:
    """可重複使用的驗證欄位：值必須大於 0"""
    def __set_name__(self, owner, name):     # 類別建立時自動呼叫，告訴描述器它叫什麼名字
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__[self.name]

    def __set__(self, obj, value):
        if not isinstance(value, (int, float)) or value <= 0:
            raise ValueError(f"{self.name} 必須是正數，收到 {value!r}")
        obj.__dict__[self.name] = value

class Product:
    price = Positive()          # 寫一次，到處重複使用
    stock = Positive()

    def __init__(self, name, price, stock):
        self.name = name
        self.price = price      # 會呼叫 Positive.__set__
        self.stock = stock

p = Product("筆電", 32000, 5)
print(p.price, p.stock)
for bad in [("price", -1), ("stock", "很多")]:
    try:
        setattr(p, *bad)
    except ValueError as e:
        print("❌", e)
```

用 property 的話，每個欄位都要寫一次 getter / setter；描述器則可以**重複使用**。這就是 Django 的 `models.CharField()`、SQLAlchemy 的 `Column()` 背後的原理。

## 類別也是物件：type

```python
class Dog:
    pass

print(type(Dog()))       # 物件的型別是 Dog
print(type(Dog))         # Dog 的型別是 type！
print(type(type))

# type 也可以「動態建立類別」
Cat = type("Cat", (), {"sound": "喵", "speak": lambda self: f"說{self.sound}"})
print(Cat().speak())
```

**類別是 type 的實例**。而**建立類別的類別**，就叫做 **metaclass（元類別）**。

## Metaclass：控制類別的建立

```python
class RegistryMeta(type):
    registry = {}

    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)
        if bases:                                   # 不登記基底類別本身
            mcs.registry[name.lower()] = cls
        return cls

class Plugin(metaclass=RegistryMeta):
    pass

class CsvExporter(Plugin):
    def run(self): return "匯出 CSV"

class PdfExporter(Plugin):
    def run(self): return "匯出 PDF"

print(RegistryMeta.registry)
print(RegistryMeta.registry["pdfexporter"]().run())
```

只要繼承 `Plugin`，類別就會自動登記，不用手動寫任何東西。

## 更簡單的替代：`__init_subclass__`

大部分 metaclass 能做的事，用 `__init_subclass__` 就可以做到，而且簡單得多。**優先用這個**：

```python
class Plugin:
    registry = {}

    def __init_subclass__(cls, name=None, **kwargs):   # 有類別繼承我的時候自動呼叫
        super().__init_subclass__(**kwargs)
        key = name or cls.__name__.lower()
        Plugin.registry[key] = cls

class Csv(Plugin, name="csv"):
    pass

class Excel(Plugin, name="xlsx"):
    pass

class Json(Plugin):
    pass

print(Plugin.registry)
```

> 💡 「Metaclass 是 99% 的使用者都不需要擔心的深層魔法。如果你在猶豫是否需要它，那你就不需要。」— Tim Peters（Python 之禪的作者）

## 實戰：迷你 ORM

把描述器和 `__init_subclass__` 組合起來，做一個像 Django Model 的東西：

```python
class Field:
    def __init__(self, type_, default=None):
        self.type, self.default = type_, default

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__.get(self.name, self.default)

    def __set__(self, obj, value):
        if not isinstance(value, self.type):
            raise TypeError(f"{self.name} 應該是 {self.type.__name__}")
        obj.__dict__[self.name] = value

class Model:
    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        cls._fields = [k for k, v in vars(cls).items() if isinstance(v, Field)]
        cls.table = cls.__name__.lower() + "s"

    def __init__(self, **kwargs):
        for name in self._fields:
            if name in kwargs:
                setattr(self, name, kwargs[name])

    def to_sql(self):
        cols = ", ".join(self._fields)
        vals = ", ".join(repr(getattr(self, f)) for f in self._fields)
        return f"INSERT INTO {self.table} ({cols}) VALUES ({vals});"

class User(Model):
    name = Field(str)
    age = Field(int, default=0)
    email = Field(str, default="")

u = User(name="小明", age=18)
print(u.to_sql())
try:
    User(name="小美", age="十八")
except TypeError as e:
    print("❌", e)
```

class Range:
    def __init__(self, low, high):
        self.low, self.high = low, high

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return obj.__dict__[self.name]

    def __set__(self, obj, value):
        if not self.low <= value <= self.high:
            raise ValueError(f"{self.name} 必須在 {self.low} 到 {self.high} 之間")
        obj.__dict__[self.name] = value


class Student:
    score = Range(0, 100)
    grade = Range(1, 6)

    def __init__(self, name, score, grade):
        self.name = name
        self.score = score
        self.grade = grade


s = Student("小明", 95, 3)
print(s.score, s.grade)
