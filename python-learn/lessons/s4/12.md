## 量測時間：timeit

```python
import timeit

setup = "data = list(range(10_000))"
tests = {
    "for 迴圈 + append": "r = []\nfor x in data:\n    r.append(x * 2)",
    "串列推導式": "r = [x * 2 for x in data]",
    "map + lambda": "r = list(map(lambda x: x * 2, data))",
}
for name, stmt in tests.items():
    t = timeit.timeit(stmt, setup=setup, number=200)
    print(f"{name:<18}{t * 1000 / 200:.3f} ms")
```

## 找出瓶頸：cProfile

不要用猜的！profiler 會告訴你**每個函式花了多少時間**：

```python
import cProfile, pstats, io

def slow_unique(items):
    result = []
    for x in items:
        if x not in result:          # 在串列裡搜尋：O(n)
            result.append(x)
    return result

def fast_unique(items):
    return list(dict.fromkeys(items))   # 用字典：O(1) 查詢，且保留順序

def main():
    data = [i % 2000 for i in range(20_000)]
    slow_unique(data)
    fast_unique(data)

pr = cProfile.Profile()
pr.enable()
main()
pr.disable()
s = io.StringIO()
pstats.Stats(pr, stream=s).sort_stats("cumulative").print_stats(5)
print(s.getvalue()[:1200])
```

在自己的電腦上可以直接在終端機執行：

```bash
python -m cProfile -s cumulative my_program.py
```

## 技巧 1：選對資料結構（效果最大！）

```python
import time

n = 20_000
data_list = list(range(n))
data_set = set(data_list)
targets = range(n - 1000, n)

t = time.perf_counter()
hits = sum(1 for x in targets if x in data_list)   # list：要一個一個比對
print(f"list 查詢：{(time.perf_counter() - t) * 1000:.1f} ms")

t = time.perf_counter()
hits = sum(1 for x in targets if x in data_set)    # set：雜湊表，幾乎瞬間
print(f"set 查詢：{(time.perf_counter() - t) * 1000:.3f} ms")
```

| 操作 | list | set / dict |
|---|---|---|
| `x in` 查詢 | 慢 O(n) | 快 O(1) |
| 依索引取值 | 快 O(1) | — |
| 開頭插入 | 慢 O(n)（改用 deque） | — |

第 5 階段會詳細解釋 **Big-O 時間複雜度**。

## 技巧 2：善用內建函式

內建函式是用 C 寫的，比自己寫的 Python 迴圈快很多：

```python
import timeit

data = list(range(100_000))

def manual_sum():
    total = 0
    for x in data:
        total += x
    return total

print("手寫迴圈", timeit.timeit(manual_sum, number=20))
print("sum()   ", timeit.timeit(lambda: sum(data), number=20))

words = ["python"] * 10_000
def concat():
    s = ""
    for w in words:
        s += w                     # 每次都建立新字串
    return s

print("字串 +=  ", timeit.timeit(concat, number=20))
print("join()  ", timeit.timeit(lambda: "".join(words), number=20))
```

## 技巧 3：快取

```python
from functools import lru_cache
import time

def count_paths(r, c):            # 網格從左上走到右下有幾種走法
    if r == 0 or c == 0:
        return 1
    return count_paths(r - 1, c) + count_paths(r, c - 1)

@lru_cache(maxsize=None)
def count_paths_cached(r, c):
    if r == 0 or c == 0:
        return 1
    return count_paths_cached(r - 1, c) + count_paths_cached(r, c - 1)

t = time.perf_counter(); print(count_paths(12, 12), f"{time.perf_counter() - t:.2f} 秒")
t = time.perf_counter(); print(count_paths_cached(12, 12), f"{time.perf_counter() - t:.5f} 秒")
print(count_paths_cached(100, 100))
```

## 技巧 4：向量化（資料科學的關鍵）

NumPy 一次對整個陣列運算，背後是高度最佳化的 C 程式：

```python
import numpy as np
import time

n = 1_000_000
py_list = list(range(n))
arr = np.arange(n)

t = time.perf_counter()
r1 = [x * x + 1 for x in py_list]
print(f"Python 串列：{(time.perf_counter() - t) * 1000:.0f} ms")

t = time.perf_counter()
r2 = arr * arr + 1
print(f"NumPy 向量化：{(time.perf_counter() - t) * 1000:.1f} ms")
```

第 7 階段會正式學 NumPy。

## 記憶體：`__slots__` 與產生器

```python
import sys

class Normal:
    def __init__(self, x, y):
        self.x, self.y = x, y

class Slotted:
    __slots__ = ("x", "y")          # 不使用 __dict__，固定屬性，省記憶體
    def __init__(self, x, y):
        self.x, self.y = x, y

a, b = Normal(1, 2), Slotted(1, 2)
print("一般物件：", sys.getsizeof(a) + sys.getsizeof(a.__dict__), "bytes")
print("__slots__：", sys.getsizeof(b), "bytes")
try:
    b.z = 3
except AttributeError as e:
    print("❌", e)
```

要建立**幾百萬個**小物件時，`__slots__` 可以省下大量記憶體。dataclass 也可以用 `@dataclass(slots=True)`。

## 最佳化的順序

1. ✅ **量測**：用 profiler 找出真正的瓶頸
2. ✅ **演算法和資料結構**：O(n²) → O(n log n)，效果最大
3. ✅ **用內建函式、標準函式庫、NumPy / pandas**
4. ✅ **快取**重複的計算
5. ✅ 平行化（async、多行程）
6. 最後才考慮：Cython、Numba、用 Rust / C 改寫

用兩個 set：`seen` 記錄看過的、`added` 記錄已經加入結果的。`in` 對 set 是 O(1)。
@@solution
def find_duplicates(orders):
    seen, added, result = set(), set(), []
    for o in orders:
        if o in seen and o not in added:
            result.append(o)
            added.add(o)
        seen.add(o)
    return result


print(find_duplicates(["A1", "B2", "A1", "C3", "B2", "A1"]))
