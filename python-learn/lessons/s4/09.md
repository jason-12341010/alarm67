## 為什麼需要非同步？

很多程式大部分的時間都在**等待**：等網路回應、等資料庫、等檔案。一般的程式是**一件做完才做下一件**：

```python
import time

def download(name, seconds):
    print(f"開始下載 {name}")
    time.sleep(seconds)            # 模擬等待網路
    print(f"✅ {name} 完成")

start = time.perf_counter()
download("圖片", 1)
download("影片", 1)
download("文件", 1)
print(f"總共 {time.perf_counter() - start:.1f} 秒")
```

明明都在「等」，為什麼不能**一起等**？這就是**非同步（asynchronous）** 的概念。

## async / await

- `async def`：定義**協程（coroutine）**，一種可以暫停的函式
- `await`：在這裡**暫停**，讓別人先做事，等結果好了再回來
- `asyncio.run()`：啟動事件迴圈，執行協程

```python
import asyncio
import time

async def download(name, seconds):
    print(f"開始下載 {name}")
    await asyncio.sleep(seconds)    # 非同步的等待：等的時候讓出控制權
    print(f"✅ {name} 完成")
    return f"{name}的資料"

async def main():
    start = time.perf_counter()
    results = await asyncio.gather(  # 同時執行好幾個協程
        download("圖片", 1),
        download("影片", 1),
        download("文件", 1),
    )
    print(results)
    print(f"總共 {time.perf_counter() - start:.1f} 秒")

asyncio.run(main())
```

3 秒變成 1 秒！

> 💡 非同步**不是**同時用很多個 CPU 做事，而是**一個人在等待的空檔切換去做別的事**。就像煮飯時，你不會站在電鍋前面等，而是同時去切菜。

## ⚠️ 不能在 async 函式裡用 time.sleep

`time.sleep` 會讓**整個程式**停住，其他協程也動不了：

```python
import asyncio, time

async def bad(name):
    time.sleep(0.5)               # ❌ 阻塞整個事件迴圈
    return name

async def good(name):
    await asyncio.sleep(0.5)      # ✅
    return name

async def main():
    t = time.perf_counter()
    await asyncio.gather(*(bad(i) for i in range(3)))
    print(f"time.sleep：{time.perf_counter() - t:.1f} 秒")
    t = time.perf_counter()
    await asyncio.gather(*(good(i) for i in range(3)))
    print(f"asyncio.sleep：{time.perf_counter() - t:.1f} 秒")

asyncio.run(main())
```

實務上，要用支援 async 的函式庫：網路請求用 `httpx` 或 `aiohttp`（不能用 `requests`）、資料庫用 `asyncpg` 等。

## 呼叫協程 ≠ 執行協程

```python
import asyncio

async def hello():
    return "哈囉"

coro = hello()
print(coro)                     # 只是一個協程物件，還沒執行
print(asyncio.run(coro))        # 要交給事件迴圈才會執行
```

## Task：在背景執行

`asyncio.create_task()` 把協程排進事件迴圈，**立刻開始執行**，不用等：

```python
import asyncio

async def tick(name, n, interval):
    for i in range(n):
        print(f"{name} {i}")
        await asyncio.sleep(interval)
    return f"{name} 完成"

async def main():
    t1 = asyncio.create_task(tick("🐢", 3, 0.3))
    t2 = asyncio.create_task(tick("🐇", 5, 0.1))
    print("兩個任務都開始了")
    print(await t1, await t2)

asyncio.run(main())
```

## 逾時與錯誤處理

```python
import asyncio

async def slow_api():
    await asyncio.sleep(3)
    return "資料"

async def flaky(n):
    await asyncio.sleep(0.1)
    if n == 2:
        raise ValueError(f"第 {n} 個失敗")
    return n

async def main():
    try:
        await asyncio.wait_for(slow_api(), timeout=0.5)
    except asyncio.TimeoutError:
        print("⏰ 逾時了")

    results = await asyncio.gather(*(flaky(i) for i in range(4)), return_exceptions=True)
    print(results)     # 錯誤也會放在結果裡，不會讓整批失敗

asyncio.run(main())
```

## 控制同時執行的數量：Semaphore

同時發出 1000 個請求可能會被網站封鎖。用 `Semaphore` 限制**最多同時幾個**：

```python
import asyncio, time

async def fetch(i, sem):
    async with sem:                       # 拿到「許可」才能執行
        print(f"  ↓ 開始 {i}")
        await asyncio.sleep(0.3)
        return i

async def main():
    sem = asyncio.Semaphore(3)            # 最多同時 3 個
    t = time.perf_counter()
    results = await asyncio.gather(*(fetch(i, sem) for i in range(9)))
    print(results, f"{time.perf_counter() - t:.1f} 秒")   # 9 個 / 每批 3 個 ≈ 0.9 秒

asyncio.run(main())
```

## 非同步產生器與 async for

```python
import asyncio

async def ticker(n):
    for i in range(n):
        await asyncio.sleep(0.1)
        yield i                            # 非同步產生器

async def main():
    async for value in ticker(5):
        print("收到", value)
    squares = [x * x async for x in ticker(4)]
    print(squares)

asyncio.run(main())
```

## 什麼時候用 async？

| 適合 ✅ | 不適合 ❌ |
|---|---|
| 大量網路請求（爬蟲、呼叫 API） | 大量計算（影像處理、訓練模型） |
| Web 伺服器（FastAPI 就是 async） | 簡單的小腳本 |
| 聊天機器人、即時通訊 | |
| 同時呼叫多個 AI 模型 API | |

計算量大的工作要用**多行程**，下一課會介紹。

import asyncio
import time

DATA = {"momo": (0.3, 1290), "PChome": (0.5, 1250), "蝦皮": (0.2, 1199), "Yahoo": (0.4, 1320)}


async def get_price(store):
    delay, price = DATA[store]
    await asyncio.sleep(delay)
    return price


async def cheapest(stores):
    prices = await asyncio.gather(*(get_price(s) for s in stores))
    return min(zip(stores, prices), key=lambda x: x[1])


t = time.perf_counter()
print(asyncio.run(cheapest(list(DATA))))
print(f"{time.perf_counter() - t:.1f} 秒")
