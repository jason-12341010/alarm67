**正規表示式（Regular Expression, regex）** 是描述「文字模式」的迷你語言。用來**搜尋、驗證、擷取、替換**符合某種格式的文字：email、電話、日期、網址… 爬蟲和資料清理一定會用到。

## 第一個例子

```python
import re

text = "我的電話是 0912-345-678，公司電話 02-2345-6789"
print(re.findall(r"\d+", text))                  # \d 是數字，+ 是一個以上
print(re.findall(r"09\d{2}-\d{3}-\d{3}", text))  # 手機號碼格式
```

> 💡 正規表示式的字串前面**一定加 `r`**（原始字串），因為 regex 裡有很多反斜線 `\`。

## 基本語法

| 符號 | 意思 | 範例 |
|---|---|---|
| `.` | 任意一個字元（換行除外） | `a.c` → abc、a7c |
| `\d` | 數字 | `\d\d` → 42 |
| `\w` | 英數字和底線（也包含中文） | `\w+` → hello_123 |
| `\s` | 空白（空格、Tab、換行） | |
| `\D` `\W` `\S` | 上面的相反 | |
| `[abc]` | a、b、c 其中一個 | `[aeiou]` 母音 |
| `[^abc]` | 不是 a、b、c | |
| `[a-z]` `[0-9]` | 範圍 | |
| `^` `$` | 開頭、結尾 | `^\d+$` 整串都是數字 |
| `\b` | 單字邊界 | `\bcat\b` 不會符合 category |

### 次數

| 符號 | 意思 |
|---|---|
| `*` | 0 次以上 |
| `+` | 1 次以上 |
| `?` | 0 或 1 次（可有可無） |
| `{3}` | 剛好 3 次 |
| `{2,4}` | 2 到 4 次 |

```python
import re

tests = ["color", "colour", "colouur"]
for t in tests:
    print(t, bool(re.fullmatch(r"colou?r", t)))    # u 可有可無

print(re.findall(r"\b\w{5}\b", "apple is a fruit, mango too"))   # 剛好 5 個字母的單字
print(re.findall(r"[A-Z][a-z]+", "Hello World From Python"))
```

## 常用函式

```python
import re

s = "訂單 A123 金額 450 元，訂單 B77 金額 1200 元"

print(re.search(r"\d+", s))            # 找第一個符合的（回傳 Match 物件或 None）
print(re.search(r"\d+", s).group())
print(re.match(r"\d+", s))             # 只從開頭比對 → None
print(re.fullmatch(r"[A-Z]\d+", "A123"))  # 整串都要符合（驗證用）
print(re.findall(r"\d+", s))           # 全部找出來（串列）
print(re.sub(r"\d+", "#", s))          # 替換
print(re.split(r"[，,\s]+", "a, b，c  d"))  # 用多種分隔符號切割
for m in re.finditer(r"\d+", s):       # 迭代每一個 Match（可以拿到位置）
    print(m.group(), m.start(), m.end())
```

## 群組：擷取部分內容

用小括號 `()` 把要擷取的部分包起來：

```python
import re

s = "訂單 A123 金額 450 元，訂單 B77 金額 1200 元"
print(re.findall(r"訂單 (\w+) 金額 (\d+)", s))      # 有群組時，findall 回傳群組的內容

m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "生日：2005-08-17")
print(m.group(0), m.group(1), m.groups())

# 具名群組：(?P<名字>...)
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", "生日：2005-08-17")
print(m.group("year"), m.groupdict())
```

替換時可以用 `\1` 或 `\g<名字>` 引用群組：

```python
import re

print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\2/\3/\1", "2026-11-04"))   # 改日期格式
print(re.sub(r"(?P<w>\w+)@", r"[\g<w>]@", "amy@mail.com"))

# 替換時也可以用函式
print(re.sub(r"\d+", lambda m: str(int(m.group()) * 2), "3 顆蘋果和 10 顆橘子"))
```

## 貪婪與非貪婪

`*` 和 `+` 預設是**貪婪的**（盡量多抓），加上 `?` 變成**非貪婪**（盡量少抓）：

```python
import re

html = "<b>粗體</b> 和 <i>斜體</i>"
print(re.findall(r"<.+>", html))     # 貪婪：一次抓到最後一個 >
print(re.findall(r"<.+?>", html))    # 非貪婪：每個標籤分開
print(re.findall(r"<(\w+)>(.*?)</\1>", html))
```

## 旗標與 compile

```python
import re

print(re.findall(r"python", "Python PYTHON python", flags=re.IGNORECASE))

pattern = re.compile(r"""
    ^(?P<user>[\w.+-]+)        # 使用者名稱
    @
    (?P<domain>[\w-]+(\.[\w-]+)+)$   # 網域
""", re.VERBOSE)               # VERBOSE：可以換行、寫註解

for email in ["amy.chen@gmail.com", "bob@mail.ntu.edu.tw", "bad@email", "@no.com"]:
    m = pattern.match(email)
    print(f"{email:<22}", m.groupdict() if m else "❌ 格式錯誤")
```

> 💡 同一個 pattern 要重複使用很多次時，先 `re.compile` 比較快，也比較好讀。

## 實戰：解析 log

```python
import re
from collections import Counter

log = """192.168.1.10 - [04/Nov/2026:10:15:32] "GET /index.html" 200 1024
10.0.0.5 - [04/Nov/2026:10:15:40] "POST /login" 401 128
192.168.1.10 - [04/Nov/2026:10:16:02] "GET /products" 200 4096
172.16.0.8 - [04/Nov/2026:10:16:30] "GET /admin" 403 64
10.0.0.5 - [04/Nov/2026:10:17:01] "POST /login" 200 256"""

LINE = re.compile(r'(?P<ip>[\d.]+) - \[(?P<time>[^\]]+)\] "(?P<method>\w+) (?P<path>\S+)" (?P<status>\d{3}) (?P<size>\d+)')
records = [m.groupdict() for m in LINE.finditer(log)]
print(records[0])
print("狀態碼統計：", Counter(r["status"] for r in records))
print("失敗的請求：", [(r["ip"], r["path"]) for r in records if not r["status"].startswith("2")])
```
