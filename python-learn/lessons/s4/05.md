Python 是動態型別語言，變數不用宣告型別。但程式變大之後，**看不出一個函式要傳什麼、會回傳什麼**，就很容易出錯。**型別提示（type hints）** 讓你把型別寫出來：

```python
def greet(name: str, times: int = 1) -> str:
    return ("哈囉，" + name + "！") * times

print(greet("小明", 2))
print(greet.__annotations__)
```

- `name: str`：參數 name 應該是字串
- `-> str`：這個函式回傳字串

> ⚠️ 型別提示**不會在執行時檢查**！傳錯型別 Python 一樣會執行。它的用途是讓**編輯器（VS Code）和檢查工具（mypy、pyright）** 幫你提早發現錯誤，同時也是最好的說明文件。

```python
def double(n: int) -> int:
    return n * 2

print(double("哈"))          # 型別錯了，但 Python 照樣執行
```

## 基本型別

```python
age: int = 18
price: float = 99.5
name: str = "小明"
ok: bool = True
nothing: None = None

# 容器：用中括號標示裡面元素的型別（Python 3.9+）
scores: list[int] = [90, 85]
point: tuple[float, float] = (1.5, 2.0)
record: tuple[str, ...] = ("a", "b", "c")    # 任意長度
tags: set[str] = {"ai", "python"}
ages: dict[str, int] = {"小明": 18}
print("型別提示不影響執行")
```

## 可能是 None、或多種型別

```python
def find_user(user_id: int) -> str | None:       # Python 3.10+：用 | 表示「或」
    users = {1: "小明", 2: "小美"}
    return users.get(user_id)

def to_number(x: int | float | str) -> float:
    return float(x)

print(find_user(1), find_user(99))
print(to_number("3.5"))
```

舊的寫法是 `Optional[str]` 和 `Union[int, str]`（要從 `typing` 匯入），在很多既有的程式碼裡還會看到。

## typing 模組的常用工具

```python
from typing import Any, Callable, Iterable, Iterator, Literal, TypedDict

def apply(f: Callable[[int], int], values: Iterable[int]) -> list[int]:
    return [f(v) for v in values]

def countdown(n: int) -> Iterator[int]:
    while n > 0:
        yield n
        n -= 1

def set_mode(mode: Literal["light", "dark"]) -> None:   # 只能是這兩個值
    print("模式：", mode)

class Movie(TypedDict):                                 # 字典的結構
    title: str
    year: int

def describe(m: Movie) -> str:
    return f"{m['title']}（{m['year']}）"

print(apply(lambda x: x * x, [1, 2, 3]))
print(list(countdown(3)))
set_mode("dark")
print(describe({"title": "全面啟動", "year": 2010}))
```

## 型別別名與泛型

```python
from typing import TypeVar

Vector = list[float]                    # 型別別名，讓程式更好讀

def scale(v: Vector, k: float) -> Vector:
    return [x * k for x in v]

T = TypeVar("T")                        # 泛型：「某個型別 T」

def first(items: list[T]) -> T:         # 傳入 list[int] 就回傳 int，傳入 list[str] 就回傳 str
    return items[0]

print(scale([1.0, 2.0], 3))
print(first([10, 20]), first(["a", "b"]))
```

Python 3.12 有更簡潔的泛型寫法：`def first[T](items: list[T]) -> T:`

## 類別的型別提示

```python
from dataclasses import dataclass
from typing import Self, ClassVar

@dataclass
class Node:
    value: int
    next: "Node | None" = None          # 還沒定義完的類別，用字串表示
    count: ClassVar[int] = 0            # 類別屬性

    def append(self, value: int) -> Self:
        self.next = Node(value)
        return self.next

head = Node(1)
head.append(2).append(3)
n = head
while n:
    print(n.value, end=" → ")
    n = n.next
print("None")
```

## 執行時真的要檢查型別？

型別提示本身不檢查，但有工具可以利用它。例如第 6 階段的 **Pydantic** 會依照型別提示**自動驗證和轉換資料**，FastAPI 也是靠型別提示自動產生 API 文件。這就是為什麼現代 Python 越來越重視型別提示。

```python
from typing import get_type_hints

def check_types(func):
    hints = get_type_hints(func)
    def wrapper(*args):
        for (name, expected), value in zip(hints.items(), args):
            if not isinstance(value, expected):
                raise TypeError(f"{name} 應該是 {expected.__name__}，收到 {type(value).__name__}")
        return func(*args)
    return wrapper

@check_types
def area(w: float, h: float) -> float:
    return w * h

print(area(3.0, 4.0))
try:
    area("3", 4.0)
except TypeError as e:
    print("❌", e)
```
