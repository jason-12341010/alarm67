**閉包（closure）**：一個內層函式，**記住了外層函式的變數**，即使外層函式已經執行完畢。

## 函式裡的函式

```python
def outer():
    message = "哈囉"

    def inner():
        print(message)      # 內層可以讀取外層的變數

    inner()

outer()
```

## 回傳內層函式

重點來了：如果把內層函式**回傳出去**，它仍然記得外層的變數：

```python
def make_greeter(greeting):
    def greet(name):
        return f"{greeting}，{name}！"
    return greet                     # 回傳函式本身（沒有括號）

hello = make_greeter("哈囉")
morning = make_greeter("早安")
print(hello("小明"))
print(morning("小美"))
print(hello.__closure__[0].cell_contents)   # 偷看它記住了什麼
```

`make_greeter` 已經執行完了，但 `hello` 還記得 `greeting = "哈囉"`。這就是閉包。

## 函式工廠

閉包很適合用來「**製造設定好的函式**」：

```python
def make_multiplier(k):
    return lambda x: x * k

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(10), triple(10))
print(list(map(make_multiplier(100), [1, 2, 3])))

def make_discount(rate):
    def apply(price):
        return round(price * (1 - rate))
    return apply

vip = make_discount(0.2)
staff = make_discount(0.3)
print(vip(1000), staff(1000))
```

## 有狀態的閉包：nonlocal

閉包可以**保存並更新狀態**，像一個簡單的物件：

```python
def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter

c1 = make_counter()
c2 = make_counter()
print(c1(), c1(), c1())
print(c2())                 # 各自獨立
```

```python
def make_averager():
    values = []                  # 串列是可變的，不用 nonlocal 也能修改內容
    def add(x):
        values.append(x)
        return sum(values) / len(values)
    return add

avg = make_averager()
for price in [100, 120, 90, 130]:
    print(f"加入 {price}，平均 {avg(price):.1f}")
```

## 閉包 vs 類別

很多時候兩種寫法都可以。閉包適合**簡單、只有一個動作**的情況；需要多個方法時，用類別比較清楚：

```python
# 閉包版
def make_account(balance):
    def withdraw(amount):
        nonlocal balance
        balance -= amount
        return balance
    return withdraw

# 類別版
class Account:
    def __init__(self, balance):
        self.balance = balance
    def withdraw(self, amount):
        self.balance -= amount
        return self.balance

w = make_account(1000)
print(w(100), w(200))
a = Account(1000)
print(a.withdraw(100), a.withdraw(200))
```

## ⚠️ 迴圈裡的閉包陷阱

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)       # 每個 lambda 記住的是「變數 i」，不是當時的值
print([f() for f in funcs])       # 全部都是 2！

funcs = []
for i in range(3):
    funcs.append(lambda i=i: i)   # 用預設參數「凍結」當下的值
print([f() for f in funcs])
```

閉包記住的是**變數本身**，而不是建立時的值。迴圈結束時 `i` 是 2，所以全部都回傳 2。

## 閉包的實際應用

下一課要學的**裝飾器**，就是建立在閉包上的。另外像「快取」也常用閉包實作：

```python
def memoize(func):
    cache = {}
    def wrapper(n):
        if n not in cache:
            cache[n] = func(n)
        return cache[n]
    return wrapper

def slow_square(n):
    print(f"  （計算 {n} 的平方…）")
    return n * n

fast = memoize(slow_square)
print(fast(4))
print(fast(4))       # 第二次直接從快取拿，不會再計算
print(fast(5))
```

def make_limited(func, max_calls):
    calls = 0

    def wrapper(*args, **kwargs):
        nonlocal calls
        if calls >= max_calls:
            raise RuntimeError("超過呼叫次數上限")
        calls += 1
        return func(*args, **kwargs)

    return wrapper
