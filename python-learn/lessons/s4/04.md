你已經用過 `with open(...) as f:`。`with` 背後的機制叫做**上下文管理器（context manager）**，它保證**進入和離開某個區塊時，一定會執行特定的動作**，即使中間發生錯誤也一樣。

## 為什麼需要 with？

```python
f = open("demo.txt", "w")
f.write("hello")
# 如果這裡發生錯誤，下面的 close() 就不會執行，檔案一直開著
f.close()

# 用 try/finally 才安全，但很囉嗦
f = open("demo.txt", "w")
try:
    f.write("hello")
finally:
    f.close()

# with 自動處理
with open("demo.txt", "w") as f:
    f.write("hello")
print(f.closed)
```

常見用途：**檔案、資料庫連線、網路連線、鎖、暫時改變設定、計時**…

## 用類別寫：`__enter__` 和 `__exit__`

```python
class Timer:
    def __enter__(self):                         # 進入 with 區塊時
        import time
        self.start = time.perf_counter()
        print("⏱ 開始計時")
        return self                              # 這個值會給 as 後面的變數

    def __exit__(self, exc_type, exc, tb):      # 離開時（不管有沒有錯誤）
        import time
        self.elapsed = time.perf_counter() - self.start
        print(f"⏱ 結束，花了 {self.elapsed * 1000:.1f} ms")
        return False                             # False：錯誤繼續往外丟

with Timer() as t:
    total = sum(i * i for i in range(300_000))
print(total, round(t.elapsed, 4))
```

`__exit__` 的三個參數：如果區塊裡發生錯誤，會收到錯誤的**類型、物件、追蹤資訊**；沒有錯誤就都是 `None`。回傳 `True` 代表「**錯誤我處理掉了**」，不會再往外丟：

```python
class Suppress:
    def __init__(self, *types):
        self.types = types

    def __enter__(self):
        return self

    def __exit__(self, exc_type, exc, tb):
        if exc_type and issubclass(exc_type, self.types):
            print(f"（忽略了 {exc_type.__name__}: {exc}）")
            return True                  # 吞掉錯誤
        return False

with Suppress(ZeroDivisionError):
    print(1 / 0)
print("程式繼續執行")
```

## 用產生器寫：@contextmanager

更簡潔的寫法：`yield` **之前**是進入，`yield` **之後**是離開：

```python
from contextlib import contextmanager
import time

@contextmanager
def timer(label):
    start = time.perf_counter()
    try:
        yield                                   # with 區塊在這裡執行
    finally:                                    # 用 finally 確保一定會執行
        print(f"{label}：{(time.perf_counter() - start) * 1000:.1f} ms")

with timer("排序"):
    sorted(range(500_000, 0, -1))

with timer("串列推導式"):
    [x * 2 for x in range(500_000)]
```

## 實用範例：暫時改變設定

```python
from contextlib import contextmanager

settings = {"debug": False, "lang": "zh-TW"}

@contextmanager
def temporary(**changes):
    old = {k: settings[k] for k in changes}
    settings.update(changes)
    try:
        yield settings
    finally:
        settings.update(old)                    # 一定會恢復原狀

print("之前：", settings)
with temporary(debug=True, lang="en"):
    print("區塊內：", settings)
print("之後：", settings)
```

## 實用範例：模擬資料庫交易

```python
from contextlib import contextmanager

class FakeDB:
    def __init__(self):
        self.data = {"小明": 1000, "小美": 500}

@contextmanager
def transaction(db):
    backup = dict(db.data)
    try:
        yield db
        print("✅ commit")
    except Exception as e:
        db.data = backup                         # 出錯就全部還原
        print(f"↩️ rollback：{e}")

db = FakeDB()
with transaction(db):
    db.data["小明"] -= 300
    db.data["小美"] += 300
print(db.data)

with transaction(db):
    db.data["小明"] -= 5000
    if db.data["小明"] < 0:
        raise ValueError("餘額不足")
print(db.data)                                  # 還原了
```

## contextlib 的其他工具

```python
from contextlib import suppress, redirect_stdout
import io

with suppress(FileNotFoundError):             # 忽略特定錯誤
    open("不存在的檔案.txt")
print("沒事")

buf = io.StringIO()
with redirect_stdout(buf):                     # 把 print 的輸出攔截下來
    print("這行不會出現在畫面上")
print("攔截到：", repr(buf.getvalue()))
```

一個 `with` 可以同時管理多個資源：

```python
with open("a.txt", "w") as a, open("b.txt", "w") as b:
    a.write("A")
    b.write("B")
print(open("a.txt").read(), open("b.txt").read())
```

from contextlib import contextmanager

level = 0


def say(text):
    print("  " * level + text)


@contextmanager
def indent():
    global level
    level += 1
    try:
        yield
    finally:
        level -= 1


say("專案")
with indent():
    say("src")
    with indent():
        say("main.py")
        say("utils.py")
    say("README.md")
say("完成")
