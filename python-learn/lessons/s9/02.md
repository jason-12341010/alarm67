上一課的權重是**手動設定**的。真正的神經網路，權重是**從資料中學出來**的。這一課我們**只用 NumPy**，從零開始寫一個會學習的神經網路。理解這個，你就理解了所有深度學習框架在做的事。

## 學習的四個步驟

```text
重複很多次：
  1. 前向傳播（Forward）：輸入資料，算出預測
  2. 計算損失（Loss）：預測和答案差多少
  3. 反向傳播（Backward）：算出每個權重該往哪個方向調整（梯度）
  4. 更新權重（Update）：w = w − 學習率 × 梯度
```

## 損失函數：衡量「錯得多離譜」

- **迴歸**：均方誤差 MSE
- **分類**：交叉熵（Cross-Entropy）：猜錯而且很有信心時，懲罰非常重

```python
import numpy as np

def bce(y, p):          # 二元交叉熵
    return -(y * np.log(p) + (1 - y) * np.log(1 - p))

print("答案是 1：")
for p in [0.99, 0.9, 0.6, 0.3, 0.01]:
    print(f"  預測 {p:.2f} → 損失 {bce(1, p):.3f}")
```

## 梯度下降：往山下走

想像你在濃霧中的山上，看不到山腳。最好的策略是：**摸摸看腳下哪個方向是下坡，往那裡走一小步**。

**梯度**就是「坡度」：告訴我們每個權重增加一點點時，損失會怎麼變。我們往**梯度的反方向**走：

```python
import numpy as np
import matplotlib.pyplot as plt

loss = lambda w: (w - 3) ** 2 + 1          # 最低點在 w = 3
grad = lambda w: 2 * (w - 3)               # 微分

fig, axes = plt.subplots(1, 3, figsize=(14, 3.5))
ws = np.linspace(-2, 8, 100)
for ax, lr in zip(axes, [0.05, 0.3, 1.05]):
    w, path = -1.0, []
    for _ in range(15):
        path.append(w)
        w -= lr * grad(w)
    ax.plot(ws, loss(ws), color="gray")
    ax.plot(path, [loss(p) for p in path], "o-", color="#e4572e", markersize=4)
    ax.set_title(f"學習率 {lr}：{'太小，走很慢' if lr < 0.1 else '剛好' if lr < 1 else '太大，發散了！'}")
    ax.set_ylim(0, 40)
fig.tight_layout()
plt.show()
```

**學習率（learning rate）** 是最重要的超參數：太小學得很慢，太大會跳過最低點甚至發散。

## 反向傳播：連鎖律

網路有很多層，怎麼算出**第一層**的權重對最終損失的影響？用微積分的**連鎖律**，從輸出層**一層一層往回推**。這就是**反向傳播（Backpropagation）**。

## 從零寫一個神經網路

用它來解決 XOR 問題，這次**讓它自己學**：

```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)

# 初始化：隨機的小數字
W1 = rng.normal(0, 1, (2, 8)); b1 = np.zeros(8)
W2 = rng.normal(0, 1, (8, 1)); b2 = np.zeros(1)
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 0.5

for epoch in range(3001):
    # 1. 前向傳播
    z1 = X @ W1 + b1
    h = np.tanh(z1)
    p = sigmoid(h @ W2 + b2)

    # 2. 損失（二元交叉熵）
    loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))

    # 3. 反向傳播（連鎖律）
    dz2 = (p - y) / len(X)              # sigmoid + 交叉熵的梯度剛好這麼簡單
    dW2 = h.T @ dz2
    db2 = dz2.sum(axis=0)
    dh = dz2 @ W2.T
    dz1 = dh * (1 - h ** 2)             # tanh 的微分
    dW1 = X.T @ dz1
    db1 = dz1.sum(axis=0)

    # 4. 更新權重
    W1 -= lr * dW1; b1 -= lr * db1
    W2 -= lr * dW2; b2 -= lr * db2

    if epoch % 500 == 0:
        print(f"第 {epoch:>4} 輪：損失 {loss:.4f}，預測 {p.ravel().round(2)}")

print("\n最終預測：", (p.ravel() > 0.5).astype(int), "答案：", y.ravel().astype(int))
```

損失越來越小，網路學會 XOR 了！🎉

## 更難的問題：看看決策邊界

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons

X, y = make_moons(400, noise=0.2, random_state=0)
y = y.reshape(-1, 1)
rng = np.random.default_rng(1)
H = 16
W1, b1 = rng.normal(0, 1, (2, H)), np.zeros(H)
W2, b2 = rng.normal(0, 1, (H, 1)) * 0.5, np.zeros(1)
sigmoid = lambda z: 1 / (1 + np.exp(-z))

def predict(X):
    return sigmoid(np.tanh(X @ W1 + b1) @ W2 + b2)

history = []
for epoch in range(2000):
    h = np.tanh(X @ W1 + b1)
    p = sigmoid(h @ W2 + b2)
    history.append(-np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9)))
    dz2 = (p - y) / len(X)
    dz1 = (dz2 @ W2.T) * (1 - h ** 2)
    W2 -= 1.0 * h.T @ dz2; b2 -= 1.0 * dz2.sum(0)
    W1 -= 1.0 * X.T @ dz1; b1 -= 1.0 * dz1.sum(0)

print(f"訓練準確率：{((predict(X) > 0.5) == y).mean():.1%}")
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].plot(history)
axes[0].set(title="損失曲線", xlabel="訓練輪數（epoch）", ylabel="損失")
xx, yy = np.meshgrid(np.linspace(-1.5, 2.5, 200), np.linspace(-1, 1.5, 200))
zz = predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
axes[1].contourf(xx, yy, zz, levels=20, cmap="RdBu", alpha=0.6)
axes[1].scatter(X[:, 0], X[:, 1], c=y.ravel(), cmap="RdBu", edgecolors="k", s=15)
axes[1].set_title("神經網路學到的決策邊界")
fig.tight_layout()
plt.show()
```

一條直線做不到的彎曲邊界，神經網路自己學會了。

## 名詞整理

| 名詞 | 意思 |
|---|---|
| **Epoch** | 把全部訓練資料看過一遍 |
| **Batch** | 每次更新權重時用的一小批資料 |
| **學習率** | 每次更新走多大步 |
| **前向傳播** | 輸入 → 預測 |
| **反向傳播** | 從損失往回算梯度 |
| **權重初始化** | 一開始的隨機權重（不能全部設成 0！） |

import numpy as np

rng = np.random.default_rng(0)
x = rng.uniform(0, 10, 100)
y = 2.5 * x + 4 + rng.normal(0, 1, 100)

w, b, lr = 0.0, 0.0, 0.01
losses = []
for _ in range(2000):
    pred = w * x + b
    losses.append(np.mean((pred - y) ** 2))
    dw = 2 * np.mean((pred - y) * x)
    db = 2 * np.mean(pred - y)
    w -= lr * dw
    b -= lr * db

print(f"w = {w:.3f}, b = {b:.3f}, 最終損失 {losses[-1]:.4f}" if losses else "還沒開始訓練")
