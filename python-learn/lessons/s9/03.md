## 張量（Tensor）

PyTorch 的張量就像 NumPy 陣列，但多了兩個超能力：
1. 可以在 **GPU** 上運算（快幾十倍）
2. 可以**自動計算梯度**（下一課）

```py
import torch

a = torch.tensor([[1., 2.], [3., 4.]])
print(a)
print(a.shape, a.dtype, a.device)       # torch.Size([2, 2]) torch.float32 cpu

print(torch.zeros(2, 3))
print(torch.ones(2, 3))
print(torch.arange(0, 10, 2))
print(torch.rand(2, 2))                  # 0～1 均勻分布
print(torch.randn(2, 2))                 # 標準常態分布
```

## 和 NumPy 對照

幾乎所有 NumPy 的寫法都能直接用：

| NumPy | PyTorch |
|---|---|
| `np.array([1, 2])` | `torch.tensor([1, 2])` |
| `a.shape` | `a.shape` 或 `a.size()` |
| `a.reshape(2, 3)` | `a.reshape(2, 3)` 或 `a.view(2, 3)` |
| `a @ b` | `a @ b` |
| `a.sum(axis=0)` | `a.sum(dim=0)` |
| `a.mean()` | `a.mean()` |
| `np.concatenate` | `torch.cat` |
| `a[a > 0]` | `a[a > 0]` |

這個網站可以執行 NumPy，來感受一下這些操作：

```python
import numpy as np

a = np.array([[1., 2.], [3., 4.]])
b = np.ones((2, 2))
print(a + b)
print(a @ b)                          # 矩陣乘法
print(a.sum(axis=0), a.mean())
print(a.reshape(4, 1).T)
print(np.concatenate([a, b], axis=0).shape)
```

```py
import torch

a = torch.tensor([[1., 2.], [3., 4.]])
b = torch.ones(2, 2)
print(a + b)
print(a @ b)
print(a.sum(dim=0), a.mean())
print(a.reshape(4, 1).T)
print(torch.cat([a, b], dim=0).shape)

# 和 NumPy 互相轉換
import numpy as np
n = a.numpy()
t = torch.from_numpy(np.array([1, 2, 3]))
```

## 使用 GPU

```py
import torch

device = "cuda" if torch.cuda.is_available() else "mps" if torch.backends.mps.is_available() else "cpu"
print("使用：", device)

x = torch.randn(4000, 4000, device=device)    # 直接在 GPU 上建立
y = x @ x                                       # 在 GPU 上計算
print(y.device)
z = y.cpu()                                     # 搬回 CPU
```

> ⚠️ 最常見的錯誤：**不同裝置上的張量不能一起運算**。模型和資料都要用 `.to(device)` 搬到同一個地方。

## 形狀操作：深度學習最常 debug 的地方

```python
import numpy as np

# 模擬：一批 32 張 28×28 的灰階圖片
batch = np.random.rand(32, 28, 28)
print("原始：", batch.shape)
print("加上 channel 維度：", batch[:, None, :, :].shape)     # PyTorch 的圖片格式是 (N, C, H, W)
print("攤平成向量：", batch.reshape(32, -1).shape)          # 丟進全連接層之前
print("交換維度：", batch.transpose(0, 2, 1).shape)
print("去掉長度 1 的維度：", np.zeros((1, 3, 1)).squeeze().shape)
```

```py
import torch

batch = torch.rand(32, 28, 28)
print(batch.unsqueeze(1).shape)        # (32, 1, 28, 28)
print(batch.flatten(start_dim=1).shape) # (32, 784)
print(batch.permute(0, 2, 1).shape)
print(torch.zeros(1, 3, 1).squeeze().shape)
```

> 💡 寫深度學習程式時，**隨時印出 `.shape`** 是最好的除錯習慣。

import numpy as np

rng = np.random.default_rng(0)
images = rng.integers(0, 256, size=(16, 32, 32, 3)).astype(np.float32)

chw = images.transpose(0, 3, 1, 2)
flat = images.reshape(16, -1)
normalized = (chw / 255 - 0.5) / 0.5
channel_mean = images.mean(axis=(0, 1, 2))
print(chw.shape, flat.shape, normalized.min(), normalized.max(), channel_mean.shape)
