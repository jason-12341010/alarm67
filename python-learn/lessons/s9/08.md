除了 PyTorch，另一個主流的深度學習框架是 Google 開發的 **TensorFlow**，以及它的高階介面 **Keras**。這一課快速比較兩者，讓你看到 TensorFlow 的程式碼也能看懂。

> 📄 TensorFlow 也無法在瀏覽器裡執行。Colab 已經內建 TensorFlow，可以直接貼上執行。在自己的電腦上：`pip install tensorflow`

## PyTorch vs TensorFlow

| | PyTorch | TensorFlow / Keras |
|---|---|---|
| 開發者 | Meta（Facebook） | Google |
| 風格 | 像寫一般的 Python，彈性大 | Keras 高度封裝，幾行就能訓練 |
| 研究界 | **主流**（大部分論文、Hugging Face 模型） | 較少 |
| 業界部署 | 越來越普及 | 行動裝置（TF Lite）、瀏覽器（TF.js）生態成熟 |
| 學習建議 | **建議先學** | 了解即可，需要時再學 |

> 💡 **Keras 3** 開始支援多種後端：同一份 Keras 程式碼，可以在 TensorFlow、PyTorch 或 JAX 上執行。

## Keras 的寫法

Keras 最大的特色是 **`compile` + `fit`**，訓練迴圈都幫你寫好了：

```py
import keras
from keras import layers
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)
scaler = StandardScaler().fit(X_train)
X_train, X_test = scaler.transform(X_train), scaler.transform(X_test)

model = keras.Sequential([
    keras.Input(shape=(4,)),
    layers.Dense(32, activation="relu"),
    layers.Dropout(0.2),
    layers.Dense(32, activation="relu"),
    layers.Dense(3, activation="softmax"),
])
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
model.summary()

history = model.fit(X_train, y_train, epochs=100, batch_size=16, validation_split=0.2, verbose=0)
loss, acc = model.evaluate(X_test, y_test, verbose=0)
print(f"測試準確率：{acc:.3f}")
model.save("iris.keras")
```

### scikit-learn（沒錯，它也有簡單的神經網路）

```python
from sklearn.neural_network import MLPClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)
model = make_pipeline(
    StandardScaler(),
    MLPClassifier(hidden_layer_sizes=(32, 32), max_iter=1000, random_state=0),
)
model.fit(X_train, y_train)
print(f"測試準確率：{model.score(X_test, y_test):.3f}")
print("每一層的權重形狀：", [w.shape for w in model[-1].coefs_])
```

`MLPClassifier` 可以在這個網站直接執行！它適合小資料、快速實驗，但不支援 GPU，也不能建立 CNN、Transformer 這類複雜的架構。

## Keras 的 Callbacks

訓練時的「外掛」，例如提早停止、自動存最好的模型：

```py
callbacks = [
    keras.callbacks.EarlyStopping(monitor="val_loss", patience=10, restore_best_weights=True),
    keras.callbacks.ModelCheckpoint("best.keras", save_best_only=True),
    keras.callbacks.ReduceLROnPlateau(factor=0.5, patience=5),
]
model.fit(X_train, y_train, validation_split=0.2, epochs=500, callbacks=callbacks)
```
