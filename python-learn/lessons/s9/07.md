文字、語音、股價… 這些資料有**順序**。「我 愛 你」和「你 愛 我」用的字一樣，意思卻完全不同。這一課介紹處理序列的模型，以及改變世界的 **Transformer**：ChatGPT 和 Claude 背後的架構。

## 第一步：文字怎麼變成數字？

### 1. 斷詞（Tokenization）

把文字切成一個個 **token**，再對應到編號：

```python
text = "我喜歡學習 Python，Python 很好玩"
vocab = {}
tokens = []
for ch in text.replace(" ", ""):            # 最簡單的做法：一個字一個 token
    if ch not in vocab:
        vocab[ch] = len(vocab)
    tokens.append(vocab[ch])
print(vocab)
print(tokens)
```

實際的大型語言模型用 **BPE**（Byte Pair Encoding）之類的方法，把常見的字詞組合成一個 token。

### 2. 詞嵌入（Embedding）

把每個 token 編號，對應到一個**向量**。訓練之後，**意思相近的詞，向量也會相近**：

```python
import numpy as np

# 假裝這是訓練好的 4 維詞向量
emb = {
    "國王": np.array([0.9, 0.8, 0.1, 0.7]),
    "皇后": np.array([0.9, 0.1, 0.8, 0.7]),
    "男人": np.array([0.1, 0.9, 0.1, 0.2]),
    "女人": np.array([0.1, 0.1, 0.9, 0.2]),
    "蘋果": np.array([0.0, 0.3, 0.3, 0.9]),
}

def cosine(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

target = emb["國王"] - emb["男人"] + emb["女人"]      # 著名的向量運算
for word, v in sorted(emb.items(), key=lambda kv: -cosine(target, kv[1])):
    print(f"{word}：{cosine(target, v):.3f}")
```

「國王 − 男人 + 女人 ≈ 皇后」，向量捕捉到了「性別」和「皇室」這些概念！第 10 階段會用真正的 embedding 做語意搜尋。

## RNN：有記憶的網路

**循環神經網路（Recurrent Neural Network）** 一次讀一個 token，並用一個**隱藏狀態**記住之前讀過的內容：

```text
h₀ → [RNN] → h₁ → [RNN] → h₂ → [RNN] → h₃ → 輸出
       ↑              ↑              ↑
      "我"           "愛"           "你"
```

```python
import numpy as np

rng = np.random.default_rng(0)
d_in, d_h = 4, 3
Wx, Wh, b = rng.normal(0, 0.5, (d_in, d_h)), rng.normal(0, 0.5, (d_h, d_h)), np.zeros(d_h)

sentence = rng.normal(size=(5, d_in))      # 5 個 token，每個是 4 維向量
h = np.zeros(d_h)
for t, x in enumerate(sentence):
    h = np.tanh(x @ Wx + h @ Wh + b)       # 新的記憶 = f(現在的輸入, 之前的記憶)
    print(f"讀完第 {t + 1} 個 token，隱藏狀態 = {h.round(3)}")
```

### RNN 的問題

1. **長期記憶不好**：句子一長，前面的資訊會慢慢消失（梯度消失）→ 改良版 **LSTM**、**GRU**
2. **無法平行運算**：一定要一個一個 token 依序處理，訓練很慢

## Transformer 與注意力機制

2017 年 Google 發表論文《**Attention Is All You Need**》，提出 **Transformer**，完全拋棄 RNN。核心是**自注意力（Self-Attention）**：

> 每個詞都可以**直接看到**句子裡的所有其他詞，並決定要**注意**哪些詞。

例如「**小明**把書給了小美，因為**他**要出國了」，模型在處理「他」的時候，會把注意力放在「小明」上。

### 注意力的計算

每個 token 產生三個向量：
- **Query（Q）**：我在找什麼？
- **Key（K）**：我有什麼特徵？
- **Value（V）**：我要提供的資訊

```text
Attention(Q, K, V) = softmax(Q·Kᵀ / √d) · V
```

用 NumPy 實作只要幾行：

```python
import numpy as np

def softmax(z):
    e = np.exp(z - z.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

def attention(Q, K, V):
    d = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d)           # 每個詞和每個詞的相關程度
    weights = softmax(scores)               # 轉成注意力權重（每一列加總為 1）
    return weights @ V, weights

rng = np.random.default_rng(1)
tokens = ["小明", "把", "書", "給", "小美", "他"]
d = 8
X = rng.normal(size=(len(tokens), d))
X[5] = X[0] + rng.normal(0, 0.3, d)          # 讓「他」的向量和「小明」很像
Wq, Wk, Wv = (rng.normal(0, 0.4, (d, d)) for _ in range(3))
Wq = Wk = np.eye(d)                          # 簡化：直接用原本的向量比較相似度

out, w = attention(X @ Wq, X @ Wk, X @ Wv)
print("「他」對每個詞的注意力：")
for t, a in zip(tokens, w[5]):
    print(f"  {t:<3}{'█' * int(a * 40)} {a:.2f}")
```

```python
import numpy as np

```

### Transformer 的優點

- ✅ **平行運算**：所有 token 同時計算，可以用 GPU 大規模訓練
- ✅ **長距離關係**：任何兩個詞之間都只隔一步
- ✅ **可以無限擴大**：參數越多、資料越多，效果越好（Scaling Law）

### GPT 是怎麼產生文字的？

GPT（Generative Pre-trained Transformer）的任務非常單純：**預測下一個 token**。

```python
import numpy as np

rng = np.random.default_rng(0)
vocab = ["我", "喜歡", "學習", "Python", "和", "AI", "。"]
# 假裝這是模型在每一步算出的「下一個 token 機率」
next_probs = {
    "我": [0, .9, .05, 0, 0, 0, .05], "喜歡": [0, 0, .7, .2, 0, .1, 0],
    "學習": [0, 0, 0, .6, 0, .35, .05], "Python": [0, 0, 0, 0, .6, 0, .4],
    "和": [0, 0, 0, .1, 0, .9, 0], "AI": [0, 0, 0, 0, .1, 0, .9],
}
text = ["我"]
while text[-1] != "。" and len(text) < 10:
    p = np.array(next_probs[text[-1]])
    text.append(vocab[rng.choice(len(vocab), p=p / p.sum())])     # 依照機率抽樣
print("".join(text))
```

把這件事用**幾千億個參數**、**幾兆個 token** 的文字去訓練，模型就「被迫」學會了文法、知識、甚至推理能力。這就是大型語言模型（LLM）。

## PyTorch 的 Transformer

```py
import torch
from torch import nn

layer = nn.TransformerEncoderLayer(d_model=64, nhead=4, batch_first=True)
encoder = nn.TransformerEncoder(layer, num_layers=2)
x = torch.randn(8, 20, 64)       # 8 個句子、每句 20 個 token、每個 token 64 維

```

實務上很少自己從零訓練 Transformer，而是用 **Hugging Face** 下載訓練好的模型，第 10 階段會介紹。

import numpy as np


def attention(Q, K, V, mask=None):
    scores = Q @ K.T / np.sqrt(Q.shape[-1])
    if mask is not None:
        scores = np.where(mask, scores, -1e9)
    e = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights = e / e.sum(axis=-1, keepdims=True)
    return weights @ V, weights
