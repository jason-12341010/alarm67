處理圖片時，全連接網路有兩個大問題：
1. **參數太多**：一張 224×224 的彩色圖片有 15 萬個像素，第一層就要上千萬個權重
2. **不認得位置變化**：貓在左上角和右下角，對它來說是完全不同的輸入

**卷積神經網路（Convolutional Neural Network, CNN）** 解決了這兩個問題，是影像辨識的核心技術。

## 卷積：用小視窗掃過圖片

**卷積核（kernel / filter）** 是一個小小的權重矩陣（例如 3×3），在圖片上**滑動**，每個位置都做「對應元素相乘再加總」：

```python
import numpy as np

def conv2d(img, kernel):
    kh, kw = kernel.shape
    H, W = img.shape
    out = np.zeros((H - kh + 1, W - kw + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = (img[i:i + kh, j:j + kw] * kernel).sum()
    return out

img = np.array([
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
])
vertical_edge = np.array([[-1, 0, 1],
                          [-1, 0, 1],
                          [-1, 0, 1]])
print(conv2d(img, vertical_edge))      # 在明暗交界的地方數值最大 → 偵測到邊緣！
```

同一個卷積核在整張圖上**共用權重**：參數少，而且不管邊緣出現在哪裡都偵測得到。

## 看看卷積核的效果

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_sample_image

img = load_sample_image("china.jpg").mean(axis=2)[::2, ::2]     # 轉成灰階、縮小
kernels = {
    "原圖": None,
    "垂直邊緣": np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]]),
    "水平邊緣": np.array([[-1, -2, -1], [0, 0, 0], [1, 2, 1]]),
    "模糊": np.ones((5, 5)) / 25,
    "銳利化": np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]]),
}

def conv2d_fast(img, k):
    from numpy.lib.stride_tricks import sliding_window_view
    return (sliding_window_view(img, k.shape) * k).sum(axis=(-1, -2))

fig, axes = plt.subplots(1, 5, figsize=(17, 3.5))
for ax, (name, k) in zip(axes, kernels.items()):
    out = img if k is None else conv2d_fast(img, k)
    ax.imshow(np.abs(out) if name.endswith("邊緣") else out, cmap="gray")
    ax.set_title(name)
    ax.axis("off")
fig.tight_layout()
plt.show()
```

傳統的影像處理要**人工設計**這些卷積核。CNN 的厲害之處是：**卷積核的數值是從資料中學出來的**！

## CNN 的組成

```text
輸入圖片
  ↓
[卷積層] → [ReLU] → [池化層]     ← 偵測簡單特徵（邊緣、顏色）
  ↓
[卷積層] → [ReLU] → [池化層]     ← 組合成複雜特徵（眼睛、輪子）
  ↓
[攤平] → [全連接層] → [softmax]   ← 分類
```

### 池化（Pooling）：縮小圖片

**最大池化**：每 2×2 的區域只保留最大值。圖片變小一半，保留最重要的特徵，也讓模型對小位移更穩健：

```python
import numpy as np

x = np.array([
    [1, 3, 2, 1],
    [4, 6, 5, 2],
    [7, 2, 9, 8],
    [1, 0, 3, 4],
])
pooled = x.reshape(2, 2, 2, 2).max(axis=(1, 3))
print(pooled)
```

## PyTorch 的 CNN

```py
import torch
from torch import nn

class SimpleCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),   # (1, 28, 28) → (32, 28, 28)
            nn.ReLU(),
            nn.MaxPool2d(2),                              # → (32, 14, 14)
            nn.Conv2d(32, 64, kernel_size=3, padding=1),  # → (64, 14, 14)
            nn.ReLU(),
            nn.MaxPool2d(2),                              # → (64, 7, 7)
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),                                 # → 3136
            nn.Linear(64 * 7 * 7, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, n_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = SimpleCNN()
x = torch.randn(8, 1, 28, 28)            # 8 張 28×28 的灰階圖片
print(model(x).shape)                     # torch.Size([8, 10])
print("參數數量：", sum(p.numel() for p in model.parameters()))
```

## 遷移學習：站在巨人的肩膀上

從零訓練一個好的 CNN 需要幾百萬張圖片。實務上，我們**拿別人在 ImageNet（1400 萬張圖片）上訓練好的模型**，只重新訓練最後一層：

```py
import torch
from torchvision import models

model = models.resnet18(weights="IMAGENET1K_V1")      # 下載預訓練好的 ResNet-18
for p in model.parameters():
    p.requires_grad = False                           # 凍結所有層
model.fc = torch.nn.Linear(model.fc.in_features, 2)   # 換掉最後一層：例如分類貓 / 狗
# 接下來只會訓練最後一層，幾百張圖片就能有很好的效果
```

這叫做**遷移學習（Transfer Learning）**，是實務上最常用的做法。

import numpy as np


def conv2d(img, kernel):
    kh, kw = kernel.shape
    H, W = img.shape
    out = np.zeros((H - kh + 1, W - kw + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = (img[i:i + kh, j:j + kw] * kernel).sum()
    return out


def max_pool(x, size=2):
    H, W = x.shape
    return x.reshape(H // size, size, W // size, size).max(axis=(1, 3))
