ChatGPT、Claude、人臉辨識、自駕車… 這些 AI 的核心都是**神經網路（Neural Network）**。這一課從最小的單位開始：**一個神經元**。

## 一個神經元在做什麼？

```text
輸入            權重
x₁ ──── w₁ ─┐
x₂ ──── w₂ ─┼──→ [ Σ 加總 + b ] ──→ [ 激活函數 ] ──→ 輸出
x₃ ──── w₃ ─┘
```

1. 每個輸入乘上**權重** w（這個輸入有多重要）
2. 全部加起來，再加上**偏差** b
3. 通過**激活函數**，決定輸出

是不是很眼熟？這就是第 8 階段的**邏輯迴歸**！

```python
import numpy as np

def neuron(x, w, b):
    z = np.dot(x, w) + b              # 加權總和
    return 1 / (1 + np.exp(-z))       # sigmoid 激活函數

# 要不要去看電影？[天氣好, 朋友有空, 有錢]
w = np.array([0.5, 2.0, 1.0])         # 朋友有沒有空最重要
b = -2.0
for x in [[1, 0, 1], [0, 1, 1], [1, 1, 0], [0, 0, 1]]:
    print(x, "→ 想去的程度", round(neuron(np.array(x), w, b), 2))
```

## 激活函數

激活函數讓神經網路可以學習**非線性**的關係。如果沒有它，疊再多層也只等於一個線性模型。

```python
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-5, 5, 200)
funcs = {
    "Sigmoid": 1 / (1 + np.exp(-z)),
    "Tanh": np.tanh(z),
    "ReLU": np.maximum(0, z),
    "GELU（Transformer 常用）": 0.5 * z * (1 + np.tanh(np.sqrt(2 / np.pi) * (z + 0.044715 * z ** 3))),
}
fig, axes = plt.subplots(1, 4, figsize=(15, 3.2))
for ax, (name, y) in zip(axes, funcs.items()):
    ax.plot(z, y, linewidth=2)
    ax.axhline(0, color="gray", linewidth=0.5)
    ax.axvline(0, color="gray", linewidth=0.5)
    ax.set_title(name)
fig.tight_layout()
plt.show()
```

| 函式 | 範圍 | 用在哪裡 |
|---|---|---|
| **ReLU** | 0 到 ∞ | 隱藏層的**預設選擇**，簡單又有效 |
| Sigmoid | 0 到 1 | 二元分類的**輸出層** |
| Tanh | −1 到 1 | RNN |
| **Softmax** | 0 到 1，總和為 1 | 多類別分類的**輸出層** |
| GELU | | Transformer（GPT、BERT） |

## 一個神經元的極限：XOR 問題

一個神經元只能畫出**一條直線**來分類。但有些問題，一條直線分不開：

```python
import numpy as np
import matplotlib.pyplot as plt

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
for ax, (name, y) in zip(axes, {"AND": [0, 0, 0, 1], "OR": [0, 1, 1, 1], "XOR（互斥或）": [0, 1, 1, 0]}.items()):
    ax.scatter(X[:, 0], X[:, 1], c=y, cmap="coolwarm", s=300, edgecolors="k")
    ax.set_title(name)
    ax.set_xlim(-0.5, 1.5); ax.set_ylim(-0.5, 1.5)
axes[0].plot([0, 1.5], [1.5, 0], "g--")          # x + y = 1.5
axes[1].plot([-0.5, 1.0], [1.0, -0.5], "g--")    # x + y = 0.5
axes[2].text(0.5, 0.5, "一條直線\n分不開！", ha="center", va="center", fontsize=13, color="red")
fig.tight_layout()
plt.show()
```

1969 年，這個問題讓神經網路的研究沉寂了十幾年。解決方法是：**多疊幾層**。

## 多層神經網路

```text
輸入層        隱藏層         輸出層
  x₁ ──┬──→ ○ ──┬──→
       ├──→ ○ ──┼──→  ○ ──→ 預測
  x₂ ──┴──→ ○ ──┘
```

每一層的每個神經元，都接收上一層**所有**神經元的輸出。整層的計算可以寫成**矩陣乘法**：

```python
import numpy as np

def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 手動設定好權重的 2 層網路，可以解決 XOR！
W1 = np.array([[1, 1], [1, 1]])        # 輸入 2 → 隱藏 2
b1 = np.array([0, -1])
W2 = np.array([[1], [-2]])              # 隱藏 2 → 輸出 1
b2 = np.array([0])

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
h = relu(X @ W1 + b1)                   # 第一層
out = h @ W2 + b2                       # 第二層
print("隱藏層的輸出：\n", h)
print("XOR 的結果：", out.ravel())
```

隱藏層把資料**轉換到新的空間**，在新的空間裡，資料就可以用一條直線分開了。這就是深度學習的核心想法：**每一層都學習更有用的表示方式（representation）**。

## 為什麼叫「深度」學習？

**深度** = 很多層。層數越多，能學到的特徵越抽象：

```text
辨識人臉的網路：
第 1 層：邊緣、線條
第 2 層：角落、紋理
第 3 層：眼睛、鼻子、嘴巴
第 4 層：整張臉
```

GPT-3 有 96 層、1750 億個參數。但每個參數做的事，就和我們上面那幾行程式一樣。
