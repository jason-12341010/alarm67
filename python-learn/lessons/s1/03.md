## 算術運算子

```python
a, b = 17, 5
print(a + b)    # 加
print(a - b)    # 減
print(a * b)    # 乘
print(a / b)    # 除：結果一定是 float
print(a // b)   # 整數除法（取商，無條件捨去）
print(a % b)    # 取餘數
print(a ** b)   # 次方
```

> 💡 `%` 取餘數非常常用：`n % 2 == 0` 判斷偶數、`n % 10` 取個位數。

運算順序跟數學一樣：先 `**`，再 `* / // %`，最後 `+ -`。不確定的時候就加**括號**：

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
print(-2 ** 2)        # -4，因為 ** 比負號先算
```

## 複合賦值

```python
score = 10
score += 5     # 等同 score = score + 5
score -= 2
score *= 3
score //= 2
print(score)
```

## 比較運算子

比較的結果是 `True` 或 `False`：

```python
print(5 > 3)
print(5 == 5.0)   # == 比較是否相等
print(5 != 3)     # != 不相等
print(3 <= 3)
print(1 < 5 < 10) # Python 可以連續比較
print("apple" < "banana")  # 字串按字典順序比
```

## 邏輯運算子

| 運算子 | 意思 |
|---|---|
| `and` | 兩邊都是 True 才是 True |
| `or` | 只要有一邊是 True 就是 True |
| `not` | 反轉 True / False |

```python
age = 20
has_ticket = False
print(age >= 18 and has_ticket)
print(age >= 18 or has_ticket)
print(not has_ticket)
```

## 浮點數的小陷阱

電腦用二進位存小數，所以有些小數存不精準：

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2) == 0.3)   # 比較前先四捨五入
```
