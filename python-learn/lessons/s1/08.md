`while` 迴圈會在**條件成立時一直重複執行**，條件變成 `False` 才停下來。

```python
count = 1
while count <= 5:
    print(f"第 {count} 次")
    count += 1
print("結束")
```

執行流程：
1. 檢查 `count <= 5` → True → 執行區塊
2. `count` 變成 2，再檢查一次…
3. `count` 變成 6 時條件是 False → 離開迴圈

## ⚠️ 無窮迴圈

如果條件永遠不會變成 False，迴圈就停不下來。最常見的原因是**忘了更新變數**：

```python
n = 1
while n <= 3:
    print(n)
    # 忘了寫 n += 1 → 永遠是 1
```

這個網站超過 30 秒會自動停止，也可以直接按 **■ 停止** 按鈕（建議！不用等）。在自己的電腦上則是按 <kbd>Ctrl</kbd> + <kbd>C</kbd>。

## 什麼時候用 while？

**不知道要跑幾次、要等某個條件達成**的時候。例如：存錢多久會翻倍？

```python
money = 10000
rate = 0.05
years = 0
while money < 20000:
    money *= 1 + rate
    years += 1
print(f"{years} 年後變成 {money:,.0f} 元")
```

## 搭配 input：重複詢問直到輸入正確

```python
password = input("請輸入密碼：")
while password != "python":
    print("密碼錯誤，再試一次")
    password = input("請輸入密碼：")
print("登入成功！")
```

## 經典範例：拆解數字

用 `% 10` 取個位數，`// 10` 去掉個位數：

```python
n = 2026
total = 0
while n > 0:
    digit = n % 10
    total += digit
    n //= 10
print("各位數字總和：", total)
```

total = 0

@@solution
total = 0
n = 0
while total <= 100:
    n += 1
    total += n
print(n, total)

:::exercise 考拉茲猜想
規則：如果 n 是偶數就除以 2，奇數就乘以 3 再加 1，一直做到 n 變成 1。從 `n = 27` 開始，算出總共要做幾步，存進 `steps`。
@@starter
n = 27
steps = 0

print(steps)
@@check
assert "while" in code, "請使用 while 迴圈"
assert ns["steps"] == 111, f"答案應該是 111 步，你的是 {ns['steps']}"
@@hint
`while n != 1:` 裡面用 if 判斷奇偶，偶數用 `n //= 2`（整數除法），最後 `steps += 1`。
@@solution
n = 27
steps = 0
while n != 1:
    if n % 2 == 0:
        n //= 2
    else:
        n = n * 3 + 1
    steps += 1
print(steps)
:::
