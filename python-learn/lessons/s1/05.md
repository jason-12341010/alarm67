要把變數放進字串，最好用的方法是 **f-string**：在字串前面加 `f`，然後用 `{}` 放變數或運算式。

```python
name = "小美"
age = 20
print(f"我叫{name}，今年{age}歲")
print(f"明年就{age + 1}歲了")
print(f"名字有 {len(name)} 個字")
```

比起用 `+` 串接（還要把數字轉成字串），f-string 簡潔很多：

```python
age = 20
print("今年" + str(age) + "歲")   # 舊寫法，麻煩
print(f"今年{age}歲")             # f-string
```

## 格式化數字

在 `{}` 裡加上 `:` 和**格式規格**：

```python
pi = 3.14159265
price = 1234567.891
rate = 0.8765

print(f"{pi:.2f}")        # 小數點後 2 位
print(f"{price:,}")       # 千分位
print(f"{price:,.2f}")    # 千分位 + 2 位小數
print(f"{rate:.1%}")      # 百分比
print(f"{42:05d}")        # 補 0 到 5 位
```

## 對齊

`<` 靠左、`>` 靠右、`^` 置中，後面接寬度。很適合印表格：

```python
items = [("蘋果", 30), ("香蕉", 5), ("西瓜", 120)]
print(f"{'品名':<6}{'價格':>6}")
print("-" * 14)
for name, p in items:
    print(f"{name:<6}{p:>8}")
print(f"[{'置中':^10}]")
print(f"[{'填滿':*^10}]")    # 用 * 填滿空位
```

> 💡 中文字在等寬字型裡大約佔兩格，所以中英混排時看起來可能會沒對齊，這是正常的。

## 除錯神器：`=`

在變數後面加 `=`，會連同變數名稱一起印出來，除錯時超好用：

```python
x = 10
y = 3
print(f"{x=}, {y=}, {x / y=:.3f}")
```

## 其他格式化方式（看得懂就好）

```python
name, age = "Tom", 30
print("%s is %d years old" % (name, age))      # 舊式 %
print("{} is {} years old".format(name, age))  # .format()
```

:::exercise 成績單
用 f-string 印出：`小明的平均分數是 86.33 分`。平均值要從 `scores` 計算，保留 2 位小數。
@@starter
name = "小明"
scores = [90, 78, 91]
avg = sum(scores) / len(scores)
# 用 f-string 印出結果

@@check
assert output.strip() == "小明的平均分數是 86.33 分", f"輸出不對：{output.strip()!r}"
assert "f\"" in code or "f'" in code, "請使用 f-string"
@@hint
`{avg:.2f}` 會四捨五入到小數點後 2 位。
@@solution
name = "小明"
scores = [90, 78, 91]
avg = sum(scores) / len(scores)
print(f"{name}的平均分數是 {avg:.2f} 分")
:::
