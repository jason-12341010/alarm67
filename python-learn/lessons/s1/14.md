## 遊戲規則

1. 電腦隨機選一個 1～100 的數字
2. 玩家猜數字，電腦回答「太大」或「太小」
3. 猜中就結束，並顯示猜了幾次

## 先認識 random 模組

```python
import random

print(random.randint(1, 100))           # 1～100 的隨機整數（包含 100）
print(random.choice(["剪刀", "石頭", "布"]))
nums = [1, 2, 3, 4, 5]
random.shuffle(nums)                    # 打亂順序
print(nums)

random.seed(42)                         # 設定種子：之後的隨機結果會固定
print(random.randint(1, 100))
```

> 💡 `random.seed()` 讓隨機結果可以重現，測試程式的時候很有用。

## 拆解步驟

寫程式之前先想清楚流程，這是很重要的習慣：

```
產生答案 answer
次數 tries = 0
重複：
    讀入 guess
    tries + 1
    如果 guess > answer → 太大
    如果 guess < answer → 太小
    否則 → 猜中了，跳出迴圈
印出結果
```

## 完整程式

輸入框裡已經放了一些猜測。因為設定了 `seed`，答案是固定的，試著執行看看：

```python
import random

random.seed(2026)
answer = random.randint(1, 100)
tries = 0

print("我想了一個 1～100 的數字，猜猜看！")
while True:
    guess = int(input("你的猜測："))
    tries += 1
    if guess > answer:
        print("太大了！")
    elif guess < answer:
        print("太小了！")
    else:
        print(f"🎉 答對了！答案就是 {answer}，你猜了 {tries} 次")
        break
```

## 二分搜尋：最聰明的猜法

每次都猜**範圍的正中間**，可以把範圍砍半。1～100 最多 7 次就一定猜得到！讓電腦自己玩玩看：

```python
import random

answer = random.randint(1, 100)
low, high = 1, 100
tries = 0
while True:
    guess = (low + high) // 2
    tries += 1
    print(f"第 {tries} 次猜 {guess}", end="  ")
    if guess > answer:
        print("太大")
        high = guess - 1
    elif guess < answer:
        print("太小")
        low = guess + 1
    else:
        print("✓ 猜中！")
        break
```

這個「每次砍半」的想法叫做**二分搜尋（Binary Search）**，第 5 階段的演算法課會再深入。

answer = 42
tries = 0
max_tries = 5

while tries < max_tries:
    guess = int(input())
    if guess < 1 or guess > 100:

        continue
    tries += 1
    if guess > answer:
        print("太大了！")
