## print() 印出內容

`print()` 是最常用的函式，用來把東西顯示在畫面上。括號裡可以放好幾個值，用逗號隔開，印出來時中間會自動加一個空白：

```python
print("我今年", 18, "歲")
print(3 + 4)
print()                 # 什麼都不放 → 印出空行
print("A", "B", "C", sep="-")   # sep：改變中間的分隔符號
print("不換行", end="")  # end：改變結尾（預設是換行 \n）
print("…接在後面")
```

## 註解

`#` 後面的文字是**註解**，Python 會直接跳過。用來寫給人看的說明：

```python
# 這一整行都是註解
print("註解不會被執行")  # 寫在程式後面也可以

"""
三個引號包起來的多行字串，
常被拿來當作多行說明使用。
"""
```

## Python 的規則：大小寫與縮排

- Python **分大小寫**：`print` 和 `Print` 是不同的東西。
- 每行開頭**不能隨便空格**，縮排在 Python 裡有特別的意義（第 7 課會學到）。

試著執行下面這段程式，看看錯誤訊息長什麼樣子。網站會用中文解釋錯誤原因：

```python
Print("大寫的 P 會出錯")
```
