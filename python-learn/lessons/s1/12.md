## tuple：不能修改的串列

**元組（tuple）** 用小括號 `()`，跟串列很像，但建立之後**不能修改**：

```python
point = (3, 4)
rgb = (255, 128, 0)
print(point[0], rgb[-1])
print(len(rgb))
# point[0] = 10   ← 會出現 TypeError
```

為什麼需要不能改的串列？
- **安全**：確定資料不會被意外修改（例如座標、日期、設定值）
- **可以當作字典的鍵**（下一課會用到）
- 稍微**快一點、省記憶體**

```python
single = (5,)        # 只有一個元素時，要加逗號！
not_tuple = (5)      # 這只是數字 5 加括號
print(type(single), type(not_tuple))
```

## 打包與解包

其實逗號才是 tuple 的關鍵，括號可以省略：

```python
t = 1, 2, 3          # 打包
a, b, c = t          # 解包
print(a, b, c)

first, *rest = [10, 20, 30, 40]   # * 收集剩下的
print(first, rest)

*init, last = "hello"
print(init, last)
```

函式回傳多個值時，其實就是回傳 tuple：

```python
nums = [4, 8, 1, 9]
lo, hi = min(nums), max(nums)
print(lo, hi)
```

## set：不重複的集合

**集合（set）** 用大括號 `{}`，特點是**元素不重複、沒有順序**：

```python
tags = {"python", "ai", "python", "data"}
print(tags)              # 重複的會被自動去掉
print(len(tags))
print("ai" in tags)      # 查詢非常快

nums = [1, 2, 2, 3, 3, 3]
print(set(nums))         # 最快的去重複方法
print(list(set(nums)))
```

> 💡 空的 set 要寫 `set()`，因為 `{}` 是空字典。

```python
s = set()
s.add("a")
s.add("b")
s.add("a")
s.discard("b")          # 刪除（不存在也不會出錯）
print(s)
```

## 集合運算

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b)    # 聯集：在 a 或 b
print(a & b)    # 交集：同時在 a 和 b
print(a - b)    # 差集：在 a 但不在 b
print(a ^ b)    # 對稱差：只在其中一邊
```

實際例子：找出兩個班級都有修的學生

```python
class_a = {"小明", "小美", "阿華", "小強"}
class_b = {"阿華", "小芳", "小明"}
print("都有修：", class_a & class_b)
print("只修 A：", class_a - class_b)
```

## 三種容器比較

| | list `[]` | tuple `()` | set `{}` |
|---|---|---|---|
| 可以修改 | ✅ | ❌ | ✅ |
| 有順序、可用索引 | ✅ | ✅ | ❌ |
| 允許重複 | ✅ | ✅ | ❌ |
| 適合 | 一般資料 | 固定資料 | 去重、查詢、集合運算 |

:::exercise 共同興趣
`amy` 和 `bob` 是兩個人的興趣串列（有重複）。用 set 算出：
- `both`：兩人共同的興趣（set）
- `only_amy`：只有 Amy 有的興趣（set）
- `total`：兩人加起來總共有幾種不同的興趣（int）
@@starter
amy = ["游泳", "電影", "程式", "電影", "旅行"]
bob = ["程式", "籃球", "旅行", "籃球"]

print(both, only_amy, total)
@@check
assert ns["both"] == {"程式", "旅行"}, f"both 不對：{ns['both']}"
assert ns["only_amy"] == {"游泳", "電影"}, f"only_amy 不對：{ns['only_amy']}"
assert ns["total"] == 5, f"total 應該是 5，你的是 {ns['total']}"
@@hint
先轉成 set：`a = set(amy)`，然後用 `&`、`-`、`len(a | b)`。
@@solution
amy = ["游泳", "電影", "程式", "電影", "旅行"]
bob = ["程式", "籃球", "旅行", "籃球"]
a, b = set(amy), set(bob)
both = a & b
only_amy = a - b
total = len(a | b)
print(both, only_amy, total)
:::
