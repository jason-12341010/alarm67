**串列（list）** 用中括號 `[]` 把多個值裝在一起，是 Python 最常用的資料結構。

```python
scores = [85, 92, 78, 90]
mixed = [1, "two", 3.0, True]   # 可以放不同型別
empty = []
print(scores, len(scores))
print(scores[0], scores[-1])    # 索引跟字串一樣
print(scores[1:3])              # 切片也一樣
```

## 串列可以修改

跟字串不同，串列是**可變的（mutable）**：

```python
nums = [10, 20, 30]
nums[1] = 99
print(nums)
```

## 新增與刪除

```python
fruits = ["蘋果", "香蕉"]
fruits.append("芒果")        # 加到最後
fruits.insert(0, "西瓜")     # 插入到指定位置
fruits.extend(["葡萄", "梨"]) # 加入另一個串列的所有元素
print(fruits)

fruits.remove("香蕉")        # 刪除第一個符合的值
last = fruits.pop()          # 取出並刪除最後一個
first = fruits.pop(0)        # 取出並刪除指定位置
del fruits[0]                # 用 del 刪除
print(fruits, last, first)
```

## 搜尋與統計

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(4 in nums)          # 是否包含
print(nums.index(5))      # 第一次出現的位置
print(nums.count(1))      # 出現幾次
print(min(nums), max(nums), sum(nums))
```

## 排序

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(sorted(nums))       # 回傳新的串列，原本的不變
print(nums)
nums.sort(reverse=True)   # 直接修改原本的串列
print(nums)
nums.reverse()
print(nums)
```

> 💡 `sorted(x)` 會建立新串列；`x.sort()` 直接改原本的串列，而且回傳 `None`。所以不要寫 `x = x.sort()`！

## ⚠️ 複製的陷阱

`b = a` **不是複製**，而是讓兩個名字指向**同一個串列**：

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)          # a 也變了！

c = a.copy()      # 真正的複製（也可以用 a[:] 或 list(a)）
c.append(5)
print(a, c)
```

## 串列裡放串列（二維）

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
]
print(grid[1][2])     # 第 2 列第 3 個
for row in grid:
    print(row)
```

## enumerate：同時拿到索引和值

```python
names = ["Amy", "Bob", "Cat"]
for i, name in enumerate(names, start=1):
    print(i, name)
```
