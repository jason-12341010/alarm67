## input() 讀取使用者輸入

`input()` 會停下來等使用者輸入一行文字。在這個網站裡，程式中有 `input()` 時，編輯器下方會出現 **⌨️ 輸入** 框，**一行對應一次 `input()`**。

```python
name = input("你叫什麼名字？")
print(f"哈囉，{name}！")
```
```stdin
小明
```

## input() 拿到的一定是字串

這是新手最常踩的坑：

```python
a = input("第一個數字：")
b = input("第二個數字：")
print(a + b)          # 字串相加 → 串接！
print(type(a))
```
```stdin
3
5
```

輸入框裡是 `3` 和 `5`，結果卻是 `35` 而不是 `8`！

## 型別轉換

| 函式 | 轉成 | 範例 |
|---|---|---|
| `int()` | 整數 | `int("42")` → `42` |
| `float()` | 浮點數 | `float("3.5")` → `3.5` |
| `str()` | 字串 | `str(42)` → `"42"` |
| `bool()` | 布林 | `bool(0)` → `False` |

```python
a = int(input("第一個數字："))
b = int(input("第二個數字："))
print(a + b)
```
```stdin
3
5
```

```python
print(int(3.99))      # 直接捨去小數，不是四捨五入
print(round(3.99))    # 四捨五入
print(int("  42  "))  # 前後空白沒關係
print(float("1e3"))
print(str(3.0) + "!")
```

## 轉換失敗

如果字串不是合法的數字，會出現 `ValueError`。第 2 階段會學怎麼用 `try / except` 處理：

```python
print(int("3.5"))     # 錯！"3.5" 不是整數，要先 float() 再 int()
```

## 布林轉換：什麼是「假」？

以下的值轉成 `bool` 都是 `False`，其他幾乎都是 `True`：`0`、`0.0`、`""`（空字串）、`[]`、`{}`、`None`。

```python
for v in [0, 1, -3, "", "0", " ", [], [0], None]:
    print(repr(v), "→", bool(v))
```

> 💡 注意 `bool("0")` 是 `True`，因為 `"0"` 不是空字串！

## 一次讀多個值

輸入 `3 5 7` 這種一行多個數字的情況，用 `split()` 切開再轉換：

```python
nums = input("輸入三個數字（空白隔開）：").split()
a, b, c = int(nums[0]), int(nums[1]), int(nums[2])
print(a + b + c)
```
```stdin
3 5 7
```

:::exercise BMI 計算機
讀入**身高（公分）**和**體重（公斤）**兩行輸入，計算 BMI = 體重 ÷ (身高公尺²)，印出 `BMI: 22.86`（保留 2 位小數）。
@@starter
height_cm = input("身高（公分）：")
weight = input("體重（公斤）：")

@@stdin
175
70
@@check
assert lines[-1] == "BMI: 22.86", f"最後一行應該是 'BMI: 22.86'，你的是 {lines[-1] if lines else '（沒有輸出）'!r}"
@@hint
先用 `float()` 轉換，公分要除以 100 變成公尺，再用 `f"BMI: {bmi:.2f}"` 印出。
@@solution
height_cm = float(input("身高（公分）："))
weight = float(input("體重（公斤）："))
h = height_cm / 100
bmi = weight / h ** 2
print(f"BMI: {bmi:.2f}")
:::

:::exercise 秒數轉換
讀入一個整數秒數，轉成「時:分:秒」格式，每個部分補 0 到 2 位。例如 `3725` → `01:02:05`。
@@starter
total = int(input())

@@stdin
3725
@@check
assert lines[-1] == "01:02:05", f"應該印出 01:02:05，你的是 {lines[-1] if lines else ''!r}"
@@hint
小時 `total // 3600`、分鐘 `total % 3600 // 60`、秒 `total % 60`，用 `{h:02d}` 補 0。
@@solution
total = int(input())
h = total // 3600
m = total % 3600 // 60
s = total % 60
print(f"{h:02d}:{m:02d}:{s:02d}")
:::
