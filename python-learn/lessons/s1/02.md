**變數**就是幫資料取一個名字，之後可以用這個名字拿到資料。用 `=` 把右邊的值存進左邊的名字：

```python
name = "小明"
age = 18
height = 172.5
is_student = True

print(name, age, height, is_student)

age = age + 1      # 變數可以重新賦值
print("明年", age, "歲")
```

> 💡 `=` 在程式裡是「**賦值**」，不是數學的「等於」。`age = age + 1` 的意思是：算出 `age + 1`，再把結果存回 `age`。

## 四種基本資料型別

| 型別 | 名稱 | 範例 |
|---|---|---|
| `int` | 整數 | `42`、`-7`、`1_000_000` |
| `float` | 浮點數（小數） | `3.14`、`-0.5`、`1e6` |
| `str` | 字串（文字） | `"hello"`、`'你好'` |
| `bool` | 布林值（真假） | `True`、`False` |

用 `type()` 可以查看一個值是什麼型別：

```python
print(type(42))
print(type(3.14))
print(type("42"))      # 有引號就是字串！
print(type(True))
print(type(None))      # None 代表「沒有值」
```

## 動態型別

Python 的變數**不用宣告型別**，同一個變數可以先放數字、再放字串。很方便，但也容易搞混，所以要記得自己存了什麼：

```python
x = 10
print(x, type(x))
x = "十"
print(x, type(x))
```

## 命名規則

- 只能用**英文字母、數字、底線**（中文也可以，但不建議）
- **不能用數字開頭**：`2name` ❌
- 不能用 Python 的保留字：`if`、`for`、`class`…
- Python 慣例使用 **snake_case**：`user_name`、`total_price`

```python
# 一次給多個變數賦值
a, b, c = 1, 2, 3
print(a, b, c)

# 交換兩個變數（Python 的特色寫法）
a, b = b, a
print(a, b)

# 多個變數設成同一個值
x = y = 0
print(x, y)
```
