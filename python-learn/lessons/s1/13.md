**字典（dict）** 存放「**鍵（key）→ 值（value）**」的對應關係，就像查字典一樣，用鍵找到值。

```python
student = {
    "name": "小明",
    "age": 18,
    "scores": [90, 85],
}
print(student["name"])
print(student["scores"][0])
print(len(student))
```

## 新增、修改、刪除

```python
d = {"apple": 30}
d["banana"] = 10         # 新增
d["apple"] = 35          # 修改（鍵已存在就覆蓋）
del d["banana"]          # 刪除
price = d.pop("apple")   # 取出並刪除
print(d, price)
```

## 安全取值：get()

用 `[]` 取不存在的鍵會出現 `KeyError`。用 `get()` 比較安全：

```python
stock = {"蘋果": 5, "香蕉": 0}
print(stock.get("蘋果"))
print(stock.get("西瓜"))          # 不存在 → None
print(stock.get("西瓜", 0))       # 不存在 → 回傳預設值
print("西瓜" in stock)            # 檢查鍵是否存在
print(stock["西瓜"])              # KeyError！
```

## 走訪字典

```python
prices = {"咖啡": 65, "紅茶": 35, "蛋糕": 90}

for name in prices:                  # 預設走訪「鍵」
    print(name)

for name, p in prices.items():       # 同時拿鍵和值（最常用）
    print(f"{name}: {p} 元")

print(list(prices.keys()))
print(list(prices.values()))
print(sum(prices.values()))
```

> 💡 Python 3.7 以後，字典會**保留加入的順序**。

## 經典用法：計數

統計每個字出現幾次：

```python
text = "banana"
count = {}
for ch in text:
    count[ch] = count.get(ch, 0) + 1
print(count)
```

## 經典用法：分組

```python
words = ["apple", "avocado", "banana", "blueberry", "cherry"]
groups = {}
for w in words:
    first = w[0]
    if first not in groups:
        groups[first] = []
    groups[first].append(w)
print(groups)
```

## 字典的鍵

鍵必須是**不可變的**型別：字串、數字、tuple 都可以，串列不行：

```python
distance = {("台北", "高雄"): 350, ("台北", "台中"): 170}
print(distance[("台北", "高雄")])
```

## 巢狀資料

真實世界的資料（像是 API 回傳的 JSON）常常是串列和字典互相包：

```python
users = [
    {"name": "Amy", "age": 25, "skills": ["Python", "SQL"]},
    {"name": "Bob", "age": 31, "skills": ["Java"]},
]
for u in users:
    print(f"{u['name']}（{u['age']}）會 {', '.join(u['skills'])}")
```

## 其他好用方法

```python
a = {"x": 1, "y": 2}
b = {"y": 20, "z": 30}
print(a | b)            # 合併（後面的蓋過前面的）
a.update(b)             # 直接更新 a
print(a)
print(a.setdefault("w", 0), a)   # 不存在才設定
```
