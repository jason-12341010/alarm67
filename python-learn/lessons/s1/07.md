## if 的基本寫法

```python
temperature = 32

if temperature > 30:
    print("好熱！")
    print("記得喝水")
print("這行不管怎樣都會執行")
```

重點：
1. 條件後面要有**冒號 `:`**
2. 條件成立時要執行的程式要**縮排 4 個空白**
3. 縮排結束，就代表 if 區塊結束

## if / else

```python
age = 16
if age >= 18:
    print("可以投票")
else:
    print(f"還要再等 {18 - age} 年")
```

## if / elif / else：多個條件

由上往下檢查，**只會執行第一個成立的區塊**：

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print(f"{score} 分是 {grade} 等級")
```

> 💡 為什麼 85 分不會被判斷成 C？因為 `score >= 80` 已經成立，後面的 elif 就不會再檢查了。所以條件的**順序**很重要。

## 巢狀 if 與組合條件

```python
age = 25
member = True

# 巢狀寫法
if age >= 18:
    if member:
        print("成人會員")

# 用 and 合併，通常比較好讀
if age >= 18 and member:
    print("成人會員")
```

## 簡寫：三元運算式

簡單的二選一可以寫成一行：

```python
n = 7
kind = "偶數" if n % 2 == 0 else "奇數"
print(n, "是", kind)
```

## 真假值判斷

if 後面可以直接放任何值，Python 會自動判斷真假（還記得上一課的「假值」嗎？）：

```python
name = ""
if name:
    print(f"哈囉 {name}")
else:
    print("你還沒輸入名字")

items = []
if not items:
    print("購物車是空的")
```

## 常見錯誤

```python
x = 5
if x = 5:        # ❌ 比較要用 ==，不是 =
    print("五")
```

:::exercise BMI 判斷
根據 `bmi` 的值，把結果存進變數 `status`：
- 小於 18.5：`"過輕"`
- 18.5 以上、小於 24：`"正常"`
- 24 以上、小於 27：`"過重"`
- 27 以上：`"肥胖"`
@@starter
bmi = 22.5

print(status)
@@check
body = code
for b, want in [(17, "過輕"), (18.5, "正常"), (23.9, "正常"), (24, "過重"), (26.9, "過重"), (27, "肥胖"), (35, "肥胖")]:
    g = {"print": lambda *a, **k: None}
    exec(body.replace("bmi = 22.5", f"bmi = {b}", 1), g)
    assert g.get("status") == want, f"bmi = {b} 時應該是 {want!r}，你的是 {g.get('status')!r}"
@@hint
用 `if bmi < 18.5:` … `elif bmi < 24:` … `elif bmi < 27:` … `else:`
@@solution
bmi = 22.5
if bmi < 18.5:
    status = "過輕"
elif bmi < 24:
    status = "正常"
elif bmi < 27:
    status = "過重"
else:
    status = "肥胖"
print(status)

:::exercise 電影票價
讀入**年齡**，印出票價：
- 未滿 6 歲或 65 歲以上：`免費`
- 6～17 歲：`半票 150 元`
- 其他：`全票 300 元`
@@starter
age = int(input("年齡："))

@@stdin
12
@@check
body = code
for a, want in [(3, "免費"), (6, "半票 150 元"), (17, "半票 150 元"), (18, "全票 300 元"), (64, "全票 300 元"), (65, "免費")]:
    outs = []
    exec(body, {"input": lambda p="": str(a), "print": lambda *x, **k: outs.append(" ".join(map(str, x)))})
    assert outs and outs[-1] == want, f"年齡 {a} 應該印出 {want!r}，你的是 {outs[-1] if outs else '（沒有輸出）'!r}"
@@hint
`if age < 6 or age >= 65:` 放第一個判斷。
@@solution
age = int(input("年齡："))
if age < 6 or age >= 65:
    print("免費")
elif age <= 17:
    print("半票 150 元")
else:
    print("全票 300 元")
