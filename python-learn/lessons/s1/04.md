## 建立字串

單引號、雙引號都可以，效果一樣。字串裡有引號時，用另一種引號包起來：

```python
a = "Hello"
b = 'Python'
c = "I'm learning"
d = """可以
寫很多行"""
print(a, b, c)
print(d)
```

## 跳脫字元

| 寫法 | 意思 |
|---|---|
| `\n` | 換行 |
| `\t` | Tab |
| `\\` | 反斜線本身 |
| `\"` | 雙引號 |

```python
print("第一行\n第二行")
print("名字\t分數")
print("路徑 C:\\Users")
print(r"C:\new\table")   # 前面加 r：原始字串，\ 不跳脫
```

## 串接與重複

```python
first = "Py"
second = "thon"
print(first + second)   # + 串接
print("哈" * 3)          # * 重複
print(len("Python"))     # len() 取長度
```

## 索引：取出某個字

字串的每個字都有位置編號（**索引**），**從 0 開始**。負數代表從後面數回來：

```
 P   y   t   h   o   n
 0   1   2   3   4   5
-6  -5  -4  -3  -2  -1
```

```python
s = "Python"
print(s[0])    # 第一個字
print(s[5])
print(s[-1])   # 最後一個字
print(s[-2])
```

## 切片：取出一段

`s[start:stop:step]`，**包含 start、不包含 stop**：

```python
s = "Hello, Python"
print(s[0:5])    # Hello
print(s[7:])     # 從 7 到最後
print(s[:5])     # 從頭到 5（不含）
print(s[-6:])    # 最後 6 個字
print(s[::2])    # 每隔一個字取一個
print(s[::-1])   # 反轉字串！
```

> 💡 切片超出範圍不會出錯，但單一索引超出範圍會出現 `IndexError`。

## 字串不能修改

字串是**不可變的（immutable）**，不能只改其中一個字，要建立新字串：

```python
s = "cat"
# s[0] = "b"   ← 這樣會出錯
s = "b" + s[1:]
print(s)
```

## 常用方法（先認識幾個）

```python
s = "  Hello Python  "
print(s.upper())
print(s.lower())
print(s.strip())               # 去掉前後空白
print(s.replace("Python", "World"))
print("Python" in s)           # 檢查是否包含
print(s.strip().split(" "))    # 切成串列
```
