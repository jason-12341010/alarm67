`for` 迴圈用來**一個一個走過**一串資料（字串、串列、range…）。

```python
for ch in "Python":
    print(ch)
```

```python
fruits = ["蘋果", "香蕉", "芒果"]
for fruit in fruits:
    print(f"我喜歡{fruit}")
```

## range()：產生數字序列

| 寫法 | 產生 |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(2, 6)` | 2, 3, 4, 5 |
| `range(0, 10, 3)` | 0, 3, 6, 9 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

跟切片一樣，**包含開頭，不包含結尾**。

```python
for i in range(5):
    print(i, end=" ")
print()
for i in range(1, 11, 2):
    print(i, end=" ")
print()
for i in range(10, 0, -3):
    print(i, end=" ")
```

## 累加的常見模式

```python
total = 0
for i in range(1, 101):
    total += i
print("1 加到 100 =", total)

# 其實 Python 有內建 sum
print(sum(range(1, 101)))
```

## 巢狀迴圈

迴圈裡面再放迴圈。外層跑一次，內層會跑完一整輪：

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}x{j}={i*j:<3}", end=" ")
    print()   # 內層跑完就換行
```

```python
# 印出三角形
for i in range(1, 6):
    print("*" * i)
```

## for 還是 while？

- **知道要跑幾次，或要走過一串資料** → `for`
- **不知道要跑幾次，等條件成立才停** → `while`

## 迴圈變數命名

如果用不到迴圈變數，習慣上用 `_` 表示「我不在乎這個值」：

```python
for _ in range(3):
    print("加油！")
```

:::exercise FizzBuzz
經典面試題！印出 1 到 15，但是：
- 3 的倍數印 `Fizz`
- 5 的倍數印 `Buzz`
- 同時是 3 和 5 的倍數印 `FizzBuzz`
- 其他印數字本身
@@starter
for i in range(1, 16):
    pass
@@check
want = ["FizzBuzz" if i % 15 == 0 else "Fizz" if i % 3 == 0 else "Buzz" if i % 5 == 0 else str(i) for i in range(1, 16)]
assert lines == want, f"輸出不對。應該是 {want}，你的是 {lines}"
@@hint
先判斷 `i % 15 == 0`（同時是 3 和 5 的倍數），再判斷 3、5，順序很重要。
@@solution
for i in range(1, 16):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
:::

height = 4

want = [" " * (4 - i) + "*" * (2 * i - 1) for i in range(1, 5)]
got = [l for l in output.split("\n") if l.strip()]
