**機率分布**描述「每種結果發生的可能性」。AI 模型的輸出常常就是一個機率分布：「這張圖 92% 是貓、7% 是狗、1% 是兔子」。

## 用模擬理解機率

電腦可以「實驗」幾十萬次，用頻率逼近機率：

```python
import numpy as np

rng = np.random.default_rng(0)
dice = rng.integers(1, 7, size=(100_000, 2))     # 擲兩顆骰子 10 萬次
total = dice.sum(axis=1)
print("點數和是 7 的機率：", (total == 7).mean(), "（理論值 6/36 =", round(6 / 36, 4), "）")
print("兩顆一樣的機率：", (dice[:, 0] == dice[:, 1]).mean())
values, counts = np.unique(total, return_counts=True)
for v, c in zip(values, counts):
    print(f"{v:>2} {'█' * (c // 600)}")
```

## 離散分布

### 二項分布：n 次試驗中成功幾次

例如：投籃命中率 70%，投 10 次會進幾球？

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

n, p = 10, 0.7
k = np.arange(0, n + 1)
pmf = stats.binom.pmf(k, n, p)                    # 每種結果的機率
plt.bar(k, pmf, color="#3776ab")
plt.title(f"二項分布：投 {n} 次、命中率 {p}")
plt.xlabel("進球數")
plt.ylabel("機率")
plt.show()
print("剛好進 7 球：", round(stats.binom.pmf(7, n, p), 4))
print("至少進 9 球：", round(1 - stats.binom.cdf(8, n, p), 4))
```

### 卜瓦松分布：一段時間內事件發生幾次

例如：客服中心平均每小時接到 4 通電話：

```python
from scipy import stats

lam = 4
for k in range(0, 10):
    print(f"一小時接到 {k} 通：{stats.poisson.pmf(k, lam):.3f}  {'▇' * int(stats.poisson.pmf(k, lam) * 100)}")
print("超過 8 通（需要加派人手）的機率：", round(1 - stats.poisson.cdf(8, lam), 4))
```

## 連續分布

### 常態分布（鐘形曲線）

自然界最常見的分布：身高、考試成績、測量誤差… 由**平均數 μ** 和**標準差 σ** 決定：

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

x = np.linspace(-5, 5, 400)
fig, ax = plt.subplots(figsize=(8, 4))
for mu, sigma in [(0, 1), (0, 2), (2, 0.7)]:
    ax.plot(x, stats.norm.pdf(x, mu, sigma), label=f"μ={mu}, σ={sigma}")
ax.legend()
ax.set_title("常態分布")
plt.show()
```

### 68-95-99.7 法則

```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(0, 1, 1_000_000)
for k in (1, 2, 3):
    print(f"在平均 ±{k} 個標準差內：{(np.abs(x) < k).mean():.2%}")
```

| 範圍 | 比例 |
|---|---|
| μ ± 1σ | 約 68% |
| μ ± 2σ | 約 95% |
| μ ± 3σ | 約 99.7% |

所以超過 3 個標準差的值非常少見，常被當作**異常值**。

```python
from scipy import stats

# 智商測驗：平均 100、標準差 15
print("IQ 超過 130 的比例：", round(1 - stats.norm.cdf(130, 100, 15), 4))
print("前 1% 的 IQ 門檻：", round(stats.norm.ppf(0.99, 100, 15), 1))
```

## 機率在 AI 裡：softmax

分類模型最後一層會輸出一堆分數，用 **softmax** 轉換成加總為 1 的機率分布：

```python
import numpy as np

def softmax(scores):
    e = np.exp(scores - scores.max())     # 減掉最大值，避免數字太大溢位
    return e / e.sum()

labels = ["貓", "狗", "兔子"]
scores = np.array([3.2, 1.1, -0.5])        # 模型輸出的原始分數（logits）
probs = softmax(scores)
for label, p in zip(labels, probs):
    print(f"{label}：{p:.1%}")
print("總和：", probs.sum())
```

## 貝氏定理：用新證據更新機率

> 某疾病盛行率 1%。檢測準確率 99%（有病時 99% 測出陽性、沒病時 99% 測出陰性）。**測出陽性時，真的有病的機率是多少？**

```python
p_disease = 0.01
p_pos_given_disease = 0.99
p_pos_given_healthy = 0.01

p_pos = p_disease * p_pos_given_disease + (1 - p_disease) * p_pos_given_healthy
p_disease_given_pos = p_disease * p_pos_given_disease / p_pos
print(f"測出陽性時，真的有病的機率：{p_disease_given_pos:.1%}")

# 用模擬驗證
import numpy as np
rng = np.random.default_rng(0)
n = 1_000_000
sick = rng.random(n) < p_disease
positive = np.where(sick, rng.random(n) < 0.99, rng.random(n) < 0.01)
print(f"模擬結果：{sick[positive].mean():.1%}")
```

只有 50%！因為沒病的人太多了，就算只有 1% 誤判，人數也和真正有病的一樣多。這種直覺陷阱叫做「**基本率謬誤**」。垃圾郵件過濾器就是用貝氏定理運作的。

import numpy as np


def birthday_exact(n):
    p_unique = 1.0
    for i in range(n):
        p_unique *= (365 - i) / 365
    return 1 - p_unique


def birthday_sim(n, trials=20000):
    rng = np.random.default_rng(0)
    b = np.sort(rng.integers(0, 365, size=(trials, n)), axis=1)
    return (b[:, 1:] == b[:, :-1]).any(axis=1).mean()


min_n = next(n for n in range(1, 366) if birthday_exact(n) > 0.5)
print(birthday_exact(23), birthday_sim(23), min_n)
