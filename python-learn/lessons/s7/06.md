真實世界的資料**一定是髒的**：缺值、重複、格式不一致、打錯字、不合理的數字… 據說資料科學家 **80% 的時間在清理資料**。這一課用一份故意弄髒的客戶資料 `messy_customers.csv` 來練習。

```python
import pandas as pd

df = pd.read_csv("messy_customers.csv")
display(df)
df.info()
```

仔細看，你能找到幾個問題？

## 1. 缺值（Missing Values）

pandas 用 `NaN`（Not a Number）表示缺值：

```python
import pandas as pd

df = pd.read_csv("messy_customers.csv")
print(df.isna().sum())                 # 每一欄有幾個缺值
display(df[df["phone"].isna()])        # 哪幾列有缺值

print(df.dropna().shape)               # 刪掉任何有缺值的列
print(df.dropna(subset=["name"]).shape)   # 只看特定欄位
filled = df.fillna({"level": "一般", "phone": "未提供"})   # 填入預設值
display(filled.tail(3))
```

**刪除還是填補？**
- 缺值很少、資料很多 → 可以刪除
- 數值欄位 → 填**平均數**或**中位數**（中位數比較不受極端值影響）
- 類別欄位 → 填**最常見的值**或「未知」
- 時間序列 → 用前一個值填（`ffill`）或內插（`interpolate`）

## 2. 重複資料

```python
import pandas as pd

df = pd.read_csv("messy_customers.csv")
print(df.duplicated().sum(), "筆完全重複")
display(df[df.duplicated(keep=False)])           # 顯示所有重複的
df = df.drop_duplicates()
print(df["id"].duplicated().sum(), "個重複的 id")
```

## 3. 字串清理

```python
import pandas as pd

df = pd.read_csv("messy_customers.csv").drop_duplicates()
df["name"] = df["name"].str.strip()                           # 去空白
df["level"] = df["level"].str.strip().str.upper()             # 統一大小寫
df["city"] = df["city"].str.replace("臺", "台")                # 統一用字
df["phone"] = df["phone"].str.replace(r"[^0-9]", "", regex=True)   # 只保留數字
display(df[["name", "city", "phone", "level"]])
print(df["level"].value_counts(dropna=False))
```

## 4. 型別轉換

```python
import pandas as pd

df = pd.read_csv("messy_customers.csv").drop_duplicates()
print(df.dtypes)

df["age"] = pd.to_numeric(df["age"], errors="coerce")           # 轉不了的變成 NaN
df["joined"] = pd.to_datetime(df["joined"].str.replace("/", "-"), errors="coerce")
print(df.dtypes)
display(df[["id", "age", "joined"]])
```

`errors="coerce"` 很好用：遇到無法轉換的值（像 `"not a date"`）不會讓程式出錯，而是變成缺值，之後再一起處理。

## 5. 不合理的值（異常值）

```python
import pandas as pd

df = pd.read_csv("messy_customers.csv").drop_duplicates()
df["age"] = pd.to_numeric(df["age"], errors="coerce")
bad = df[(df["age"] < 0) | (df["age"] > 120)]
display(bad[["id", "name", "age"]])
df.loc[(df["age"] < 0) | (df["age"] > 120), "age"] = None   # 不合理的當作缺值
df["age"] = df["age"].fillna(df["age"].median())
print(df["age"].tolist())
```

### 用統計方法找異常值：IQR

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(0)
s = pd.Series(np.append(rng.normal(50, 10, 100), [150, -40, 180]))
q1, q3 = s.quantile(0.25), s.quantile(0.75)
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print(f"正常範圍：{low:.1f} ～ {high:.1f}")
print("異常值：", s[(s < low) | (s > high)].round(1).tolist())
```

## 完整的清理流程

把所有步驟寫成一個函式，以後新資料進來可以直接重複使用。善用**方法串接（method chaining）**：

```python
import pandas as pd

def clean_customers(path):
    df = (
        pd.read_csv(path)
        .drop_duplicates()
        .assign(
            name=lambda d: d["name"].str.strip(),
            city=lambda d: d["city"].str.replace("臺", "台"),
            phone=lambda d: d["phone"].str.replace(r"\D", "", regex=True),
            level=lambda d: d["level"].str.strip().str.upper().fillna("一般"),
            age=lambda d: pd.to_numeric(d["age"], errors="coerce"),
            joined=lambda d: pd.to_datetime(d["joined"].str.replace("/", "-"), errors="coerce"),
        )
    )
    df.loc[~df["age"].between(0, 120), "age"] = None
    df = df[df["name"].fillna("") != ""]                 # 沒有名字的資料刪除
    df["phone"] = df["phone"].replace("", None)
    return df.reset_index(drop=True)

clean = clean_customers("messy_customers.csv")
display(clean)
print(clean.isna().sum())
```

import pandas as pd

raw = pd.DataFrame({
    "product": [" 筆電", "滑鼠 ", "鍵盤", "鍵盤", "螢幕", "耳機"],
    "price": ["32000", "590", "1990", "1990", "免費", "1290"],
    "qty": [1, None, 2, 2, 1, None],
})


def clean(raw):
    df = raw.drop_duplicates().copy()
    df["product"] = df["product"].str.strip()
    df["price"] = pd.to_numeric(df["price"], errors="coerce")
    df = df.dropna(subset=["price"])
    df["qty"] = df["qty"].fillna(1).astype(int)
    return df.reset_index(drop=True)


display(clean(raw))
