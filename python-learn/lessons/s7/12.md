## Step 3：營收儀表板

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
```

## Step 5：客戶分析（RFM）

**RFM** 是行銷常用的客戶分群方法：
- **R**ecency：最近一次購買距今多久
- **F**requency：購買次數
- **M**onetary：總消費金額

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]
today = df["date"].max() + pd.Timedelta(days=1)

rfm = df.groupby("customer").agg(
    R=("date", lambda d: (today - d.max()).days),
    F=("order_id", "count"),
    M=("revenue", "sum"),
)
rfm["R分"] = pd.qcut(rfm["R"], 3, labels=[3, 2, 1]).astype(int)            # 越近越高分
rfm["F分"] = pd.qcut(rfm["F"].rank(method="first"), 3, labels=[1, 2, 3]).astype(int)
rfm["M分"] = pd.qcut(rfm["M"], 3, labels=[1, 2, 3]).astype(int)

def segment(row):
    if row["R分"] == 3 and row["F分"] >= 2 and row["M分"] >= 2:
        return "💎 忠實客戶"
    if row["R分"] == 1 and row["M分"] >= 2:
        return "⚠️ 流失中的大客戶"
    if row["R分"] == 3:
        return "🌱 新客／活躍客"
    return "😴 一般客戶"

rfm["分群"] = rfm.apply(segment, axis=1)
summary = rfm.groupby("分群").agg(人數=("M", "size"), 平均消費=("M", "mean"), 平均次數=("F", "mean")).round(0)
display(summary.sort_values("平均消費", ascending=False))
```

## Step 6：寫結論

分析的價值在於**行動建議**。好的結論要：**具體、有數字、可以執行**。

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]
m = df.groupby(df["date"].dt.month)["revenue"].sum()
city = df.groupby("city")["revenue"].sum()
cat = df.groupby("category")["revenue"].sum()
top_product = df.groupby("product")["revenue"].sum().idxmax()

q4_share = m.loc[11:12].sum() / m.sum()
print("📋 分析結論")
print(f"1. 11–12 月貢獻全年 {q4_share:.0%} 營收（兩個月占 1/6 的時間），年底檔期是重點。")
print(f"2. {city.idxmax()}營收最高（占 {city.max() / city.sum():.0%}），{city.idxmin()}最低，可以評估地區性促銷。")
print(f"3. {cat.idxmax()} 類別營收最高；單品冠軍是「{top_product}」，建議確保年底庫存。")
print("4. 建議：針對「流失中的大客戶」發送回購優惠券。")
```
