資料分析最常問的問題是：「**每個 ○○ 的 △△ 是多少？**」每個城市的營收、每個月的訂單數、每個類別的平均價格… 這就是 **groupby**。

## groupby：分組統計

概念是 **Split → Apply → Combine**：依照某個欄位**分組**，對每組**計算**，再**合併**結果。

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
df["revenue"] = df["price"] * df["qty"]

print(df.groupby("city")["revenue"].sum().sort_values(ascending=False))
print(df.groupby("category")["qty"].mean().round(2))
print(df.groupby("city").size())       # 每組幾筆
```

## agg：一次算多種統計

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
df["revenue"] = df["price"] * df["qty"]

summary = df.groupby("category").agg(
    訂單數=("order_id", "count"),
    總營收=("revenue", "sum"),
    平均單價=("price", "mean"),
    最大數量=("qty", "max"),
    客戶數=("customer", "nunique"),
).round(0).sort_values("總營收", ascending=False)
display(summary)
```

## 多個欄位分組

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
df["revenue"] = df["price"] * df["qty"]
r = df.groupby(["city", "category"])["revenue"].sum()
print(r.head(8))
display(r.unstack(fill_value=0))     # 把第二層索引轉成欄位 → 交叉表
```

## 時間序列分組

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]
df["month"] = df["date"].dt.to_period("M")
monthly = df.groupby("month")["revenue"].sum()
print(monthly)
print("營收最高的月份：", monthly.idxmax())

weekly = df.set_index("date").resample("W")["revenue"].sum()   # resample：依時間重新取樣
print(weekly.head())
```

## pivot_table：樞紐分析表

就是 Excel 的樞紐分析表：

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]
df["quarter"] = "Q" + df["date"].dt.quarter.astype(str)
pt = pd.pivot_table(
    df, values="revenue", index="category", columns="quarter",
    aggfunc="sum", margins=True, margins_name="合計",
)
display(pt)
```

## transform：在原本的表格加上分組結果

`agg` 會把每組**壓縮成一列**；`transform` 則保持原本的列數，適合計算「**占同組的比例**」、「**和組平均的差距**」：

```python
import pandas as pd

df = pd.read_csv("students.csv")
df["gender_avg"] = df.groupby("gender")["final_score"].transform("mean").round(1)
df["diff"] = df["final_score"] - df["gender_avg"]
display(df[["student_id", "gender", "final_score", "gender_avg", "diff"]].head())
```

## 合併資料：merge

資料常常分散在不同的表格（就像資料庫）。用 `merge` 依照共同欄位合併：

```python
import pandas as pd

orders = pd.DataFrame({
    "order_id": [1, 2, 3, 4],
    "customer_id": ["C1", "C2", "C1", "C9"],
    "amount": [300, 150, 800, 50],
})
customers = pd.DataFrame({
    "customer_id": ["C1", "C2", "C3"],
    "name": ["小明", "小美", "阿華"],
    "level": ["VIP", "一般", "一般"],
})
print("inner（兩邊都有的）：")
display(pd.merge(orders, customers, on="customer_id"))
print("left（保留所有訂單）：")
display(pd.merge(orders, customers, on="customer_id", how="left"))
print("outer（全部保留）：")
display(pd.merge(orders, customers, on="customer_id", how="outer"))
```

| how | 保留 |
|---|---|
| `inner`（預設） | 兩邊都有的 |
| `left` | 左邊全部，右邊對不到的填 NaN |
| `right` | 右邊全部 |
| `outer` | 全部 |

## 疊加資料：concat

```python
import pandas as pd

jan = pd.DataFrame({"商品": ["A", "B"], "銷量": [10, 20]})
feb = pd.DataFrame({"商品": ["A", "C"], "銷量": [15, 5]})
all_months = pd.concat([jan.assign(月份=1), feb.assign(月份=2)], ignore_index=True)
display(all_months)
display(all_months.pivot(index="商品", columns="月份", values="銷量"))
```
