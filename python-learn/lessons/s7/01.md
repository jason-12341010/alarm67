歡迎來到 **AI 與數據路線**！🎉 這條路線的第一站是 **NumPy**（Numerical Python）。它是 Python 科學運算的地基：pandas、scikit-learn、PyTorch、TensorFlow… **全部都建立在 NumPy 之上**。

> 💡 第一次執行 NumPy 程式時，瀏覽器要下載套件，大約需要 5～10 秒。

## 為什麼不用 list？

```python
import numpy as np

prices = [100, 200, 300]
print(prices * 2)                 # list：重複兩次
arr = np.array([100, 200, 300])
print(arr * 2)                    # NumPy：每個元素乘以 2
print(arr * 1.05 + 10)            # 一次對所有元素做運算
```

NumPy 陣列：
- **快**：底層用 C 實作，比 Python 迴圈快 10～100 倍
- **省記憶體**：所有元素是同一種型別，緊密排列
- **方便**：數學運算直接寫，不用迴圈

## 建立陣列

```python
import numpy as np

a = np.array([1, 2, 3, 4])
print(a, a.dtype)                         # dtype：元素的型別

print(np.zeros(5))                        # 全部是 0
print(np.ones((2, 3)))                    # 2 列 3 行，全部是 1
print(np.arange(0, 10, 2))                # 像 range，但回傳陣列
print(np.linspace(0, 1, 5))               # 0 到 1 之間平均切 5 個點
print(np.full((2, 2), 7))
print(np.eye(3))                          # 單位矩陣
```

## 隨機陣列

```python
import numpy as np

rng = np.random.default_rng(42)           # 建議的新寫法：建立隨機數產生器
print(rng.integers(1, 7, size=10))        # 擲骰子 10 次
print(rng.random(3))                      # 0～1 的小數
print(rng.normal(170, 8, size=5).round(1))  # 常態分布：平均 170、標準差 8
print(rng.choice(["剪刀", "石頭", "布"], size=5))
```

## 多維陣列

```python
import numpy as np

m = np.array([[1, 2, 3],
              [4, 5, 6]])
print(m)
print("形狀 shape：", m.shape)      # (列數, 行數)
print("維度 ndim：", m.ndim)
print("元素個數 size：", m.size)
```

在 AI 裡，資料幾乎都是多維陣列（也叫**張量 tensor**）：

| 資料 | 形狀 |
|---|---|
| 一個學生的 5 科成績 | `(5,)` |
| 100 個學生的 5 科成績 | `(100, 5)` |
| 一張 28×28 的灰階圖片 | `(28, 28)` |
| 一張 224×224 的彩色圖片 | `(224, 224, 3)` |
| 32 張彩色圖片（一個批次） | `(32, 224, 224, 3)` |

## 改變形狀

```python
import numpy as np

a = np.arange(12)
print(a)
print(a.reshape(3, 4))
print(a.reshape(2, -1))            # -1：自動計算
b = a.reshape(3, 4)
print(b.T)                         # 轉置（列和行交換）
print(b.flatten())                 # 攤平成一維
```

## 索引與切片

```python
import numpy as np

m = np.arange(1, 13).reshape(3, 4)
print(m)
print(m[0, 2])          # 第 0 列第 2 行（不用寫 m[0][2]）
print(m[1])             # 第 1 列
print(m[:, 0])          # 所有列的第 0 行（整個「行」）
print(m[:2, 1:3])       # 前 2 列，第 1～2 行
print(m[-1, ::-1])      # 最後一列，反過來
```

## 布林索引：篩選資料（超常用！）

```python
import numpy as np

scores = np.array([45, 82, 67, 90, 38, 75, 58])
print(scores > 60)                   # 每個元素比較，得到布林陣列
print(scores[scores > 60])           # 只留下 True 的位置
print(scores[(scores >= 60) & (scores < 80)])   # 多個條件用 & |，每個條件要加括號
print((scores >= 60).sum(), "人及格")            # True 當 1、False 當 0
scores[scores < 60] = 60             # 把不及格的改成 60
print(scores)
```

> ⚠️ NumPy 的「且」「或」要用 `&` `|`，不能用 `and` `or`，而且每個條件都要**加括號**。

## 統計函式

```python
import numpy as np

data = np.array([[80, 90, 70],
                 [60, 75, 85],
                 [95, 88, 92]])     # 3 個學生 × 3 科
print("總平均：", data.mean())
print("每科平均（沿著列，axis=0）：", data.mean(axis=0))
print("每人平均（沿著行，axis=1）：", data.mean(axis=1).round(1))
print("最高分：", data.max(), "在位置", np.unravel_index(data.argmax(), data.shape))
print("標準差：", data.std().round(2))
print("每科最高分的學生：", data.argmax(axis=0))
```

> 💡 `axis=0` 是「**跨列**」計算（對每一行做統計，結果每一行一個值）；`axis=1` 是「**跨行**」計算（對每一列做統計）。記法：axis 是**會被壓縮掉**的那個維度。
