**pandas** 是 Python 處理**表格資料**的標準工具，就像程式版的 Excel，但更強大：幾百萬筆資料也能輕鬆處理。資料分析師、資料科學家每天都在用。

```python
import pandas as pd
print(pd.__version__)
```

## Series：一欄資料

Series 是**帶有標籤（index）的一維陣列**：

```python
import pandas as pd

sales = pd.Series([120, 95, 140, 88], index=["一月", "二月", "三月", "四月"], name="銷售量")
print(sales)
print(sales["三月"], sales.iloc[0])      # 用標籤或位置取值
print(sales[sales > 100])                # 布林篩選，跟 NumPy 一樣
print(sales.mean(), sales.max(), sales.idxmax())
print((sales * 1.1).round())             # 向量化運算
```

## DataFrame：整張表格

DataFrame 是**由多個 Series 組成的表格**，每一欄可以是不同的型別：

```python
import pandas as pd

df = pd.DataFrame({
    "姓名": ["小明", "小美", "阿華", "小強", "小芳"],
    "年齡": [18, 17, 19, 18, 17],
    "城市": ["台北", "台中", "台北", "高雄", "台中"],
    "分數": [85, 92, 78, 65, 88],
})
display(df)                      # display 會顯示成漂亮的表格
print(df.shape)                  # (列數, 欄數)
print(df.columns.tolist())
print(df.dtypes)
```

> 💡 在這個網站和 Jupyter 裡，用 `display(df)` 會顯示成表格；用 `print(df)` 是純文字。在一般的 `.py` 檔裡只能用 `print`。

## 快速認識資料

拿到新資料時，第一件事就是這幾招：

```python
import pandas as pd

df = pd.read_csv("students.csv")     # 讀取課程提供的練習資料
display(df.head())                   # 前 5 筆
print(df.tail(3))                    # 最後 3 筆
df.info()                            # 欄位、型別、缺值
display(df.describe().round(1))      # 數值欄位的統計摘要
```

## 選取欄位

```python
import pandas as pd

df = pd.read_csv("students.csv")
print(df["final_score"].head())               # 一欄 → Series
display(df[["student_id", "final_score"]].head(3))   # 多欄 → DataFrame（注意兩層中括號）
print(df.final_score.mean())                  # 欄位名稱是英文時也可以用 .
```

## 選取列：loc 和 iloc

| 方法 | 用什麼選 | 例子 |
|---|---|---|
| `df.loc[...]` | **標籤**（index 名稱、欄位名稱） | `df.loc[0, "name"]` |
| `df.iloc[...]` | **位置**（第幾列、第幾欄，從 0 開始） | `df.iloc[0, 1]` |

```python
import pandas as pd

df = pd.DataFrame(
    {"分數": [85, 92, 78], "城市": ["台北", "台中", "台北"]},
    index=["小明", "小美", "阿華"],
)
print(df.loc["小美"])                     # 一列
print(df.loc["小美", "分數"])              # 一格
print(df.loc[["小明", "阿華"], "城市"])
print(df.iloc[0])                          # 第 0 列
print(df.iloc[:2, 0])                      # 前兩列的第 0 欄
print(df.loc[df["分數"] > 80, "城市"])     # 條件 + 欄位（最常用的寫法）
```

## 新增、修改、刪除欄位

```python
import pandas as pd

df = pd.DataFrame({"商品": ["筆", "本子", "書包"], "單價": [20, 45, 890], "數量": [10, 5, 1]})
df["小計"] = df["單價"] * df["數量"]                  # 新增欄位：向量化計算
df["含稅"] = (df["小計"] * 1.05).round().astype(int)
df["等級"] = df["小計"].apply(lambda x: "高" if x > 200 else "低")   # 套用自訂函式
df = df.rename(columns={"商品": "品名"})
df = df.drop(columns=["含稅"])
display(df)
print("總金額：", df["小計"].sum())
```

## 排序

## 常用的 Series 方法

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
print(df["city"].unique())              # 有哪些值
print(df["city"].nunique(), "個城市")
print(df["city"].value_counts())        # 每個值出現幾次（超常用！）
print(df["category"].value_counts(normalize=True).round(3))   # 比例
```
