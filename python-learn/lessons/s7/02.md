## 向量化：告別迴圈

**向量化（vectorization）** 是指：用**整個陣列的運算**取代 Python 的 for 迴圈。這是資料科學和 AI 最重要的效能技巧。

```python
import numpy as np
import time

n = 1_000_000
heights = np.random.default_rng(0).normal(165, 10, n)   # 公分
weights = np.random.default_rng(1).normal(60, 12, n)    # 公斤

t = time.perf_counter()
bmi_loop = [w / (h / 100) ** 2 for h, w in zip(heights, weights)]
print(f"迴圈：{(time.perf_counter() - t) * 1000:.0f} ms")

t = time.perf_counter()
bmi_vec = weights / (heights / 100) ** 2               # 整個陣列一次算
print(f"向量化：{(time.perf_counter() - t) * 1000:.1f} ms")
print(np.allclose(bmi_loop, bmi_vec))
```

## 元素對元素（element-wise）運算

形狀相同的陣列，運算會**一個對一個**進行：

```python
import numpy as np

price = np.array([100, 250, 80])
qty = np.array([3, 1, 5])
print(price * qty)                  # 每個商品的小計
print((price * qty).sum())          # 總金額
print(np.sqrt([4, 9, 16]), np.exp([0, 1]), np.log([1, np.e]))
print(np.round(np.array([1.234, 5.678]), 1))
print(np.maximum(np.array([3, 8, 1]), 5))    # 每個元素和 5 比，取較大的
```

## 向量化的條件判斷：np.where

```python
import numpy as np

scores = np.array([45, 82, 67, 90, 38])
print(np.where(scores >= 60, "及格", "不及格"))
print(np.where(scores >= 60, scores, scores + 10))   # 不及格的加 10 分

temps = np.array([12, 18, 25, 31, 35])
labels = np.select(
    [temps < 15, temps < 25, temps < 32],
    ["冷", "舒適", "熱"],
    default="酷熱",
)
print(labels)
```

## 廣播（Broadcasting）

形狀**不同**的陣列也能運算！NumPy 會自動把小的「**延伸**」成跟大的一樣：

```python
import numpy as np

a = np.array([[1, 2, 3],
              [4, 5, 6]])     # 形狀 (2, 3)
print(a + 10)                 # 純量：延伸到每個元素
print(a + np.array([10, 20, 30]))        # (3,) → 延伸到每一列
print(a + np.array([[100], [200]]))      # (2, 1) → 延伸到每一行
```

```text
規則：從最後一個維度開始比較，每個維度必須「相等」或「其中一個是 1」

(2, 3) + (3,)    → (2, 3) + (1, 3) → ✅ (2, 3)
(2, 3) + (2, 1)  → ✅ (2, 3)
(2, 3) + (2,)    → 3 和 2 不相等，也都不是 1 → ❌ 錯誤
```

```python
import numpy as np

a = np.ones((2, 3))
b = np.array([1, 2])
print(a + b)       # 形狀不相容 → ValueError
```

## 廣播的實際應用：標準化

機器學習前常常要把每個特徵**標準化**（減掉平均、除以標準差），讓不同單位的資料可以比較：

```python
import numpy as np

# 5 個人的 [身高(cm), 體重(kg), 年收入(萬)]
X = np.array([
    [170, 65, 60],
    [160, 50, 45],
    [180, 80, 120],
    [175, 70, 80],
    [165, 55, 50],
], dtype=float)

mean = X.mean(axis=0)          # 每個特徵的平均，形狀 (3,)
std = X.std(axis=0)
X_std = (X - mean) / std       # (5, 3) 和 (3,) 廣播
print("平均：", mean)
print(X_std.round(2))
print("標準化後的平均：", X_std.mean(axis=0).round(10))
print("標準化後的標準差：", X_std.std(axis=0))
```

## 距離計算：廣播的威力

計算每個點到每個點的距離（KNN、分群演算法的核心），**完全不用迴圈**：

```python
import numpy as np

points = np.array([[0, 0], [3, 4], [6, 8], [1, 1]])
diff = points[:, None, :] - points[None, :, :]    # (4,1,2) - (1,4,2) → (4,4,2)
dist = np.sqrt((diff ** 2).sum(axis=-1))
print(dist.round(2))
print("離 (0,0) 最近的其他點：", points[np.argsort(dist[0])[1]])
```

`None`（也可以寫 `np.newaxis`）會插入一個長度 1 的新維度，讓廣播可以運作。

## 矩陣乘法

神經網路的核心運算就是**矩陣乘法**，用 `@` 運算子：

```python
import numpy as np

# 3 道料理 × 2 種食材的用量
recipes = np.array([[2, 1],     # 料理 A：2 份番茄、1 份蛋
                    [0, 3],     # 料理 B：3 份蛋
                    [1, 2]])
cost = np.array([15, 8])         # 番茄 15 元、蛋 8 元
print(recipes @ cost)            # 每道料理的成本

W = np.array([[0.2, 0.8],
              [0.5, 0.5],
              [0.9, 0.1]])       # (3, 2)
x = np.array([1.0, 2.0])         # (2,)
print(W @ x)                     # (3, 2) @ (2,) → (3,)：這就是一層神經網路！
```

import numpy as np

X = np.array([
    [25, 5, 300],
    [40, 20, 800],
    [32, 8, 450],
    [18, 30, 1200],
], dtype=float)
new = np.array([30, 10, 500], dtype=float)

mean, std = X.mean(axis=0), X.std(axis=0)
X_std = (X - mean) / std
new_std = (new - mean) / std
dist = np.sqrt(((X_std - new_std) ** 2).sum(axis=1))
nearest = dist.argmin()
print(dist.round(3), nearest)
