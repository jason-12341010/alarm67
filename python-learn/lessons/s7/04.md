這一課用一個模擬的網路商店訂單資料 `shop_orders.csv`（600 筆，2025 年整年），練習最常用的**讀取和篩選**技巧。

## 讀取資料

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
display(df.head())
print(df.shape)
df.info()
```

`read_csv` 常用參數：

```py
pd.read_csv(
    "data.csv",
    encoding="utf-8",           # Excel 存的中文 CSV 常常是 "big5" 或 "utf-8-sig"
    sep=",",                    # 分隔符號，Tab 分隔用 "\t"
    usecols=["a", "b"],         # 只讀取部分欄位
    parse_dates=["date"],       # 自動轉成日期
    dtype={"zip": str},         # 指定型別（郵遞區號開頭的 0 才不會消失）
    na_values=["-", "N/A"],     # 哪些值要當作缺值
    nrows=1000,                 # 只讀前 1000 筆（資料很大時先試試看）
)
pd.read_excel("data.xlsx", sheet_name="工作表1")   # 讀 Excel（需要 openpyxl）
pd.read_json("data.json")
```

## 條件篩選

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")

taipei = df[df["city"] == "台北"]
print("台北的訂單：", len(taipei))

big = df[(df["price"] >= 1000) & (df["qty"] >= 3)]      # 且：&
display(big.head())

north = df[df["city"].isin(["台北", "新北", "桃園"])]    # 屬於某幾個值
print("北部訂單：", len(north))

not_food = df[~(df["category"] == "食品")]               # 不是：~
print("非食品：", len(not_food))
```

> ⚠️ 跟 NumPy 一樣：用 `&` `|` `~`，每個條件都要**加括號**。

## query：更好讀的篩選

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
r = df.query("city == '台中' and price > 1000 and qty >= 2")
display(r)

min_price = 2000
display(df.query("price >= @min_price").head(3))     # 用 @ 引用變數
```

## 字串篩選：.str

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
display(df[df["product"].str.contains("鍵盤|滑鼠")].head())     # 支援正規表示式
print(df[df["product"].str.startswith("USB")]["product"].unique())
print(df["product"].str.len().max(), "是最長的商品名稱長度")
```

## 日期資料

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
print(df["date"].dtype)
df["month"] = df["date"].dt.month              # .dt 取出日期的各個部分
df["weekday"] = df["date"].dt.day_name()
display(df[["date", "month", "weekday"]].head(3))

q4 = df[df["date"] >= "2025-10-01"]            # 日期可以直接和字串比較
print("第四季訂單：", len(q4))
nov = df[df["date"].dt.month == 11]
print("11 月訂單：", len(nov))
print(df["weekday"].value_counts())
```

## 計算欄位 + 篩選

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]
print(f"全年營收：{df['revenue'].sum():,} 元")
print(f"平均客單價：{df['revenue'].mean():,.0f} 元")
top10 = df.nlargest(10, "revenue")[["order_id", "date", "product", "revenue"]]
display(top10)
```

## 選取 + 存檔

```python
import pandas as pd

df = pd.read_csv("shop_orders.csv")
vip = df[df["price"] * df["qty"] > 5000]
vip.to_csv("vip_orders.csv", index=False)     # index=False：不要把索引存進去
print(open("vip_orders.csv", encoding="utf-8").read()[:300])
```

> 💡 要讓 Excel 正確顯示中文，存檔時用 `encoding="utf-8-sig"`。
