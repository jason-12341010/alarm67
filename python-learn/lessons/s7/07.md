「一張圖勝過千言萬語」。**Matplotlib** 是 Python 最基本的繪圖套件，pandas 和 seaborn 的繪圖功能都建立在它上面。

## 第一張圖

```python
import matplotlib.pyplot as plt

months = ["1月", "2月", "3月", "4月", "5月", "6月"]
sales = [120, 135, 98, 160, 175, 190]

plt.plot(months, sales, marker="o")
plt.title("上半年銷售量")
plt.xlabel("月份")
plt.ylabel("銷售量（件）")
plt.grid(alpha=0.3)
plt.show()
```

## 常用圖表

| 想表達什麼 | 用什麼圖 | 函式 |
|---|---|---|
| 隨時間的**變化趨勢** | 折線圖 | `plt.plot` |
| 不同類別的**比較** | 長條圖 | `plt.bar` / `plt.barh` |
| 數值的**分布** | 直方圖 | `plt.hist` |
| 兩個變數的**關係** | 散佈圖 | `plt.scatter` |
| **組成比例**（類別少時） | 圓餅圖 | `plt.pie` |
| 分布的**比較、異常值** | 箱型圖 | `plt.boxplot` |

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(1)
fig, axes = plt.subplots(2, 2, figsize=(10, 7))     # 2×2 的子圖

axes[0, 0].bar(["台北", "台中", "高雄"], [320, 180, 210], color=["#3776ab", "#ffd43b", "#4b8bbe"])
axes[0, 0].set_title("長條圖：各地區營收")

axes[0, 1].hist(rng.normal(165, 8, 500), bins=25, color="#4b8bbe", edgecolor="white")
axes[0, 1].set_title("直方圖：身高分布")

x = rng.uniform(0, 10, 80)
axes[1, 0].scatter(x, 3 * x + rng.normal(0, 4, 80), alpha=0.7)
axes[1, 0].set_title("散佈圖：讀書時間 vs 分數")

axes[1, 1].pie([45, 30, 15, 10], labels=["3C", "服飾", "食品", "其他"], autopct="%1.0f%%", startangle=90)
axes[1, 1].set_title("圓餅圖：營收占比")

fig.tight_layout()                                   # 自動調整間距，避免文字重疊
plt.show()
```

## 兩種寫法：plt 和 fig, ax

- **`plt.xxx()`**：快速、簡單，適合單張圖
- **`fig, ax = plt.subplots()`**：物件導向寫法，可以精確控制每一張子圖，**正式的程式建議用這種**

```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 2 * np.pi, 100)
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(x, np.sin(x), label="sin(x)", linewidth=2)
ax.plot(x, np.cos(x), label="cos(x)", linestyle="--")
ax.axhline(0, color="gray", linewidth=0.8)
ax.set(title="三角函數", xlabel="x", ylabel="y")
ax.legend()                                  # 圖例（用到 label）
ax.annotate("最高點", xy=(np.pi / 2, 1), xytext=(2.5, 0.7), arrowprops=dict(arrowstyle="->"))
plt.show()
```

## 用 pandas 直接畫圖

DataFrame 和 Series 都有 `.plot()`，資料分析時最方便：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("taipei_weather.csv", parse_dates=["date"])
df["month"] = df["date"].dt.month
monthly = df.groupby("month").agg(平均氣溫=("temp_avg", "mean"), 雨量=("rain_mm", "sum"))

fig, ax1 = plt.subplots(figsize=(9, 4))
monthly["雨量"].plot(kind="bar", ax=ax1, color="#9ec5e8", label="雨量")
ax1.set_ylabel("月雨量（mm）")
ax2 = ax1.twinx()                                # 共用 x 軸的第二個 y 軸
ax2.plot(range(12), monthly["平均氣溫"], color="#e4572e", marker="o", label="平均氣溫")
ax2.set_ylabel("平均氣溫（°C）")
ax1.set_title("台北 2025 每月氣溫與雨量（模擬資料）")
ax1.set_xlabel("月份")
plt.show()
```

## 讓圖表更好讀

好的圖表原則：
1. **標題和座標軸標籤**一定要有，要寫單位
2. 長條圖**由大到小排序**，比較容易比較
3. **少即是多**：去掉不必要的格線、邊框、3D 效果
4. 顏色有意義：用**一個強調色**標出重點，其他用灰色

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("shop_orders.csv")
df["revenue"] = df["price"] * df["qty"]
s = df.groupby("product")["revenue"].sum().nlargest(8).sort_values()

colors = ["#c8ccd4"] * (len(s) - 1) + ["#3776ab"]     # 只強調第一名
fig, ax = plt.subplots(figsize=(8, 4.5))
bars = ax.barh(s.index, s.values, color=colors)
ax.bar_label(bars, labels=[f"{v/1000:.0f}K" for v in s.values], padding=4)
ax.spines[["top", "right"]].set_visible(False)      # 去掉上方和右方的框線
ax.set_title("營收前 8 名商品", loc="left", fontsize=14, fontweight="bold")
ax.set_xlabel("營收（元）")
plt.show()
```
