**Seaborn** 建立在 Matplotlib 之上，專門用來畫**統計圖表**。它的特色是：**一行程式就能畫出漂亮的圖**，而且直接吃 pandas 的 DataFrame。

> 💡 這個網站第一次使用 seaborn 時，會從 PyPI 自動下載安裝，需要多等幾秒。在自己的電腦上：`pip install seaborn`

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("students.csv")
sns.histplot(data=df, x="final_score", hue="gender", kde=True)   # kde：平滑的分布曲線
plt.title("期末成績分布")
plt.show()
```

## 習慣用法

Seaborn 的函式都長得很像：`sns.圖表(data=DataFrame, x="欄位", y="欄位", hue="分組欄位")`

`hue` 是 seaborn 的精髓：**用顏色區分不同的組別**，一個參數就能做分組比較。

## 分布：直方圖、KDE、箱型圖、小提琴圖

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("titanic.csv")
fig, axes = plt.subplots(1, 3, figsize=(13, 4))
sns.histplot(data=df, x="Age", bins=30, ax=axes[0])
axes[0].set_title("年齡分布")
sns.boxplot(data=df, x="Pclass", y="Fare", ax=axes[1])
axes[1].set_title("各艙等票價（箱型圖）")
axes[1].set_ylim(0, 200)
sns.violinplot(data=df, x="Sex", y="Age", hue="Survived", split=True, ax=axes[2])
axes[2].set_title("性別、年齡與生還")
fig.tight_layout()
plt.show()
```

### 看懂箱型圖

```text
     ○  ← 異常值（超過 1.5 倍 IQR）
     ┬  ← 最大值（排除異常值）
   ┌─┴─┐
   │   │ ← 第 3 四分位數（Q3，75%）
   ├───┤ ← 中位數（50%）
   │   │ ← 第 1 四分位數（Q1，25%）
   └─┬─┘
     ┴  ← 最小值
```

## 類別比較：barplot、countplot

`barplot` 會自動計算**平均值**和**信賴區間**（黑色的線）：

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("titanic.csv")
fig, axes = plt.subplots(1, 2, figsize=(11, 4))
sns.countplot(data=df, x="Pclass", hue="Survived", ax=axes[0])
axes[0].set_title("各艙等的生還人數")
sns.barplot(data=df, x="Sex", y="Survived", hue="Pclass", ax=axes[1])
axes[1].set_title("生還率：性別 × 艙等")
axes[1].set_ylabel("生還率")
fig.tight_layout()
plt.show()
```

這張圖已經透露很多資訊：**女性、頭等艙**的生還率遠高於其他人。第 8 階段我們會用機器學習預測誰能生還！

## 熱力圖：相關係數矩陣

一眼看出**哪些變數之間有關係**（下兩課會詳細解釋相關係數）：

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("students.csv")
corr = df.select_dtypes("number").corr()
plt.figure(figsize=(8, 6))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="RdBu_r", vmin=-1, vmax=1, square=True)
plt.title("學生資料的相關係數")
plt.show()
```

## pairplot：一次看所有變數的兩兩關係

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("students.csv")
cols = ["study_hours", "sleep_hours", "phone_hours", "final_score", "passed"]
sns.pairplot(df[cols], hue="passed", corner=True, plot_kws={"alpha": 0.5, "s": 15})
plt.show()
```

拿到新資料集時，`pairplot` 和 `heatmap` 是最快了解資料的方法。

## 主題與調色盤

```python
import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("shop_orders.csv")
df["revenue"] = df["price"] * df["qty"]
sns.set_theme(style="whitegrid", font="Noto Sans TC")    # 網頁版的中文字型名稱
sns.boxplot(data=df, x="category", y="revenue", hue="category", palette="Set2", legend=False)

plt.ylabel("訂單金額（元）")
plt.show()
sns.reset_defaults()
```
