兩個變數之間有沒有關係？讀書時間越長，成績越好嗎？房子越大，價格越高嗎？**相關係數**可以用一個數字回答。

## 皮爾森相關係數（r）

範圍是 **−1 到 1**：

| r | 意思 |
|---|---|
| 接近 +1 | 強烈**正相關**：一個變大，另一個也變大 |
| 接近 0 | 沒有**線性**關係 |
| 接近 −1 | 強烈**負相關**：一個變大，另一個變小 |

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)
x = rng.normal(0, 1, 200)
fig, axes = plt.subplots(1, 5, figsize=(15, 3))
for ax, target in zip(axes, [0.95, 0.6, 0, -0.6, -0.95]):
    y = target * x + np.sqrt(1 - target ** 2) * rng.normal(0, 1, 200)
    r = np.corrcoef(x, y)[0, 1]
    ax.scatter(x, y, s=8, alpha=0.6)
    ax.set_title(f"r = {r:.2f}")
    ax.set_xticks([]); ax.set_yticks([])
fig.tight_layout()
plt.show()
```

## ⚠️ 相關係數的陷阱

### 1. 相關 ≠ 因果

冰淇淋銷量和溺水人數高度相關，是因為吃冰淇淋會溺水嗎？不是，是因為**夏天**（第三個變數，叫做**干擾因子**）同時讓兩者增加：

```python
import numpy as np

rng = np.random.default_rng(1)
temperature = rng.uniform(15, 35, 100)                     # 干擾因子
ice_cream = 20 * temperature + rng.normal(0, 40, 100)
drowning = 0.3 * temperature + rng.normal(0, 1.5, 100)
print("冰淇淋 vs 溺水：r =", round(np.corrcoef(ice_cream, drowning)[0, 1], 2))
```

要證明因果關係，需要**隨機對照實驗**（A/B 測試）。

### 2. 只能偵測「線性」關係

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-3, 3, 100)
y = x ** 2                       # 完美的關係，但是曲線
print("r =", round(np.corrcoef(x, y)[0, 1], 3))   # 接近 0！
plt.scatter(x, y, s=10)
plt.title("關係很明顯，但相關係數是 0")
plt.show()
```

**一定要畫圖！** 下面四組資料的平均、變異數、相關係數幾乎一模一樣，但長相完全不同（Anscombe's quartet）：

```python
import numpy as np
import matplotlib.pyplot as plt

x = [10, 8, 13, 9, 11, 14, 6, 4, 12, 7, 5]
data = {
    "I": (x, [8.04, 6.95, 7.58, 8.81, 8.33, 9.96, 7.24, 4.26, 10.84, 4.82, 5.68]),
    "II": (x, [9.14, 8.14, 8.74, 8.77, 9.26, 8.10, 6.13, 3.10, 9.13, 7.26, 4.74]),
    "III": (x, [7.46, 6.77, 12.74, 7.11, 7.81, 8.84, 6.08, 5.39, 8.15, 6.42, 5.73]),
    "IV": ([8] * 7 + [19] + [8] * 3, [6.58, 5.76, 7.71, 8.84, 8.47, 7.04, 5.25, 12.50, 5.56, 7.91, 6.89]),
}
fig, axes = plt.subplots(1, 4, figsize=(15, 3.2), sharey=True)
for ax, (name, (xs, ys)) in zip(axes, data.items()):
    ax.scatter(xs, ys)
    ax.set_title(f"{name}：平均 {np.mean(ys):.2f}，r = {np.corrcoef(xs, ys)[0, 1]:.3f}")
fig.tight_layout()
plt.show()
```

### 3. 對異常值很敏感

```python
import numpy as np

x = np.arange(1, 11)
y = np.array([5, 4, 6, 5, 4, 6, 5, 4, 5, 50])   # 最後一個是異常值
print("有異常值：", round(np.corrcoef(x, y)[0, 1], 2))
print("去掉異常值：", round(np.corrcoef(x[:-1], y[:-1])[0, 1], 2))
from scipy import stats
print("Spearman（用排名計算，比較不受異常值影響）：", round(stats.spearmanr(x, y)[0], 2))
```

## 簡單線性迴歸：畫出最佳的直線

相關係數告訴我們「有沒有關係」，**迴歸**更進一步告訴我們「**關係是多少**」：讀書時間多 1 小時，成績平均多幾分？

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("students.csv")
x, y = df["study_hours"], df["final_score"]
slope, intercept = np.polyfit(x, y, 1)                # 一次多項式 = 直線
print(f"成績 ≈ {slope:.2f} × 讀書時數 + {intercept:.2f}")
print(f"每多讀 1 小時，成績平均多 {slope:.2f} 分")

r = x.corr(y)
print(f"r = {r:.3f}，R² = {r ** 2:.3f}（讀書時數可以解釋 {r ** 2:.0%} 的成績差異）")

plt.scatter(x, y, alpha=0.4, s=15)
xs = np.linspace(x.min(), x.max(), 50)
plt.plot(xs, slope * xs + intercept, color="#e4572e", linewidth=2)
plt.xlabel("每週讀書時數")
plt.ylabel("期末成績")
plt.title("簡單線性迴歸")
plt.show()

print("預測：每週讀 15 小時，成績大約", round(slope * 15 + intercept))
```
