機器學習的本質就是**統計學**。這一課用程式複習最重要的統計概念：不用背公式，用**算出來、畫出來**的方式理解。

## 集中趨勢：資料的「中心」在哪裡？

| 指標 | 意思 | 特性 |
|---|---|---|
| **平均數** mean | 加總 ÷ 個數 | 容易受**極端值**影響 |
| **中位數** median | 排序後最中間的值 | 不受極端值影響 |
| **眾數** mode | 出現最多次的值 | 適合類別資料 |

```python
import numpy as np
import pandas as pd

salaries = pd.Series([32, 35, 36, 38, 40, 41, 45, 48, 52, 500])   # 單位：千元，最後一個是老闆
print("平均數：", salaries.mean())
print("中位數：", salaries.median())
print("去掉老闆後的平均：", salaries[:-1].mean())
print("眾數：", pd.Series(["A", "B", "A", "C", "A"]).mode()[0])
```

> 💡 新聞說「平均薪資 6 萬」，但大部分人都領不到？因為平均數被少數高薪拉高了。**有極端值時，中位數更能代表一般情況**。

## 離散程度：資料有多「分散」？

```python
import numpy as np

rng = np.random.default_rng(0)
class_a = rng.normal(70, 3, 30).round()    # 成績很集中
class_b = rng.normal(70, 15, 30).round()   # 成績很分散
for name, s in [("A 班", class_a), ("B 班", class_b)]:
    print(f"{name}：平均 {s.mean():.1f}、標準差 {s.std(ddof=1):.1f}、全距 {s.max() - s.min():.0f}")
```

- **變異數（variance）**：每個值和平均數的差距，平方後平均
- **標準差（standard deviation）**：變異數開根號，單位和原資料相同，最常用
- **四分位距（IQR）**：Q3 − Q1，中間 50% 資料的範圍，不受極端值影響

```python
import numpy as np

x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
mean = x.mean()
var = ((x - mean) ** 2).mean()
print("手算變異數：", var, "標準差：", var ** 0.5)
print("NumPy：", x.var(), x.std())
print("樣本標準差（除以 n-1）：", x.std(ddof=1))
```

> 💡 `ddof=1` 是**樣本**標準差（除以 n−1），用在「從樣本推估母體」的時候。pandas 的 `.std()` 預設就是 ddof=1，NumPy 預設是 0，要注意！

## 標準分數（Z-score）

「這個值比平均多幾個標準差？」可以用來**比較不同單位的資料**、找異常值：

```python
import pandas as pd

df = pd.DataFrame({
    "科目": ["國文", "數學"],
    "我的分數": [82, 70],
    "班平均": [75, 55],
    "班標準差": [5, 12],
})
df["Z"] = ((df["我的分數"] - df["班平均"]) / df["班標準差"]).round(2)
display(df)
print("相對表現比較好的是：", df.loc[df["Z"].idxmax(), "科目"])
```

數學雖然只有 70 分，但比平均高了 1.25 個標準差，相對表現比國文更好！

## 抽樣與中央極限定理

**不管母體長什麼樣子，樣本平均數的分布都會接近常態分布。** 這是統計學最重要的定理之一：

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
population = rng.exponential(10, 100_000)      # 很偏的分布（例如等待時間）

fig, axes = plt.subplots(1, 3, figsize=(13, 3.5))
axes[0].hist(population, bins=60, color="#9aa5b1")
axes[0].set_title("母體（很偏）")
for ax, n in zip(axes[1:], [5, 50]):
    means = [rng.choice(population, n).mean() for _ in range(2000)]
    ax.hist(means, bins=40, color="#3776ab")
    ax.set_title(f"每次抽 {n} 個，算平均，重複 2000 次")
fig.tight_layout()
plt.show()
```

樣本越大，樣本平均數的分布就越窄、越接近常態。這就是為什麼**民調抽樣 1000 人就能推估全國**。

## 信賴區間

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(3)
sample = rng.normal(165, 8, 40)          # 抽樣 40 人的身高
mean = sample.mean()
se = sample.std(ddof=1) / np.sqrt(len(sample))       # 標準誤
low, high = stats.t.interval(0.95, len(sample) - 1, loc=mean, scale=se)
print(f"樣本平均：{mean:.1f} 公分")
print(f"95% 信賴區間：{low:.1f} ～ {high:.1f} 公分")
```

意思是：如果重複抽樣很多次，用這種方法算出的區間，大約 95% 會包含真正的母體平均。

## 假設檢定：差異是真的，還是運氣？

兩班平均差了 3 分，是真的有差，還是剛好抽到的？用 **t 檢定**：

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
class_a = rng.normal(72, 10, 35)
class_b = rng.normal(78, 10, 35)
t, p = stats.ttest_ind(class_a, class_b)
print(f"A 班平均 {class_a.mean():.1f}，B 班平均 {class_b.mean():.1f}")
print(f"p 值 = {p:.4f}")
print("差異顯著 ✅" if p < 0.05 else "差異不顯著（可能只是運氣）")
```

**p 值**：如果兩班其實沒有差別，看到這麼大（或更大）差異的機率。p < 0.05 通常被認為「**統計上顯著**」。

> ⚠️ 「顯著」不等於「重要」。資料量很大時，很小的差異也會顯著。要同時看**差異的大小**。
