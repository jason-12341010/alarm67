網站在自己的電腦上（`127.0.0.1`）只有你看得到。要讓全世界都能用，就要**部署（deploy）** 到雲端的伺服器上。這一課介紹部署的基本觀念，以及一步一步把 FastAPI 網站部署到免費的平台。

## 開發伺服器 vs 正式伺服器

`flask run`、`fastapi dev`、`manage.py runserver` 都是**開發用**的伺服器：方便除錯，但效能差、不安全。正式上線要用**正式的伺服器**：

| 框架類型 | 正式伺服器 | 啟動指令範例 |
|---|---|---|
| Flask、Django（WSGI） | **gunicorn** | `gunicorn app:app --workers 4` |
| FastAPI（ASGI） | **uvicorn** | `uvicorn main:app --host 0.0.0.0 --port 8000` |

> 💡 `--host 0.0.0.0`：接受**來自其他電腦**的連線（預設的 127.0.0.1 只接受自己）。

## 環境變數：設定和程式碼分開

密碼、API 金鑰、資料庫網址**不能寫在程式碼裡**，要用**環境變數**：

```python
import os

os.environ["DATABASE_URL"] = "sqlite:///prod.db"      # 模擬：平台會幫你設定好
os.environ["DEBUG"] = "false"

DATABASE_URL = os.environ.get("DATABASE_URL", "sqlite:///dev.db")
DEBUG = os.environ.get("DEBUG", "false").lower() == "true"
SECRET_KEY = os.environ.get("SECRET_KEY")              # 沒有設定就是 None

print(f"資料庫：{DATABASE_URL}")
print(f"除錯模式：{DEBUG}")
if SECRET_KEY is None:
    print("⚠️ 沒有設定 SECRET_KEY！正式環境一定要設定")
```

更好的做法是用 **pydantic-settings**（要另外安裝：`pip install pydantic-settings`），自動讀取並驗證所有設定：

```py
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    database_url: str = "sqlite:///dev.db"
    debug: bool = False
    secret_key: str                     # 沒有預設值 → 沒設定就直接報錯，不會帶著錯誤的設定上線

settings = Settings()                   # 自動讀取環境變數 DATABASE_URL、DEBUG、SECRET_KEY
```

本機開發時，可以把環境變數寫在 `.env` 檔裡（**記得加進 `.gitignore`**）。

## 部署前的檢查清單

- [ ] `requirements.txt` 列出所有套件（`pip freeze > requirements.txt`）
- [ ] 金鑰、密碼都改用環境變數
- [ ] **關閉除錯模式**（`debug=False`、Django 的 `DEBUG = False`）
- [ ] Django：設定 `ALLOWED_HOSTS`、執行 `collectstatic`
- [ ] 資料庫：SQLite 只適合很小的網站；正式環境建議 **PostgreSQL**
- [ ] `.gitignore` 排除 `.venv/`、`.env`、`*.db`、`__pycache__/`

## 實戰：部署 FastAPI 到 Render

[Render](https://render.com) 有免費方案，可以直接從 GitHub 部署（其他類似的平台：Railway、Fly.io、Google Cloud Run）。

### Step 1：準備專案

```text
my-api/
├── main.py
├── requirements.txt
└── .gitignore
```

`main.py`：

```py
import os
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "我的 API 上線了！", "env": os.environ.get("APP_ENV", "dev")}
```

`requirements.txt`：

```text
fastapi
uvicorn
```

### Step 2：上傳到 GitHub

```bash
git init
git add .
git commit -m "第一版"
```

然後在 GitHub 建立一個新的 repository，照著頁面上的指令 `git push`。

### Step 3：在 Render 建立服務

1. 用 GitHub 帳號登入 Render
2. **New → Web Service** → 選擇你的 repository
3. 設定：
   - **Build Command**：`pip install -r requirements.txt`
   - **Start Command**：`uvicorn main:app --host 0.0.0.0 --port $PORT`
4. **Environment** 加上環境變數，例如 `APP_ENV` = `production`
5. 按 **Create Web Service**，等幾分鐘

完成後會得到一個網址，例如 `https://my-api.onrender.com`，全世界都可以連了！🎉 之後每次 `git push`，Render 都會**自動重新部署**。

> 💡 免費方案閒置一段時間後會休眠，第一次連線要等幾十秒喚醒。

## Docker：打包成「貨櫃」

不同電腦的環境不一樣，常常發生「**我電腦上可以跑啊！**」的問題。**Docker** 把程式、Python、套件全部打包成一個**映像檔（image）**，在任何地方執行結果都一樣。

`Dockerfile`：

```text
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

```bash
docker build -t my-api .
docker run -p 8000:8000 my-api
```

幾乎所有雲端平台都支援直接部署 Docker 映像檔。

## 上線之後

| 主題 | 說明 |
|---|---|
| **HTTPS** | 加密連線，Render 等平台會自動幫你設定 |
| **網域名稱** | 購買自己的網址（例如 `myshop.com`），在平台設定 DNS |
| **日誌（logging）** | 第 5 階段學的 logging，出問題時才找得到原因 |
| **監控** | 網站掛掉時通知你（例如 UptimeRobot） |
| **備份** | 定期備份資料庫！ |

def load_config(env):
    if "SECRET_KEY" not in env:
        raise RuntimeError("缺少 SECRET_KEY")
    debug = env.get("DEBUG", "").lower() in ("1", "true", "yes")
    secret = env["SECRET_KEY"]
    if not debug and len(secret) < 16:
        raise RuntimeError("SECRET_KEY 太短")
    return {
        "database_url": env.get("DATABASE_URL", "sqlite:///dev.db"),
        "debug": debug,
        "port": int(env.get("PORT", 8000)),
        "secret_key": secret,
    }
