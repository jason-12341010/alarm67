**Django** 是 Python 最完整的網頁框架，口號是「**給有截止日期的完美主義者**」。它內建了做網站需要的**幾乎所有東西**：資料庫 ORM、會員系統、管理後台、表單、安全防護… Instagram、Pinterest 的早期版本都是用 Django 開發的。

| | Flask / FastAPI | Django |
|---|---|---|
| 哲學 | 輕量，需要什麼自己加 | **內建全部**，照它的規則做 |
| 適合 | API、小型網站、微服務 | 有會員、後台、很多資料表的**完整網站** |
| 學習曲線 | 平緩 | 比較陡，但做大專案很快 |

> 📄 請在自己的電腦跟著做。

## Step 1：安裝與建立專案

```bash
mkdir django-demo
cd django-demo
python -m venv .venv
```

啟動虛擬環境後：

```bash
pip install django
django-admin startproject mysite .
```

> ⚠️ 最後的 `.` 很重要：代表在**目前的資料夾**建立專案，不然會多一層資料夾。

產生的結構：

```text
django-demo/
├── manage.py           ← 管理專案的指令工具
└── mysite/
    ├── settings.py     ← 所有設定
    ├── urls.py         ← 網址對應
    └── wsgi.py / asgi.py
```

執行開發伺服器：

```bash
python manage.py runserver
```

打開 http://127.0.0.1:8000，看到一個火箭 🚀 的頁面就成功了！

## Step 2：建立 App

Django 的**專案（project）** 由很多個 **App** 組成，每個 App 負責一個功能（例如部落格、商店、會員）：

```bash
python manage.py startapp blog
```

到 `mysite/settings.py`，把 App 登記進去：

```py
INSTALLED_APPS = [
    "django.contrib.admin",
    "django.contrib.auth",
    # ...（原本的保留）
    "blog",                       # ← 加這一行
]
```

## MVT 架構

Django 的架構叫 **MVT**：

```text
使用者的請求
     ↓
  urls.py        網址 → 對應到哪個 View
     ↓
  views.py       View（視圖）：處理邏輯
     ↓    ↘
  models.py      Model（模型）：資料庫的資料表
     ↓
  templates/     Template（模板）：產生 HTML
     ↓
  回應給使用者
```

## Step 3：第一個 View

`blog/views.py`：

```py
from django.http import HttpResponse
from django.shortcuts import render

def home(request):
    return HttpResponse("<h1>歡迎來到我的部落格</h1>")

def hello(request, name):
    return render(request, "blog/hello.html", {"name": name, "skills": ["Python", "Django", "AI"]})
```

建立 `blog/urls.py`：

```py
from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
    path("hello/<str:name>/", views.hello, name="hello"),
]
```

在 `mysite/urls.py` 把 blog 的網址加進來：

```py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("blog.urls")),          # ← 加這一行
]
```

建立模板 `blog/templates/blog/hello.html`（注意資料夾結構）：

```html
<h1>哈囉，{{ name }}！</h1>
<p>你會的技能：</p>
<ul>
  {% for s in skills %}<li>{{ s }}</li>{% endfor %}
</ul>
```

打開 http://127.0.0.1:8000/hello/小明/。

> 💡 Django 的模板語法和 Jinja2 **非常像**（`{{ }}`、`{% for %}`），學會一個另一個也就會了。

## Django 的指令工具

| 指令 | 用途 |
|---|---|
| `python manage.py runserver` | 啟動開發伺服器 |
| `python manage.py startapp 名稱` | 建立新 App |
| `python manage.py makemigrations` | 根據 Model 的變更產生「遷移檔」 |
| `python manage.py migrate` | 把遷移套用到資料庫 |
| `python manage.py createsuperuser` | 建立管理員帳號 |
| `python manage.py shell` | 互動式的 Python，可以直接操作資料庫 |
| `python manage.py test` | 執行測試 |

## 在網頁上練習：理解 URL 對應

Django 的 `path("hello/<str:name>/", ...)` 是怎麼比對網址的？我們用正規表示式模擬：

```python
import re

CONVERTERS = {"str": r"[^/]+", "int": r"[0-9]+", "slug": r"[-a-zA-Z0-9_]+"}

def compile_path(pattern):
    def repl(m):
        conv, name = m.group(1), m.group(2)
        return f"(?P<{name}>{CONVERTERS[conv]})"
    return re.compile("^" + re.sub(r"<(\w+):(\w+)>", repl, pattern) + "$")

urlpatterns = [
    ("", "home"),
    ("hello/<str:name>/", "hello"),
    ("posts/<int:year>/<slug:slug>/", "post_detail"),
]

def resolve(url):
    for pattern, view in urlpatterns:
        m = compile_path(pattern).match(url)
        if m:
            kwargs = {k: int(v) if v.isdigit() else v for k, v in m.groupdict().items()}
            return view, kwargs
    return "404", {}

for url in ["", "hello/小明/", "posts/2026/learn-django/", "posts/abc/x/", "nothing/"]:
    print(f"/{url:<28} → {resolve(url)}")
```

:::exercise 反向解析網址
Django 的 `{% url 'hello' name='小明' %}` 或 `reverse()` 可以**由名稱產生網址**，這樣網址改了也不用到處修改。寫函式 `reverse(route_name, /, **kwargs)`（`/` 代表 route_name 只能用位置傳入，這樣才不會和網址參數 `name` 撞名）：
- 用 `ROUTES`（名稱 → 網址模式）找到模式，把 `<型別:參數名>` 換成 kwargs 對應的值
- 回傳開頭加上 `/` 的網址
- 找不到名稱，或缺少參數時 `raise KeyError`
@@starter
import re

ROUTES = {
    "home": "",
    "hello": "hello/<str:name>/",
    "post_detail": "posts/<int:year>/<slug:slug>/",
}


def reverse(route_name, /, **kwargs):
    pass


print(reverse("home"))
print(reverse("hello", name="小明"))
print(reverse("post_detail", year=2026, slug="learn-django"))

@@hint
`pattern = ROUTES[route_name]`（找不到會自動 KeyError），然後 `re.sub(r"<\w+:(\w+)>", lambda m: str(kwargs[m.group(1)]), pattern)`。
@@solution
import re

ROUTES = {
    "home": "",
    "hello": "hello/<str:name>/",
    "post_detail": "posts/<int:year>/<slug:slug>/",
}


def reverse(route_name, /, **kwargs):
    pattern = ROUTES[route_name]
    return "/" + re.sub(r"<\w+:(\w+)>", lambda m: str(kwargs[m.group(1)]), pattern)


print(reverse("home"))
print(reverse("hello", name="小明"))
print(reverse("post_detail", year=2026, slug="learn-django"))
