**FastAPI** 是近年最受歡迎的 Python API 框架：
- ⚡ **快**：建立在 async 之上（第 4 階段學的！），效能接近 Node.js、Go
- 📝 **自動產生 API 文件**：寫完程式就有互動式的文件網頁
- ✅ **自動驗證資料**：靠**型別提示**（第 4 階段）和 Pydantic（下一課）
- 🤖 **AI 服務的首選**：很多 AI 模型的 API 都是用 FastAPI 部署的

> 📄 請在自己的電腦執行。

```bash
cd fastapi-demo
python -m venv .venv
```

```bash

```

## Step 2：第一個 API

建立 `main.py`：

```py
from fastapi import FastAPI

app = FastAPI(title="我的第一個 API")

@app.get("/")
def root():
    return {"message": "哈囉，FastAPI！"}          # 回傳字典，自動轉成 JSON

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):  # 型別提示 = 自動驗證
    return {"item_id": item_id, "q": q}
```

執行開發伺服器：

```bash
fastapi dev main.py
```

看到 `Uvicorn running on http://127.0.0.1:8000` 就成功了。打開：
- http://127.0.0.1:8000 → `{"message": "哈囉，FastAPI！"}`
- http://127.0.0.1:8000/items/42?q=hello → `{"item_id": 42, "q": "hello"}`
- http://127.0.0.1:8000/items/abc → **422 錯誤**：自動告訴你 item_id 必須是整數

## 路徑參數、查詢參數、請求內容

FastAPI 依照**參數的寫法**自動判斷資料從哪裡來：

```py
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):          # 請求的 JSON 內容（下一課詳細介紹）
    name: str
    price: float
    tags: list[str] = []

@app.get("/users/{user_id}/items")
def list_user_items(
    user_id: int,               # 在路徑 {} 裡 → 路徑參數
    skip: int = 0,              # 有預設值 → 查詢參數 ?skip=0
    limit: int = 10,
):
    return {"user_id": user_id, "skip": skip, "limit": limit}

@app.post("/items", status_code=201)
def create_item(item: Item):    # Pydantic 模型 → 從 JSON 內容讀取
    return {"created": item, "price_with_tax": item.price * 1.05}
```

在 `/docs` 頁面找到 `POST /items`，按 Try it out，輸入：

```json
{"name": "耳機", "price": 1290, "tags": ["3C"]}
```

## 完整的 CRUD API

```py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI(title="商品 API")


class ProductIn(BaseModel):
    name: str
    price: int
    stock: int = 0


class Product(ProductIn):
    id: int


db: dict[int, Product] = {}
next_id = 1


@app.get("/products")
def list_products(max_price: int | None = None) -> list[Product]:
    items = list(db.values())
    if max_price is not None:
        items = [p for p in items if p.price <= max_price]
    return items


@app.get("/products/{pid}")
def get_product(pid: int) -> Product:
    if pid not in db:
        raise HTTPException(status_code=404, detail="找不到商品")
    return db[pid]


@app.post("/products", status_code=201)
def create_product(data: ProductIn) -> Product:
    global next_id
    product = Product(id=next_id, **data.model_dump())
    db[next_id] = product
    next_id += 1
    return product


@app.put("/products/{pid}")
def update_product(pid: int, data: ProductIn) -> Product:
    if pid not in db:
        raise HTTPException(404, "找不到商品")
    db[pid] = Product(id=pid, **data.model_dump())
    return db[pid]


@app.delete("/products/{pid}", status_code=204)
def delete_product(pid: int):
    if db.pop(pid, None) is None:
        raise HTTPException(404, "找不到商品")
```

## async：同時處理很多請求

需要等待外部服務（資料庫、呼叫其他 API、呼叫 AI 模型）時，用 `async def`：

```py
import httpx
from fastapi import FastAPI

app = FastAPI()

@app.get("/weather/{city}")
async def weather(city: str):
    async with httpx.AsyncClient() as client:
        r = await client.get("https://wttr.in/" + city, params={"format": "j1"})
    data = r.json()
    return {"city": city, "temp_c": data["current_condition"][0]["temp_C"]}
```

> 💡 函式裡沒有 `await` 的話，寫一般的 `def` 就好，FastAPI 會自動放到執行緒池裡執行。

## 用程式測試 API

FastAPI 內建測試工具，搭配第 5 階段學的 pytest：

```py
# test_main.py
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_create_and_get():
    r = client.post("/products", json={"name": "滑鼠", "price": 590})
    assert r.status_code == 201
    pid = r.json()["id"]
    assert client.get(f"/products/{pid}").json()["name"] == "滑鼠"

def test_not_found():
    assert client.get("/products/9999").status_code == 404

def test_validation():
    assert client.post("/products", json={"name": "x", "price": "很貴"}).status_code == 422
```

## 常見錯誤

| 錯誤 | 原因 |
|---|---|
| `422 Unprocessable Entity` | 傳入的資料不符合型別（看回應裡的 `detail`，會告訴你哪個欄位錯） |
| `fastapi: command not found` | 安裝時沒加 `[standard]`；或用 `uvicorn main:app --reload` 啟動 |
| `Error loading ASGI app` | 檔名或變數名稱不對，`main:app` 代表 `main.py` 裡的 `app` |
| 瀏覽器呼叫 API 被擋（CORS） | 前端和 API 不同網域時，要加 `CORSMiddleware` |

:::exercise 設計 API 路由
FastAPI 用函式參數決定資料來源。寫函式 `classify_params(path, params)`，模擬 FastAPI 的判斷規則：
- `path` 是路由路徑，例如 `"/users/{user_id}/orders"`
- `params` 是 `[(參數名稱, 型別名稱, 是否有預設值), ...]`
- 回傳字典 `{參數名稱: 來源}`，來源是：
  - 名稱出現在 path 的 `{}` 裡 → `"path"`
  - 型別名稱是 `"BaseModel"` → `"body"`
  - 其他 → `"query"`
@@starter
import re


def classify_params(path, params):
    pass


print(classify_params("/users/{user_id}/orders", [
    ("user_id", "int", False), ("limit", "int", True), ("order", "BaseModel", False),
]))

@@hint
`path_names = set(re.findall(r"\{(\w+)\}", path))`
@@solution
import re


def classify_params(path, params):
    path_names = set(re.findall(r"\{(\w+)\}", path))
    result = {}
    for name, type_name, _ in params:
        if name in path_names:
            result[name] = "path"
        elif type_name == "BaseModel":
            result[name] = "body"
        else:
            result[name] = "query"
    return result


print(classify_params("/users/{user_id}/orders", [
    ("user_id", "int", False), ("limit", "int", True), ("order", "BaseModel", False),
]))
