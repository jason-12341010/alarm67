**爬蟲（Web Scraping）**：用程式自動抓取網頁上的資料：比價、追蹤新聞、收集研究資料… 也是 AI 收集訓練資料的方法之一。

> ⚠️ 瀏覽器的安全限制（CORS）讓這個網站**沒辦法抓取其他網站**。所以 `requests` 的部分請在自己的電腦執行；**解析 HTML** 的部分（BeautifulSoup）可以在網頁上用範例 HTML 練習。

## 爬蟲的禮儀與法律 ⚖️

- 先看網站有沒有提供 **API**，有的話優先用 API
- 遵守 **robots.txt**（例如 `https://example.com/robots.txt`）和網站的**使用條款**
- **放慢速度**：每次請求之間等一下，不要造成對方伺服器的負擔
- 注意**個人資料**和**著作權**，抓下來的資料不一定可以公開或商用

### 呼叫 JSON API

很多資料其實是透過 API 提供的，回傳 JSON，比解析 HTML 簡單多了：

```py
import requests

r = requests.get("https://api.github.com/repos/python/cpython", timeout=10)
r.raise_for_status()                 # 狀態碼不是 2xx 就丟出錯誤
data = r.json()                      # 直接轉成字典
print(data["full_name"], "⭐", data["stargazers_count"])

r = requests.post("https://httpbin.org/post", json={"name": "小明"}, timeout=10)
print(r.json()["json"])
```

## Step 2：用 BeautifulSoup 解析 HTML

HTML 是一層一層的**標籤**（還記得第 5 階段的「樹」嗎？HTML 就是一棵樹）：

```python
from bs4 import BeautifulSoup

html = """
<html><body>
  <h1 class="title">科技新聞</h1>
  <div class="news">
    <article class="item" data-id="101">
      <h2><a href="/news/101">AI 模型再創新高</a></h2>
      <span class="date">2026-11-03</span>
      <p class="summary">新一代的語言模型在多項測試中表現亮眼…</p>
    </article>
    <article class="item hot" data-id="102">
      <h2><a href="/news/102">Python 3.15 搶先看</a></h2>
      <span class="date">2026-11-02</span>
      <p class="summary">新版本帶來更快的執行速度…</p>
    </article>
    <article class="item" data-id="103">
      <h2><a href="/news/103">台灣半導體產業展望</a></h2>
      <span class="date">2026-11-01</span>
    </article>
  </div>
</body></html>
"""
soup = BeautifulSoup(html, "html.parser")

print(soup.h1.text)                                  # 第一個 h1 的文字
print(soup.find("span", class_="date").text)         # 第一個符合的
for a in soup.find_all("a"):                         # 全部符合的
    print(a.text, "→", a["href"])                    # 取屬性用 ["屬性名稱"]
```

## CSS 選擇器：最好用的找法

`select()` 用 **CSS 選擇器**找元素，寫法和網頁設計一樣：

```python
from bs4 import BeautifulSoup

html = """
<div class="news">
  <article class="item" data-id="101"><h2><a href="/news/101">AI 模型再創新高</a></h2><span class="date">2026-11-03</span></article>
  <article class="item hot" data-id="102"><h2><a href="/news/102">Python 3.15 搶先看</a></h2><span class="date">2026-11-02</span></article>
  <article class="item" data-id="103"><h2><a href="/news/103">台灣半導體產業展望</a></h2><span class="date">2026-11-01</span></article>
</div>
"""
soup = BeautifulSoup(html, "html.parser")

print([a.text for a in soup.select("article h2 a")])        # article 裡面的 h2 裡面的 a
print(soup.select_one("article.hot a").text)                 # class 有 hot 的 article
print([el["data-id"] for el in soup.select("[data-id]")])    # 有 data-id 屬性的

news = []
for item in soup.select("article.item"):
    news.append({
        "id": int(item["data-id"]),
        "title": item.select_one("h2 a").get_text(strip=True),
        "url": "https://example.com" + item.select_one("a")["href"],
        "date": item.select_one(".date").text,
        "hot": "hot" in item.get("class", []),
    })
for n in news:
    print(n)
```

| CSS 選擇器 | 意思 |
|---|---|
| `p` | 所有 `<p>` |
| `.price` | class 是 price 的 |
| `#main` | id 是 main 的 |
| `div p` | div **裡面**的 p（任意層） |
| `div > p` | div 的**直接**子元素 p |
| `a[href]` | 有 href 屬性的 a |
| `a[href^="https"]` | href 以 https 開頭的 |
| `li:nth-of-type(2)` | 第 2 個 li |

> 💡 在瀏覽器的網頁上按右鍵 → **檢查**，可以看到 HTML 結構；在元素上按右鍵 → **Copy → Copy selector** 可以直接複製 CSS 選擇器。

```python
from io import StringIO
import pandas as pd

<table id="prices">
  <tr><th>商品</th><th>價格</th><th>庫存</th></tr>

```

## 完整的爬蟲範例（在自己的電腦執行）

```py
import time
import requests
from bs4 import BeautifulSoup
import pandas as pd

BASE = "https://books.toscrape.com/"          # 專門給人練習爬蟲的網站
session = requests.Session()
session.headers["User-Agent"] = "Mozilla/5.0 (learning-bot)"

rows = []
for page in range(1, 4):
    url = f"{BASE}catalogue/page-{page}.html"
    r = session.get(url, timeout=10)
    r.raise_for_status()
    soup = BeautifulSoup(r.text, "html.parser")
    for book in soup.select("article.product_pod"):
        rows.append({
            "title": book.h3.a["title"],
            "price": float(book.select_one(".price_color").text.lstrip("£Â")),
            "rating": book.select_one("p.star-rating")["class"][1],
        })
    print(f"第 {page} 頁完成，累計 {len(rows)} 本")
    time.sleep(1)                              # 禮貌：每頁之間等 1 秒

df = pd.DataFrame(rows)
df.to_csv("books.csv", index=False, encoding="utf-8-sig")
print(df.groupby("rating")["price"].mean().round(2))
```

from bs4 import BeautifulSoup

html = """
<ul class="products">
  <li class="product"><a href="/p/1"><span class="name"> 藍牙耳機 </span></a><span class="price">NT$ 1,290</span></li>
  <li class="product"><a href="/p/2"><span class="name">無線滑鼠</span></a><span class="price">NT$590</span><span class="sold-out">售完</span></li>
  <li class="product"><a href="/p/3"><span class="name">機械鍵盤</span></a><span class="price">NT$ 12,490</span></li>
</ul>
"""


def parse_products(html):
    soup = BeautifulSoup(html, "html.parser")
    result = []
    for li in soup.select("li.product"):
        price_text = li.select_one(".price").text.replace("NT$", "").replace(",", "").strip()
        result.append({
            "name": li.select_one(".name").get_text(strip=True),
            "price": int(price_text),
            "in_stock": li.select_one(".sold-out") is None,
            "url": li.select_one("a")["href"],
        })
    return result


for p in parse_products(html):
    print(p)
