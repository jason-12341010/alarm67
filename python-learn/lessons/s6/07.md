Django 最強大的兩個功能：**ORM** 讓你用 Python 操作資料庫，完全不用寫 SQL；**Admin 後台**讓你**不用寫任何程式**，就有一個可以新增、修改、刪除資料的管理介面。

> 📄 接續上一課的 `django-demo` 專案，在自己的電腦執行。

## Step 1：定義 Model

`blog/models.py`：

```py
from django.db import models
from django.contrib.auth.models import User


class Category(models.Model):
    name = models.CharField("分類名稱", max_length=50, unique=True)

    def __str__(self):
        return self.name


class Post(models.Model):
    title = models.CharField("標題", max_length=200)
    content = models.TextField("內容")
    category = models.ForeignKey(Category, on_delete=models.SET_NULL, null=True, related_name="posts")
    author = models.ForeignKey(User, on_delete=models.CASCADE)
    published = models.BooleanField("已發布", default=False)
    views = models.PositiveIntegerField(default=0)
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ["-created_at"]          # 預設依建立時間由新到舊

    def __str__(self):
        return self.title
```

每個 Model 類別 = 一張資料表；每個屬性 = 一個欄位。還記得第 4 階段的**描述器**嗎？`models.CharField()` 就是用那種機制做出來的！

## Step 2：建立資料表

```bash
python manage.py makemigrations
python manage.py migrate
```

- `makemigrations`：比對 Model 和資料庫的差異，產生「遷移檔」（記錄要怎麼改資料庫）
- `migrate`：真正去修改資料庫

> 💡 每次修改 `models.py`，都要再執行這兩個指令。

## Step 3：Admin 後台

建立管理員帳號：

```bash
python manage.py createsuperuser
```

依照提示輸入帳號、email（可以留空）、密碼。

在 `blog/admin.py` 登記 Model：

```py
from django.contrib import admin
from .models import Category, Post


@admin.register(Post)
class PostAdmin(admin.ModelAdmin):
    list_display = ["title", "category", "author", "published", "views", "created_at"]
    list_filter = ["published", "category"]
    search_fields = ["title", "content"]


admin.site.register(Category)
```

啟動伺服器，打開 **http://127.0.0.1:8000/admin**，用剛剛的帳號登入。你會看到一個完整的管理介面：可以新增分類、發表文章、搜尋、篩選… **而你幾乎沒寫任何程式**！

> 💡 想要中文介面：在 `settings.py` 設定 `LANGUAGE_CODE = "zh-hant"`、`TIME_ZONE = "Asia/Taipei"`。

## Step 4：用 ORM 查詢資料

用 `python manage.py shell` 開啟互動模式來試試：

```py
from blog.models import Post, Category
from django.contrib.auth.models import User

me = User.objects.first()
tech = Category.objects.create(name="科技")

# 新增
Post.objects.create(title="學 Django 第一天", content="好好玩", category=tech, author=me, published=True)

# 查詢
Post.objects.all()                                   # 全部
Post.objects.filter(published=True)                  # WHERE published = 1
Post.objects.filter(title__contains="Django")        # WHERE title LIKE '%Django%'
Post.objects.filter(views__gte=100)                  # views >= 100（gte = greater than or equal）
Post.objects.filter(category__name="科技")           # 跨資料表查詢（JOIN）
Post.objects.exclude(published=True)                 # NOT
Post.objects.order_by("-views")[:5]                  # 前 5 名
Post.objects.get(id=1)                               # 拿一筆（找不到會出錯）
Post.objects.filter(published=True).count()

# 修改
post = Post.objects.get(id=1)
post.views += 1
post.save()
Post.objects.filter(published=False).update(published=True)   # 批次修改

# 刪除
Post.objects.filter(views=0).delete()

# 反向關聯：分類底下的所有文章
tech.posts.all()

# 統計
from django.db.models import Count, Avg
Category.objects.annotate(n=Count("posts")).values("name", "n")
Post.objects.aggregate(avg_views=Avg("views"))
```

| 查詢條件 | 意思 |
|---|---|
| `欄位=值` | 等於 |
| `欄位__gt` / `__gte` / `__lt` / `__lte` | 大於 / 大於等於 / 小於 / 小於等於 |
| `欄位__contains` / `__icontains` | 包含（i：不分大小寫） |
| `欄位__in=[...]` | 在清單裡 |
| `欄位__startswith` | 開頭是 |
| `外鍵__欄位` | 跨資料表 |

## Step 5：在 View 裡使用

`blog/views.py`：

```py
from django.shortcuts import render, get_object_or_404
from .models import Post


def post_list(request):
    posts = Post.objects.filter(published=True).select_related("category", "author")
    q = request.GET.get("q")
    if q:
        posts = posts.filter(title__icontains=q)
    return render(request, "blog/post_list.html", {"posts": posts, "q": q})


def post_detail(request, pk):
    post = get_object_or_404(Post, pk=pk, published=True)    # 找不到就回 404
    post.views += 1
    post.save(update_fields=["views"])
    return render(request, "blog/post_detail.html", {"post": post})
```

`blog/templates/blog/post_list.html`：

```html
<h1>文章列表</h1>
<form><input name="q" value="{{ q|default:'' }}" placeholder="搜尋標題"><button>搜尋</button></form>
{% for post in posts %}
  <article>
    <h2><a href="{% url 'post_detail' post.pk %}">{{ post.title }}</a></h2>
    <small>{{ post.category }}・{{ post.author }}・{{ post.created_at|date:"Y-m-d" }}・👁 {{ post.views }}</small>
    <p>{{ post.content|truncatechars:80 }}</p>
  </article>
{% empty %}
  <p>沒有文章</p>
{% endfor %}
```

在 `blog/urls.py` 加上：

```py
path("posts/", views.post_list, name="post_list"),
path("posts/<int:pk>/", views.post_detail, name="post_detail"),
```

## 在網頁上練習：模擬 ORM 的查詢語法

Django 的 `filter(views__gte=100)` 這種寫法是怎麼運作的？我們用 Python 模擬一個迷你版：

```python
import operator

LOOKUPS = {
    "exact": operator.eq, "gt": operator.gt, "gte": operator.ge, "lt": operator.lt, "lte": operator.le,
    "contains": lambda a, b: b in a, "icontains": lambda a, b: b.lower() in a.lower(),
    "in": lambda a, b: a in b, "startswith": lambda a, b: a.startswith(b),
}

def matches(row, **conditions):
    for key, value in conditions.items():
        field, _, lookup = key.partition("__")
        if not LOOKUPS[lookup or "exact"](row[field], value):
            return False
    return True

posts = [
    {"title": "學 Django 第一天", "views": 120, "published": True},
    {"title": "Python 小技巧", "views": 80, "published": True},
    {"title": "django ORM 教學", "views": 300, "published": False},
]
print([p["title"] for p in posts if matches(p, views__gte=100)])
print([p["title"] for p in posts if matches(p, title__icontains="django", published=True)])
print([p["title"] for p in posts if matches(p, views__in=[80, 300])])
```

@@solution
import operator

OPS = {"": operator.eq, "gt": operator.gt, "gte": operator.ge, "lt": operator.lt, "contains": lambda a, b: b in a}


class QuerySet:
    def __init__(self, rows):
        self.rows = list(rows)

    def filter(self, **conditions):
        def ok(row):
            for key, value in conditions.items():
                field, _, op = key.partition("__")
                if not OPS[op](row[field], value):
                    return False
            return True
        return QuerySet(r for r in self.rows if ok(r))

    def order_by(self, field):
        desc = field.startswith("-")
        field = field.lstrip("-")
        return QuerySet(sorted(self.rows, key=lambda r: r[field], reverse=desc))

    def count(self):
        return len(self.rows)

    def values(self, field):
        return [r[field] for r in self.rows]


posts = QuerySet([

])
