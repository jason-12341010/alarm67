**Flask** 是最受歡迎的 Python 輕量級網頁框架：核心很小、很好上手，需要什麼功能再加什麼。很適合做小型網站、API、原型。

> 📄 Flask 要開伺服器，請在**自己的電腦**跟著步驟做。標示「🐍 可以修改後執行」的範例可以直接在網頁上跑。

## Step 1：建立專案

```bash
mkdir flask-demo
cd flask-demo
python -m venv .venv
```

啟動虛擬環境（第 5 階段第 2 課）：

```bash
# Windows
.venv\Scripts\activate
# Mac / Linux
source .venv/bin/activate
```

安裝 Flask：

```bash
pip install flask
```

## Step 2：第一個網站

建立 `app.py`：

```py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>哈囉，Flask！</h1><p>這是我的第一個網站</p>"

@app.route("/about")
def about():
    return "關於我們"

if __name__ == "__main__":
    app.run(debug=True)
```

執行：

```bash
python app.py
```

看到這樣的訊息就成功了：

```text
 * Running on http://127.0.0.1:5000
 * Debugger is active!
```

打開瀏覽器輸入 **http://127.0.0.1:5000**，就會看到你的網站！再試試 http://127.0.0.1:5000/about。

> 💡 `debug=True`：修改程式碼存檔後，伺服器會**自動重新啟動**；出錯時會顯示詳細的錯誤畫面。**正式上線時一定要關掉**。按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 停止伺服器。

## 動態路由：網址裡的變數

```py
@app.route("/hello/<name>")
def hello(name):
    return f"哈囉，{name}！"

@app.route("/products/<int:product_id>")       # int: 自動轉成整數，不是數字就 404
def product(product_id):
    return f"商品編號 {product_id}"
```

試試 http://127.0.0.1:5000/hello/小明 和 http://127.0.0.1:5000/products/42。

## 讀取查詢參數與回傳 JSON

```py
from flask import Flask, request, jsonify

app = Flask(__name__)
PRODUCTS = [
    {"id": 1, "name": "藍牙耳機", "price": 1290},
    {"id": 2, "name": "無線滑鼠", "price": 590},
    {"id": 3, "name": "機械鍵盤", "price": 2490},
]

@app.route("/api/products")
def api_products():
    max_price = request.args.get("max_price", type=int)     # ?max_price=1000
    items = [p for p in PRODUCTS if max_price is None or p["price"] <= max_price]
    return jsonify(items)                                   # 回傳 JSON

@app.route("/api/products/<int:pid>")
def api_product(pid):
    for p in PRODUCTS:
        if p["id"] == pid:
            return jsonify(p)
    return jsonify({"error": "找不到商品"}), 404           # 回傳 (內容, 狀態碼)
```

試試 http://127.0.0.1:5000/api/products?max_price=1000。

## 模板（Template）：Jinja2

在 Python 裡寫 HTML 字串很痛苦。Flask 用 **Jinja2 模板**把 HTML 和程式分開。Jinja2 可以在網頁上直接練習：

```python
from jinja2 import Template

t = Template("""
<h1>{{ title }}</h1>
<p>歡迎，{{ user.name }}！你有 {{ cart | length }} 件商品在購物車。</p>
<ul>
{% for item in cart %}
  <li>{{ item.name }} — {{ "{:,}".format(item.price) }} 元{% if item.price > 1000 %} 🔥{% endif %}</li>
{% endfor %}
</ul>
<p>總計：{{ cart | sum(attribute="price") }} 元</p>
""")
html = t.render(
    title="購物車",
    user={"name": "小明"},
    cart=[{"name": "藍牙耳機", "price": 1290}, {"name": "滑鼠墊", "price": 250}],
)
print(html)
```

| 語法 | 用途 |
|---|---|
| `{{ 變數 }}` | 顯示值（會**自動跳脫 HTML**，防止 XSS 攻擊） |
| `{% for %} … {% endfor %}` | 迴圈 |
| `{% if %} … {% endif %}` | 條件 |
| `{{ 值 \| 過濾器 }}` | 轉換，例如 `upper`、`length`、`default("無")` |
| `{% extends "base.html" %}` | 繼承版型（共用的頁首頁尾） |

### 在 Flask 裡使用模板

專案結構：

```text
flask-demo/
├── app.py
└── templates/          ← 資料夾名稱一定要叫 templates
    ├── base.html
    └── products.html
```

`templates/base.html`（共用版型）：

```html
<!doctype html>
<html lang="zh-Hant">
<head><meta charset="utf-8"><title>{% block title %}我的商店{% endblock %}</title></head>
<body>
  <nav><a href="/">首頁</a> | <a href="/products">商品</a></nav>
  <main>{% block content %}{% endblock %}</main>
</body>
</html>
```

`templates/products.html`：

```html
{% extends "base.html" %}
{% block title %}商品列表{% endblock %}
{% block content %}
  <h1>商品列表</h1>
  {% for p in products %}
    <p><a href="{{ url_for('product_page', pid=p.id) }}">{{ p.name }}</a>：{{ p.price }} 元</p>
  {% endfor %}
{% endblock %}
```

`app.py` 加上：

```py
from flask import render_template, abort

@app.route("/products")
def products_page():
    return render_template("products.html", products=PRODUCTS)

@app.route("/products/<int:pid>")
def product_page(pid):
    p = next((p for p in PRODUCTS if p["id"] == pid), None)
    if p is None:
        abort(404)
    return f"<h1>{p['name']}</h1><p>{p['price']} 元</p>"
```

## 常見錯誤

| 錯誤 | 原因 |
|---|---|
| `TemplateNotFound` | 模板沒放在 `templates/` 資料夾裡，或檔名打錯 |
| `Address already in use` | 5000 port 被佔用了（Mac 的 AirPlay 常佔用）→ `app.run(port=5001)` |
| 改了程式沒反應 | 沒開 `debug=True`，或瀏覽器快取 → 按 <kbd>Ctrl</kbd>+<kbd>F5</kbd> |
| `ModuleNotFoundError: flask` | 虛擬環境沒啟動，或裝在別的 Python |
