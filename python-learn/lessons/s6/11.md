辦公室裡最多的重複工作，大概就是 **Excel** 了：合併幾十個檔案、每週做一樣的報表、把資料整理成固定格式… 用 Python 自動化，幾個小時的工作可以變成幾秒鐘。

這一課用兩個工具：
- **pandas**：讀寫資料、計算（第 7 階段學過）
- **openpyxl**：控制 Excel 的**格式**：字型、顏色、欄寬、公式、圖表

> 💡 這個網站可以直接執行！第一次使用 openpyxl 時會自動下載安裝，需要等幾秒。在自己的電腦上：`pip install openpyxl pandas`

## pandas：最快的讀寫方式

```python
import pandas as pd

df = pd.DataFrame({
    "業務": ["小明", "小美", "阿華", "小強"],
    "地區": ["北區", "南區", "北區", "中區"],
    "Q1": [120, 98, 150, 80],
    "Q2": [135, 110, 142, 95],
})
df["合計"] = df["Q1"] + df["Q2"]
df.to_excel("業績.xlsx", index=False, sheet_name="上半年")    # 寫入 Excel

back = pd.read_excel("業績.xlsx", sheet_name="上半年")        # 讀回來
display(back)
```

### 一個檔案多個工作表

```python
import pandas as pd

orders = pd.read_csv("shop_orders.csv")
orders["revenue"] = orders["price"] * orders["qty"]

with pd.ExcelWriter("銷售報表.xlsx") as writer:
    orders.to_excel(writer, sheet_name="明細", index=False)
    orders.groupby("city")["revenue"].sum().to_excel(writer, sheet_name="各城市")
    orders.pivot_table(index="category", columns="city", values="revenue", aggfunc="sum").to_excel(writer, sheet_name="交叉表")

xls = pd.ExcelFile("銷售報表.xlsx")
print("工作表：", xls.sheet_names)
display(pd.read_excel(xls, sheet_name="各城市"))
```

## openpyxl：控制格式

```python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

wb = Workbook()
ws = wb.active
ws.title = "成績單"

ws.append(["姓名", "國文", "英文", "數學", "總分"])          # 一次加入一列
data = [("小明", 85, 92, 78), ("小美", 90, 88, 95), ("阿華", 72, 65, 88)]
for name, *scores in data:
    row = ws.max_row + 1
    ws.append([name, *scores, f"=SUM(B{row}:D{row})"])     # 也可以寫 Excel 公式！

header_font = Font(bold=True, color="FFFFFF")
header_fill = PatternFill("solid", fgColor="3776AB")
thin = Side(style="thin", color="CCCCCC")
for cell in ws[1]:                                        # 第 1 列（標題）
    cell.font = header_font
    cell.fill = header_fill
    cell.alignment = Alignment(horizontal="center")

for row in ws.iter_rows(min_row=2):
    for cell in row:
        cell.border = Border(top=thin, bottom=thin, left=thin, right=thin)
        if isinstance(cell.value, int) and cell.value < 70:
            cell.font = Font(color="C00000", bold=True)    # 不及格標紅色

ws.column_dimensions["A"].width = 12
ws.freeze_panes = "A2"                                     # 凍結標題列
wb.save("成績單.xlsx")
print("✅ 已儲存成績單.xlsx")

from openpyxl import load_workbook
ws2 = load_workbook("成績單.xlsx").active
for row in ws2.iter_rows(values_only=True):
    print(row)
```

> 💡 公式要用 Excel 打開才會計算。用 `load_workbook(..., data_only=True)` 讀取的是**最後一次在 Excel 存檔時**計算出的值。

## 加上圖表

```python
from openpyxl import Workbook
from openpyxl.chart import BarChart, Reference

wb = Workbook()
ws = wb.active
ws.append(["月份", "營收"])
for m, v in zip(["1月", "2月", "3月", "4月", "5月", "6月"], [120, 135, 98, 160, 175, 190]):
    ws.append([m, v])

chart = BarChart()
chart.title = "上半年營收"
chart.y_axis.title = "萬元"
chart.add_data(Reference(ws, min_col=2, min_row=1, max_row=7), titles_from_data=True)
chart.set_categories(Reference(ws, min_col=1, min_row=2, max_row=7))
ws.add_chart(chart, "D2")
wb.save("營收圖表.xlsx")
print("✅ 圖表已加入，用 Excel 打開就能看到")
```

## 實戰：合併多個檔案

最常見的需求：每個分店一個 Excel，要合併成一份總表。

```python
import pandas as pd
from pathlib import Path
import numpy as np

# 先模擬產生 5 個分店的檔案
Path("分店").mkdir(exist_ok=True)
rng = np.random.default_rng(0)
for store in ["台北", "台中", "台南", "高雄", "花蓮"]:
    pd.DataFrame({
        "日期": pd.date_range("2026-10-01", periods=5).strftime("%Y-%m-%d"),
        "營收": rng.integers(20000, 80000, 5),
    }).to_excel(f"分店/{store}.xlsx", index=False)

# 自動合併資料夾裡所有的 Excel
frames = []
for f in sorted(Path("分店").glob("*.xlsx")):
    df = pd.read_excel(f)
    df["分店"] = f.stem                     # 檔名（不含副檔名）當作分店名稱
    frames.append(df)
total = pd.concat(frames, ignore_index=True)
print(f"合併了 {len(frames)} 個檔案，共 {len(total)} 筆")

summary = total.pivot_table(index="日期", columns="分店", values="營收", aggfunc="sum", margins=True, margins_name="合計")
display(summary)
summary.to_excel("總表.xlsx")
```

@@solution
from openpyxl import Workbook, load_workbook
from openpyxl.styles import Font


def make_report(rows, path):
    wb = Workbook()
    ws = wb.active
    ws.append(["業務", "業績", "達標"])
    for cell in ws[1]:
        cell.font = Font(bold=True)
    for name, amount in sorted(rows, key=lambda r: -r[1]):
        ws.append([name, amount, "✅" if amount >= 100 else "❌"])
        if amount < 100:
            ws.cell(row=ws.max_row, column=2).font = Font(color="FF0000")
    ws.append(["合計", sum(a for _, a in rows), ""])
    wb.save(path)


make_report([("小明", 120), ("小美", 85), ("阿華", 150)], "report.xlsx")
