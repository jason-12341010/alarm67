## KNN：物以類聚

**K 近鄰（K-Nearest Neighbors）** 可能是最直覺的機器學習方法：

> 要預測一個新的點，就找出離它**最近的 K 個鄰居**，看大部分鄰居是什麼類別。

它其實沒有「訓練」，只是把資料記下來，預測時再計算距離。

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)
a = rng.normal([2, 2], 0.8, (20, 2))
b = rng.normal([5, 4], 0.8, (20, 2))
X = np.vstack([a, b])
y = np.array([0] * 20 + [1] * 20)
new = np.array([3.8, 3.0])

dist = np.sqrt(((X - new) ** 2).sum(axis=1))
k = 5
nearest = np.argsort(dist)[:k]
vote = np.bincount(y[nearest]).argmax()

plt.scatter(*a.T, label="A 類", c="#3776ab")
plt.scatter(*b.T, label="B 類", c="#ffb000")
for i in nearest:
    plt.plot([new[0], X[i, 0]], [new[1], X[i, 1]], "k--", alpha=0.4)
plt.scatter(*new, c="red", marker="*", s=300, label="新的點")
plt.title(f"K={k} 個鄰居中，{(y[nearest] == vote).sum()} 個是 {'AB'[vote]} 類 → 預測為 {'AB'[vote]} 類")
plt.legend()
plt.show()
```

## 用 scikit-learn

```python
from sklearn.datasets import load_iris
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
for k in [1, 3, 5, 15, 50]:
    knn = KNeighborsClassifier(n_neighbors=k).fit(X_train, y_train)
    print(f"K = {k:>2}：測試準確率 {knn.score(X_test, y_test):.3f}")
```

- **K 太小**（例如 1）：容易被雜訊影響 → 過擬合
- **K 太大**：太多遠方的鄰居也來投票 → 欠擬合

## ⚠️ 特徵縮放：距離型模型的必要步驟

KNN 用**距離**判斷相似度。如果特徵的**單位差很多**，大的會完全主導距離：

```python
import numpy as np

# [年收入（元）, 年齡]
a = np.array([800000, 25])
b = np.array([810000, 60])    # 收入差一點，年齡差很多
c = np.array([600000, 26])    # 收入差很多，年齡幾乎一樣
print("a-b 距離：", np.linalg.norm(a - b).round())
print("a-c 距離：", np.linalg.norm(a - c).round())
print("→ 年齡的差異幾乎被忽略了！")
```

解決方法是**特徵縮放**，把所有特徵變成差不多的範圍：

| 方法 | 做法 | 結果範圍 |
|---|---|---|
| **StandardScaler**（標準化） | (x − 平均) ÷ 標準差 | 平均 0、標準差 1 |
| **MinMaxScaler**（正規化） | (x − 最小值) ÷ (最大值 − 最小值) | 0 到 1 |

```python
from sklearn.datasets import load_wine
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler, MinMaxScaler
from sklearn.model_selection import train_test_split
import pandas as pd

X, y = load_wine(return_X_y=True, as_frame=True)
print(X.describe().loc[["mean", "std", "max"]].round(1).iloc[:, :6])    # 各特徵的範圍差很多

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
print(f"\n沒有縮放：{KNeighborsClassifier().fit(X_train, y_train).score(X_test, y_test):.3f}")
for scaler in [StandardScaler(), MinMaxScaler()]:
    scaler.fit(X_train)                                  # 只用訓練集 fit！
    knn = KNeighborsClassifier().fit(scaler.transform(X_train), y_train)
    print(f"{type(scaler).__name__}：{knn.score(scaler.transform(X_test), y_test):.3f}")
```

準確率大幅提升！

### 哪些模型需要縮放？

| 需要縮放 ✅ | 不需要 ❌ |
|---|---|
| KNN、K-Means（用距離） | 決策樹、隨機森林、梯度提升 |
| SVM、邏輯迴歸（有正則化時） | |
| **神經網路**（訓練更穩定） | |
| PCA | |

## KNN 迴歸

KNN 也可以做迴歸：取 K 個鄰居的**平均值**：

```python
import pandas as pd
from sklearn.neighbors import KNeighborsRegressor
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split

df = pd.read_csv("house_prices.csv")
X = df[["area", "age", "floor", "near_mrt"]]
y = df["price"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
scaler = StandardScaler().fit(X_train)
knn = KNeighborsRegressor(n_neighbors=7).fit(scaler.transform(X_train), y_train)
print(f"R²：{knn.score(scaler.transform(X_test), y_test):.3f}")

new_house = pd.DataFrame({"area": [35], "age": [10], "floor": [8], "near_mrt": [1]})
print(f"35 坪、屋齡 10 年、8 樓、近捷運的預測房價：{knn.predict(scaler.transform(new_house))[0]:,.0f} 萬")
```

## 推薦系統的雛形

「**喜歡這個的人也喜歡…**」其實就是找最近的鄰居：

```python
import numpy as np
import pandas as pd
from sklearn.neighbors import NearestNeighbors

ratings = pd.DataFrame(
    [[5, 4, 0, 1, 0], [4, 5, 1, 0, 1], [0, 1, 5, 4, 5], [1, 0, 4, 5, 4], [5, 5, 0, 0, 1]],
    index=["小明", "小美", "阿華", "小強", "你"],
    columns=["復仇者聯盟", "蜘蛛人", "鐵達尼號", "真愛每一天", "愛在黎明破曉時"],
)
display(ratings)
nn = NearestNeighbors(n_neighbors=2, metric="cosine").fit(ratings.drop(index="你"))
dist, idx = nn.kneighbors(ratings.loc[["你"]])
similar = ratings.index[idx[0]]
print("跟你品味最像的人：", list(similar))
```

from sklearn.datasets import load_breast_cancer
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=7, stratify=y)

acc_raw = KNeighborsClassifier(n_neighbors=5).fit(X_train, y_train).score(X_test, y_test)
scaler = StandardScaler().fit(X_train)
X_train_s, X_test_s = scaler.transform(X_train), scaler.transform(X_test)
acc_scaled = KNeighborsClassifier(n_neighbors=5).fit(X_train_s, y_train).score(X_test_s, y_test)
scores = [KNeighborsClassifier(n_neighbors=k).fit(X_train_s, y_train).score(X_test_s, y_test) for k in range(1, 21)]
best_k = scores.index(max(scores)) + 1
print(f"沒縮放 {acc_raw:.3f}，縮放後 {acc_scaled:.3f}，最佳 K = {best_k}")
