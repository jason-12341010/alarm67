> 「資料和特徵決定了機器學習的上限，模型和演算法只是在逼近這個上限。」

**特徵工程（Feature Engineering）**：把原始資料轉換成模型更容易學習的特徵。這往往比換一個更厲害的模型更有效。

## 1. 類別特徵編碼

```python
import pandas as pd
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder

df = pd.DataFrame({
    "城市": ["台北", "台中", "高雄", "台北"],
    "尺寸": ["S", "L", "M", "XL"],
})

# One-Hot：沒有順序的類別（城市）
ohe = OneHotEncoder(sparse_output=False, handle_unknown="ignore")
print(pd.DataFrame(ohe.fit_transform(df[["城市"]]), columns=ohe.get_feature_names_out()))

# Ordinal：有順序的類別（尺寸）
oe = OrdinalEncoder(categories=[["S", "M", "L", "XL"]])
print(oe.fit_transform(df[["尺寸"]]).ravel())
```

> 💡 `handle_unknown="ignore"`：預測時遇到訓練時沒看過的類別（例如「花蓮」），不會出錯。

## 2. 從現有欄位創造新特徵

**領域知識**是最好的特徵來源：

```python
import pandas as pd

df = pd.read_csv("titanic.csv")
df["family_size"] = df["SibSp"] + df["Parch"] + 1                     # 家庭人數
df["is_alone"] = (df["family_size"] == 1).astype(int)
df["title"] = df["Name"].str.extract(r",\s*([^.]+)\.")[0]               # 從名字取出稱謂
df["title"] = df["title"].replace({"Mlle": "Miss", "Ms": "Miss", "Mme": "Mrs"})
df.loc[~df["title"].isin(["Mr", "Mrs", "Miss", "Master"]), "title"] = "Rare"
df["has_cabin"] = df["Cabin"].notna().astype(int)
df["fare_per_person"] = df["Fare"] / df["family_size"]

print(df.groupby("title")["Survived"].agg(["mean", "count"]).round(2))
print(df.groupby("family_size")["Survived"].mean().round(2))
```

「Master」是小男孩的稱謂，他們的生還率比成年男性（Mr）高很多。這個資訊光看「性別」和「年齡」是不夠的！

## 5. 缺值處理

```python
import pandas as pd
from sklearn.impute import SimpleImputer

df = pd.read_csv("titanic.csv")
print(df[["Age", "Embarked", "Cabin"]].isna().sum())
imp = SimpleImputer(strategy="median")
df["Age_filled"] = imp.fit_transform(df[["Age"]])

```

## Pipeline：把所有步驟串起來

前處理有很多步驟，而且每一步都要「**只用訓練集 fit**」。手動做很容易出錯（資料洩漏）。**Pipeline** 把前處理和模型包成一個物件：

```python
import pandas as pd
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

df = pd.read_csv("titanic.csv")
X = df[["Pclass", "Sex", "Age", "Fare", "Embarked", "SibSp", "Parch"]]
y = df["Survived"]

numeric = ["Age", "Fare", "SibSp", "Parch"]
categorical = ["Pclass", "Sex", "Embarked"]

preprocess = ColumnTransformer([
    ("num", Pipeline([("impute", SimpleImputer(strategy="median")), ("scale", StandardScaler())]), numeric),
    ("cat", Pipeline([("impute", SimpleImputer(strategy="most_frequent")), ("onehot", OneHotEncoder(handle_unknown="ignore"))]), categorical),
])
model = Pipeline([("prep", preprocess), ("clf", LogisticRegression(max_iter=1000))])

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)
model.fit(X_train, y_train)                  # 所有步驟一起 fit（只用訓練集）
print(f"準確率：{model.score(X_test, y_test):.3f}")

new = pd.DataFrame([{"Pclass": 1, "Sex": "female", "Age": None, "Fare": 80, "Embarked": "C", "SibSp": 0, "Parch": 0}])
print(f"生還機率：{model.predict_proba(new)[0, 1]:.0%}")   # 新資料直接丟進去，前處理自動完成
```

Pipeline 的好處：
- ✅ 自動避免資料洩漏
- ✅ 新資料不用手動前處理
- ✅ 可以整個存檔、部署（`joblib.dump(model, "model.pkl")`）
- ✅ 可以和交叉驗證、調參一起用（下一課）

## 自訂轉換：FunctionTransformer

```python
import numpy as np
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import FunctionTransformer
from sklearn.linear_model import LinearRegression

def add_features(X):
    X = X.copy()
    X["area_per_room"] = X["area"] / X["rooms"]
    X["is_new"] = (X["age"] <= 5).astype(int)
    return X

df = pd.read_csv("house_prices.csv")
X, y = df[["area", "rooms", "age", "near_mrt"]], df["price"]
model = make_pipeline(FunctionTransformer(add_features), LinearRegression()).fit(X, y)
print(f"R²（訓練集）：{model.score(X, y):.3f}")
```

from sklearn.model_selection import train_test_split
