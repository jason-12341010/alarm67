## 只切一次不夠可靠

用不同的 `random_state` 分割，結果可能差很多：

```python
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
for seed in range(6):
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=seed)
    acc = DecisionTreeClassifier(max_depth=4, random_state=0).fit(X_train, y_train).score(X_test, y_test)
    print(f"random_state={seed}：{acc:.3f}")
```

同一個模型，準確率從 0.89 到 0.96 都有！到底哪個才是真正的表現？

## K 折交叉驗證（K-Fold Cross Validation）

把資料分成 K 份，輪流用其中 1 份當測試、其他 K−1 份訓練，做 K 次，最後**取平均**：

```text
第 1 次：[測試] [訓練] [訓練] [訓練] [訓練]
第 2 次：[訓練] [測試] [訓練] [訓練] [訓練]
第 3 次：[訓練] [訓練] [測試] [訓練] [訓練]
第 4 次：[訓練] [訓練] [訓練] [測試] [訓練]
第 5 次：[訓練] [訓練] [訓練] [訓練] [測試]
```

每一筆資料都會被當過一次測試資料，結果更可靠。

```python
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import cross_val_score

X, y = load_breast_cancer(return_X_y=True)
scores = cross_val_score(DecisionTreeClassifier(max_depth=4, random_state=0), X, y, cv=5)
print("每一折：", scores.round(3))
print(f"平均 {scores.mean():.3f} ± {scores.std():.3f}")
```

## 用交叉驗證比較模型

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier

X, y = load_breast_cancer(return_X_y=True)
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)   # 分類問題：每一折的類別比例一樣
models = {
    "邏輯迴歸": make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000)),
    "KNN": make_pipeline(StandardScaler(), KNeighborsClassifier()),
    "決策樹": DecisionTreeClassifier(random_state=0),
    "隨機森林": RandomForestClassifier(n_estimators=100, random_state=0),
}
for name, m in models.items():
    s = cross_val_score(m, X, y, cv=cv, scoring="f1")
    print(f"{name:<6} F1 = {s.mean():.3f} ± {s.std():.3f}")
```

> 💡 把前處理放在 Pipeline 裡，交叉驗證時**每一折都會重新 fit 縮放器**，自動避免資料洩漏。

## 超參數

- **參數（parameter）**：模型從資料**學到**的，例如線性迴歸的係數
- **超參數（hyperparameter）**：訓練**前**由人設定的，例如樹的深度、KNN 的 K、森林的樹數量

找出最好的超參數組合，叫做**調參（hyperparameter tuning）**。

## GridSearchCV：網格搜尋

把所有可能的組合**全部試一遍**，每個組合都用交叉驗證評估：

```python
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV, train_test_split
import pandas as pd

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)

grid = GridSearchCV(
    RandomForestClassifier(random_state=0),
    param_grid={
        "n_estimators": [50, 150],
        "max_depth": [3, 6, None],
        "min_samples_leaf": [1, 5],
    },
    cv=4,
    scoring="accuracy",
)
grid.fit(X_train, y_train)                      # 2 × 3 × 2 = 12 種組合 × 4 折 = 48 次訓練
print("最佳參數：", grid.best_params_)
print(f"交叉驗證分數：{grid.best_score_:.3f}")
print(f"測試集分數：{grid.score(X_test, y_test):.3f}")   # 最後才用測試集

results = pd.DataFrame(grid.cv_results_)[["params", "mean_test_score", "rank_test_score"]]
display(results.sort_values("rank_test_score").head(5))
```

## Pipeline + 調參

在 Pipeline 裡調參，參數名稱是 `步驟名稱__參數名稱`（兩個底線）：

```python
from sklearn.datasets import load_wine
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, MinMaxScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import GridSearchCV

X, y = load_wine(return_X_y=True)
pipe = Pipeline([("scale", StandardScaler()), ("knn", KNeighborsClassifier())])
grid = GridSearchCV(pipe, {
    "scale": [StandardScaler(), MinMaxScaler()],          # 連步驟本身都可以換
    "knn__n_neighbors": [1, 3, 5, 9, 15],
    "knn__weights": ["uniform", "distance"],
}, cv=5).fit(X, y)
print(grid.best_params_)
print(f"{grid.best_score_:.3f}")
```

## RandomizedSearchCV：參數很多時

組合太多時，網格搜尋太慢。**隨機搜尋**只隨機抽一部分組合來試，通常效果差不多，但快很多：

```python
from scipy.stats import randint, uniform
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.model_selection import RandomizedSearchCV

X, y = load_breast_cancer(return_X_y=True)
search = RandomizedSearchCV(
    HistGradientBoostingClassifier(random_state=0),
    {"learning_rate": uniform(0.01, 0.3), "max_depth": randint(2, 8), "max_iter": randint(50, 300)},
    n_iter=8, cv=3, random_state=0,
).fit(X, y)
print({k: round(v, 3) if isinstance(v, float) else v for k, v in search.best_params_.items()})
print(f"{search.best_score_:.3f}")
```
