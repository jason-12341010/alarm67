機器學習最核心的挑戰：模型在**訓練資料**上表現很好，不代表在**新資料**上也會好。

## 過擬合 vs 欠擬合

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline

rng = np.random.default_rng(1)
x = np.sort(rng.uniform(0, 1, 15))
y = np.sin(2 * np.pi * x) + rng.normal(0, 0.2, 15)
xs = np.linspace(0, 1, 200)

fig, axes = plt.subplots(1, 3, figsize=(14, 4), sharey=True)
for ax, degree, title in zip(axes, [1, 4, 14], ["欠擬合：太簡單", "剛剛好", "過擬合：太複雜"]):
    model = make_pipeline(PolynomialFeatures(degree), LinearRegression()).fit(x[:, None], y)
    ax.scatter(x, y, color="#3776ab", zorder=3)
    ax.plot(xs, np.sin(2 * np.pi * xs), "g--", alpha=0.5, label="真正的規律")
    ax.plot(xs, model.predict(xs[:, None]), color="#e4572e", label=f"{degree} 次多項式")
    ax.set_ylim(-2, 2)
    ax.set_title(title)
    ax.legend(loc="lower left")
fig.tight_layout()
plt.show()
```

| | 欠擬合（Underfitting） | 過擬合（Overfitting） |
|---|---|---|
| 比喻 | 沒讀書 | 死背考古題 |
| 訓練集表現 | 差 | **非常好** |
| 測試集表現 | 差 | **差** |
| 原因 | 模型太簡單 | 模型太複雜、資料太少 |
| 解決 | 更複雜的模型、更好的特徵 | 更多資料、簡化模型、正則化 |

## 學習曲線

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)
depths = range(1, 15)
train_acc, test_acc = [], []
for d in depths:
    m = DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_train, y_train)
    train_acc.append(m.score(X_train, y_train))
    test_acc.append(m.score(X_test, y_test))

plt.plot(depths, train_acc, "o-", label="訓練集")
plt.plot(depths, test_acc, "s-", label="測試集")
plt.xlabel("模型複雜度（樹的深度）")
plt.ylabel("準確率")
plt.title("模型越複雜，訓練越好，但測試不一定")
plt.legend()
plt.show()
```

## 三份資料：訓練、驗證、測試

如果一直用測試集來**挑選模型**，其實也是一種「偷看答案」。正確的做法是分成三份：

| 資料集 | 用途 | 比例（參考） |
|---|---|---|
| **訓練集** | 訓練模型 | 60–70% |
| **驗證集** | 調整模型、挑選參數 | 15–20% |
| **測試集** | **最後**才用一次，評估真實表現 | 15–20% |

```python
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_temp, X_test, y_temp, y_test = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)
X_train, X_val, y_train, y_val = train_test_split(X_temp, y_temp, test_size=0.25, random_state=0, stratify=y_temp)
print(f"訓練 {len(X_train)}、驗證 {len(X_val)}、測試 {len(X_test)}")

best = max(range(1, 11), key=lambda d: DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_train, y_train).score(X_val, y_val))
print("用驗證集選出的最佳深度：", best)
final = DecisionTreeClassifier(max_depth=best, random_state=0).fit(X_temp, y_temp)   # 用訓練+驗證重新訓練
print(f"最終測試準確率：{final.score(X_test, y_test):.3f}")
```

第 10 課會學更好的方法：**交叉驗證**。

## 正則化：懲罰太複雜的模型

**Ridge**、**Lasso** 是加了「懲罰項」的線性迴歸：係數太大會被扣分，讓模型保持簡單：

```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.pipeline import make_pipeline

rng = np.random.default_rng(1)
x = np.sort(rng.uniform(0, 1, 20))
y = np.sin(2 * np.pi * x) + rng.normal(0, 0.2, 20)
x_test = np.linspace(0, 1, 100)
y_test = np.sin(2 * np.pi * x_test)

for name, reg in [("沒有正則化", LinearRegression()), ("Ridge", Ridge(alpha=0.01)), ("Lasso", Lasso(alpha=0.001, max_iter=50000))]:
    m = make_pipeline(PolynomialFeatures(12), StandardScaler(), reg).fit(x[:, None], y)
    coef = m[-1].coef_
    mse = ((m.predict(x_test[:, None]) - y_test) ** 2).mean()
    print(f"{name:<8} 測試 MSE {mse:8.4f}　最大係數 {np.abs(coef).max():10.1f}　係數為 0 的個數 {(np.abs(coef) < 1e-6).sum()}")
```

- **Ridge（L2）**：讓所有係數變小
- **Lasso（L1）**：會讓不重要的係數**直接變成 0**，順便做了特徵選擇

## 資料洩漏（Data Leakage）⚠️

最常見、也最危險的錯誤：**測試集的資訊不小心跑進了訓練過程**。結果模型評估看起來超好，上線後卻很爛。

```py
# ❌ 錯誤：先用全部資料計算平均和標準差，再分割
X_scaled = StandardScaler().fit_transform(X)        # 測試集的資訊已經混進來了！
X_train, X_test = train_test_split(X_scaled)

# ✅ 正確：先分割，只用訓練集 fit
X_train, X_test = train_test_split(X)
scaler = StandardScaler().fit(X_train)
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)                 # 測試集只做 transform
```

其他常見的洩漏：用「未來」的資料預測「過去」、特徵裡偷偷包含了答案（例如用「是否退款」預測「是否客訴」）。第 9 課會教 **Pipeline**，自動避免這種錯誤。
