## 傳統程式 vs 機器學習

```text
傳統程式：  規則 + 資料 → 答案
           （人寫好 if/else 規則）

機器學習：  資料 + 答案 → 規則
           （電腦從例子中自己找出規則）
```

例如判斷垃圾郵件：傳統做法要人工寫幾百條規則（「包含『免費』就是垃圾信」…），永遠寫不完。機器學習則是給電腦看**幾萬封已經標好「是/不是垃圾信」的郵件**，讓它自己學出判斷方法。

## 機器學習的三大類

| 類型 | 資料 | 目標 | 例子 |
|---|---|---|---|
| **監督式學習** | 有標準答案（標籤） | 預測答案 | 房價預測、垃圾信分類、疾病診斷 |
| **非監督式學習** | 沒有答案 | 找出資料的結構 | 客戶分群、異常偵測 |
| **強化學習** | 環境的獎勵 | 學會做決策 | 下棋 AI、自駕車、機器人 |

監督式學習又分成兩種：
- **迴歸（regression）**：預測**數字**（房價、溫度、銷售量）
- **分類（classification）**：預測**類別**（是不是垃圾信、圖片是貓還是狗）

## 名詞解釋

用一張表格來說明：

| 坪數 | 屋齡 | 離捷運 | **房價** |
|---|---|---|---|
| 30 | 5 | 300m | **1500 萬** |
| 25 | 20 | 800m | **900 萬** |

- **特徵（feature）**：用來預測的欄位，習慣叫 **X**（坪數、屋齡、離捷運）
- **標籤 / 目標（label / target）**：要預測的答案，習慣叫 **y**（房價）
- **樣本（sample）**：每一列資料
- **模型（model）**：從資料學到的「規則」
- **訓練（fit / train）**：讓模型從資料中學習
- **預測（predict）**：用學好的模型，對新資料做出預測

## scikit-learn：Python 機器學習的標準工具

**scikit-learn**（`sklearn`）提供幾十種演算法，而且**所有模型的用法都一樣**：

```py
model = 某種模型()          # 1. 建立模型
model.fit(X_train, y_train)   # 2. 訓練
model.predict(X_new)          # 3. 預測
model.score(X_test, y_test)   # 4. 評估
```

學會一個，就等於學會全部！

## 第一個機器學習模型

用 scikit-learn 內建的**鳶尾花資料集**：根據花瓣和花萼的長寬，判斷是哪一種鳶尾花。

> 💡 第一次載入 scikit-learn 需要下載，大約 10 秒。

```python
from sklearn.datasets import load_iris
import pandas as pd

iris = load_iris(as_frame=True)
df = iris.frame
df["species"] = df["target"].map(dict(enumerate(iris.target_names)))
display(df.sample(6, random_state=0))
print(df["species"].value_counts())
```

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

X, y = load_iris(return_X_y=True)

# 把資料分成「訓練用」和「測試用」：用沒看過的資料來考試，才知道模型是不是真的學會了
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
print("訓練資料：", X_train.shape, "測試資料：", X_test.shape)

model = DecisionTreeClassifier(random_state=42)    # 1. 建立模型
model.fit(X_train, y_train)                         # 2. 訓練
pred = model.predict(X_test)                        # 3. 預測
print("預測：", pred[:10])
print("答案：", y_test[:10])
print(f"準確率：{model.score(X_test, y_test):.1%}")  # 4. 評估
```

就這樣，你訓練出第一個機器學習模型了！🎉

## 預測新的資料

```python
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier

iris = load_iris()
model = DecisionTreeClassifier(random_state=0).fit(iris.data, iris.target)

new_flowers = [
    [5.0, 3.4, 1.5, 0.2],    # 花萼長、花萼寬、花瓣長、花瓣寬（公分）
    [6.7, 3.0, 5.2, 2.3],
    [5.9, 2.8, 4.3, 1.3],
]
for flower, p, proba in zip(new_flowers, model.predict(new_flowers), model.predict_proba(new_flowers)):
    print(flower, "→", iris.target_names[p], f"（信心 {proba.max():.0%}）")
```

## 為什麼要分訓練集和測試集？

想像學生考試：如果考題和練習題**一模一樣**，100 分也不代表真的學會了，可能只是**背答案**。

模型也一樣，一定要用**沒看過的資料**評估，才能知道它在真實世界的表現。第 5 課會深入討論這個問題（**過擬合**）。

## 機器學習專案的流程

```text
1. 定義問題：要預測什麼？迴歸還是分類？用什麼評估？
2. 收集資料
3. 探索資料（EDA）：第 7 階段學的技巧
4. 資料前處理：清理、處理缺值、轉換特徵
5. 分割資料：訓練集 / 測試集
6. 選擇模型、訓練
7. 評估、調整
8. 部署：讓模型真的被使用
```

from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

X, y = load_wine(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0)
model = DecisionTreeClassifier(random_state=0)
model.fit(X_train, y_train)

accuracy = model.score(X_test, y_test)
pred_first = model.predict(X_test[:1])[0]
