## 決策樹：像玩「20 個問題」

決策樹透過一連串的**是非題**來做判斷，和人類思考的方式很像，所以**非常好解釋**：

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree, export_text
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("titanic.csv")
df["is_female"] = (df["Sex"] == "female").astype(int)
df["Age"] = df["Age"].fillna(df["Age"].median())
features = ["is_female", "Pclass", "Age", "Fare"]
tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(df[features], df["Survived"])

print(export_text(tree, feature_names=features))
plt.figure(figsize=(14, 6))
plot_tree(tree, feature_names=features, class_names=["死亡", "生還"], filled=True, rounded=True, fontsize=9)
plt.show()
```

## 樹是怎麼長出來的？

每一步，樹會找出「**最能把資料分乾淨**」的問題。「乾淨」用**吉尼不純度（Gini impurity）** 衡量：一群資料如果全部是同一類，不純度是 0；兩類各半，不純度最高（0.5）。

```python
def gini(labels):
    n = len(labels)
    if n == 0:
        return 0
    p = sum(labels) / n
    return 1 - p ** 2 - (1 - p) ** 2

print("全部生還：", gini([1, 1, 1, 1]))
print("一半一半：", gini([1, 0, 1, 0]))
print("大部分生還：", round(gini([1, 1, 1, 0]), 3))

# 比較兩種切法哪個好
import pandas as pd
df = pd.read_csv("titanic.csv")
for name, mask in [("性別", df["Sex"] == "female"), ("是否頭等艙", df["Pclass"] == 1)]:
    left, right = df[mask]["Survived"], df[~mask]["Survived"]
    weighted = (len(left) * gini(list(left)) + len(right) * gini(list(right))) / len(df)
    print(f"用「{name}」切分後的加權不純度：{weighted:.3f}")
```

用「性別」切，不純度降得更多，所以樹的第一個問題就是性別。

## 特徵重要性

```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("titanic.csv")
df["is_female"] = (df["Sex"] == "female").astype(int)
df["Age"] = df["Age"].fillna(df["Age"].median())
features = ["is_female", "Pclass", "Age", "Fare", "SibSp", "Parch"]
tree = DecisionTreeClassifier(max_depth=5, random_state=0).fit(df[features], df["Survived"])
imp = pd.Series(tree.feature_importances_, index=features).sort_values(ascending=False)
print(imp.round(3))
```

## 決策樹的優缺點

| 優點 ✅ | 缺點 ❌ |
|---|---|
| 好解釋，可以畫出來 | **很容易過擬合** |
| 不需要特徵縮放 | 資料稍微改變，樹可能完全不同（不穩定） |
| 可以處理非線性關係 | 單棵樹的準確率通常不是最好 |

## 隨機森林：三個臭皮匠，勝過一個諸葛亮

**隨機森林（Random Forest）** 訓練**很多棵**不同的決策樹，最後**投票**決定答案：
1. 每棵樹用**隨機抽樣**的資料訓練（bootstrap）
2. 每次切分只考慮**隨機一部分**的特徵

因為每棵樹都不太一樣，它們犯的錯也不一樣，投票之後錯誤會互相抵消。這種方法叫做**集成學習（Ensemble Learning）**。

```python
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)

tree = DecisionTreeClassifier(random_state=0).fit(X_train, y_train)
forest = RandomForestClassifier(n_estimators=200, random_state=0).fit(X_train, y_train)
print(f"單棵決策樹：訓練 {tree.score(X_train, y_train):.3f}，測試 {tree.score(X_test, y_test):.3f}")
print(f"隨機森林：  訓練 {forest.score(X_train, y_train):.3f}，測試 {forest.score(X_test, y_test):.3f}")
```

## 樹的數量越多越好嗎？

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)
ns_ = [1, 3, 5, 10, 25, 50, 100, 200]
scores = [RandomForestClassifier(n_estimators=n, random_state=0).fit(X_train, y_train).score(X_test, y_test) for n in ns_]
plt.plot(ns_, scores, "o-")
plt.xscale("log")
plt.xlabel("樹的數量")
plt.ylabel("測試準確率")
plt.title("樹越多越穩定，但到一定數量後就不太會再進步")
plt.show()
```

## 梯度提升（Gradient Boosting）

另一種集成方法：一棵一棵**依序**訓練，每棵新的樹專門修正前面的樹**犯的錯**。在表格資料的比賽（像 Kaggle）中，**梯度提升幾乎是最強的方法**。著名的實作有 **XGBoost**、**LightGBM**、**CatBoost**：

```python
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import HistGradientBoostingClassifier, RandomForestClassifier
from sklearn.model_selection import train_test_split

X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)
for name, m in [("隨機森林", RandomForestClassifier(n_estimators=200, random_state=0)),
                ("梯度提升", HistGradientBoostingClassifier(random_state=0))]:
    print(f"{name}：{m.fit(X_train, y_train).score(X_test, y_test):.3f}")
```

> 💡 **表格資料**（Excel 那種）首選樹模型（隨機森林、梯度提升）；**圖片、文字、聲音**則是深度學習的天下。
