前面學的都是**監督式學習**（有標準答案）。這一課進入**非監督式學習**：資料**沒有答案**，讓電腦自己找出資料裡的**群組**。

應用：**客戶分群**（行銷）、圖片壓縮、文件主題分類、異常偵測…

## K-Means 的演算法

1. 隨機放 K 個**中心點**
2. 每個點分配給**最近的中心點**
3. 把每個中心點移到它那一群的**平均位置**
4. 重複 2～3，直到中心點不再移動

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(4)
X = np.vstack([rng.normal(c, 0.6, (40, 2)) for c in [(1, 1), (5, 2), (3, 5)]])
centers = X[rng.choice(len(X), 3, replace=False)]

fig, axes = plt.subplots(1, 4, figsize=(16, 3.8))
for step, ax in enumerate(axes):
    labels = np.argmin(((X[:, None] - centers[None]) ** 2).sum(axis=2), axis=1)   # 分配到最近的中心
    ax.scatter(X[:, 0], X[:, 1], c=labels, cmap="viridis", s=15)
    ax.scatter(centers[:, 0], centers[:, 1], c="red", marker="X", s=200)
    ax.set_title(f"第 {step + 1} 次迭代")
    centers = np.array([X[labels == k].mean(axis=0) for k in range(3)])          # 移到平均位置
fig.tight_layout()
plt.show()
```

## 用 scikit-learn

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=0)
km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X)
plt.scatter(X[:, 0], X[:, 1], c=km.labels_, cmap="tab10", s=15)
plt.scatter(*km.cluster_centers_.T, c="black", marker="X", s=200)
plt.title("K-Means 分群結果")
plt.show()
print("每群的數量：", np.bincount(km.labels_))
print("新的點屬於哪一群：", km.predict([[0, 4], [2, 1]]))
```

## 要分幾群？手肘法

K 要自己決定。畫出不同 K 的「**群內距離平方和**」（inertia），找下降趨勢變平緩的「**手肘**」：

```python
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
from sklearn.metrics import silhouette_score

X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=0)
ks = range(2, 10)
inertias, sils = [], []
for k in ks:
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    inertias.append(km.inertia_)
    sils.append(silhouette_score(X, km.labels_))

fig, axes = plt.subplots(1, 2, figsize=(11, 3.8))
axes[0].plot(ks, inertias, "o-")
axes[0].set(title="手肘法：找轉折點", xlabel="K", ylabel="inertia")
axes[1].plot(ks, sils, "s-", color="#e4572e")
axes[1].set(title="輪廓係數：越高越好", xlabel="K", ylabel="silhouette")
fig.tight_layout()
plt.show()
print("輪廓係數最高的 K：", list(ks)[sils.index(max(sils))])
```

**輪廓係數（silhouette score）**：範圍 −1 到 1，衡量每個點「和自己群的距離」相對於「和其他群的距離」。越接近 1，分得越好。

## 實戰：客戶分群

用第 7 階段的商店資料，依照消費行為把客戶分群：

```python
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]
customers = df.groupby("customer").agg(
    次數=("order_id", "count"),
    總消費=("revenue", "sum"),
    平均單價=("price", "mean"),
    買3C比例=("category", lambda s: (s == "3C").mean()),
)
X = StandardScaler().fit_transform(customers)          # K-Means 用距離，一定要縮放！
km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X)
customers["群組"] = km.labels_

profile = customers.groupby("群組").mean().round(2)
profile["人數"] = customers["群組"].value_counts().sort_index()
display(profile)

plt.scatter(customers["次數"], customers["總消費"], c=customers["群組"], cmap="tab10", alpha=0.7)
plt.xlabel("購買次數")
plt.ylabel("總消費（元）")
plt.title("客戶分群")
plt.show()
```

看著每一群的平均特徵，就可以幫它們取名字，例如「3C 愛好者」、「高消費常客」，再設計不同的行銷策略。

## PCA：降維與視覺化

資料有很多個特徵時，沒辦法直接畫圖。**PCA（主成分分析）** 可以把高維資料**壓縮成 2 維**，同時保留最多的資訊：

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_wine
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X, y = load_wine(return_X_y=True)                 # 13 個特徵
X2 = PCA(n_components=2).fit(StandardScaler().fit_transform(X))
Z = X2.transform(StandardScaler().fit_transform(X))
print("兩個主成分保留了", f"{X2.explained_variance_ratio_.sum():.0%}", "的資訊")
plt.scatter(Z[:, 0], Z[:, 1], c=y, cmap="viridis", s=20)
plt.title("13 維的葡萄酒資料，壓縮成 2 維")
plt.xlabel("主成分 1")
plt.ylabel("主成分 2")
plt.show()
```

## K-Means 的限制

```python
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans, DBSCAN
from sklearn.datasets import make_moons

X, _ = make_moons(n_samples=300, noise=0.06, random_state=0)
fig, axes = plt.subplots(1, 2, figsize=(10, 3.8))
axes[0].scatter(*X.T, c=KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(X), cmap="coolwarm", s=12)
axes[0].set_title("K-Means：只能切出圓形的群")
axes[1].scatter(*X.T, c=DBSCAN(eps=0.2).fit_predict(X), cmap="coolwarm", s=12)
axes[1].set_title("DBSCAN：依照密度，可以找出任意形狀")
fig.tight_layout()
plt.show()
```
