LLM 很聰明，但它**不知道你的資料**：公司的規章、產品說明書、你的筆記… 而且被問到不知道的事，它有時會**編造答案**（幻覺）。

**RAG（Retrieval-Augmented Generation，檢索增強生成）** 是目前最常用的解決方法：

```text
使用者的問題
     ↓
1. 檢索（Retrieval）：用語意搜尋，從你的文件中找出最相關的幾段
     ↓
2. 增強（Augmented）：把找到的段落 + 問題，組合成提示詞
     ↓
3. 生成（Generation）：LLM 根據這些資料回答
```

模型不需要重新訓練，**更新文件就能更新知識**，而且可以附上**資料來源**。

## Step 1：切塊（Chunking）

文件通常很長，要先切成小段落。每段太長會混入不相關的內容，太短又會缺少上下文。常見的做法是**固定長度 + 重疊**：

```python
def chunk_text(text, size=60, overlap=15):
    chunks = []
    start = 0
    while start < len(text):
        chunks.append(text[start:start + size])
        if start + size >= len(text):
            break
        start += size - overlap          # 和上一塊重疊一部分，避免句子被切斷
    return chunks

text = "第一條：員工每年享有特休假。到職滿半年有 3 天、滿一年有 7 天。第二條：請假需在三天前提出申請，病假可以事後補請。第三條：加班費依勞基法計算，平日前兩小時為 1.34 倍。"
for i, c in enumerate(chunk_text(text, 40, 10)):
    print(i, c)
```

比較好的做法是**依照段落或句子**切，保持語意完整：

```python
import re

def chunk_by_sentence(text, max_chars=60):
    sentences = [s for s in re.split(r"(?<=[。！？\n])", text) if s.strip()]
    chunks, current = [], ""
    for s in sentences:
        if len(current) + len(s) > max_chars and current:
            chunks.append(current)
            current = ""
        current += s
    if current:
        chunks.append(current)
    return chunks

text = "第一條：員工每年享有特休假。到職滿半年有 3 天、滿一年有 7 天。第二條：請假需在三天前提出申請，病假可以事後補請。第三條：加班費依勞基法計算，平日前兩小時為 1.34 倍。"
for c in chunk_by_sentence(text, 40):
    print("•", c)
```

## Step 2 + 3：檢索、組合提示詞

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer

handbook = [
    "【特休假】到職滿半年有 3 天特休，滿一年 7 天，滿兩年 10 天，滿三年 14 天。",
    "【請假】事假需在三天前提出申請。病假可以事後補請，但需附上診斷證明。",
    "【加班】平日加班前兩小時，加班費為時薪的 1.34 倍，之後為 1.67 倍。",
    "【遠端工作】每週最多可以遠端工作兩天，需事先在系統登記。",
    "【報帳】出差的交通與住宿費用，需在回來後 14 天內檢附收據報帳。",
    "【健康檢查】公司每年提供一次免費健康檢查，可以選擇合作的三家醫院。",
]

vectorizer = TfidfVectorizer(analyzer="char", ngram_range=(1, 2)).fit(handbook)
doc_vecs = vectorizer.transform(handbook).toarray()

def retrieve(question, k=2):
    q = vectorizer.transform([question]).toarray()[0]
    sims = doc_vecs @ q / (np.linalg.norm(doc_vecs, axis=1) * np.linalg.norm(q) + 1e-9)
    return [(handbook[i], sims[i]) for i in np.argsort(-sims)[:k]]

def build_rag_prompt(question, k=2):
    docs = retrieve(question, k)
    context = "\n".join(f'<doc id="{i + 1}">{d}</doc>' for i, (d, _) in enumerate(docs))
    return f"""請根據下面的公司規章回答員工的問題。
如果規章裡沒有相關資訊，請回答「規章中沒有提到，請洽人資部」，不要自己猜。
回答時標註參考的文件編號，例如 [1]。

<documents>
{context}
</documents>

問題：{question}"""

for d, s in retrieve("我剛來八個月，可以休幾天假？"):
    print(f"{s:.3f} {d}")
print()
print(build_rag_prompt("我剛來八個月，可以休幾天假？"))
```

最後把這個提示詞傳給 LLM，它就會根據規章回答：「到職滿半年有 3 天特休 [1]」。

## 完整的 RAG（在自己的電腦執行）

```py
import anthropic
import numpy as np
from sentence_transformers import SentenceTransformer

client = anthropic.Anthropic()
embedder = SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")

handbook = [...]                                   # 你的文件切塊
doc_vecs = embedder.encode(handbook, normalize_embeddings=True)

def answer(question, k=3):
    q = embedder.encode([question], normalize_embeddings=True)[0]
    top = np.argsort(-(doc_vecs @ q))[:k]
    context = "\n".join(f'<doc id="{i + 1}">{handbook[j]}</doc>' for i, j in enumerate(top))
    response = client.messages.create(
        model="claude-opus-5-5",
        max_tokens=4096,
        system="你是公司的人資助理。只根據提供的文件回答，沒有相關資訊就說不知道。回答時標註文件編號。",
        messages=[{"role": "user", "content": f"<documents>\n{context}\n</documents>\n\n問題：{question}"}],
    )
    return "".join(b.text for b in response.content if b.type == "text")

print(answer("出差的錢要多久內報帳？"))
```

## 讓 RAG 更好的技巧

| 問題 | 改善方法 |
|---|---|
| 找到的段落不相關 | 更好的 embedding 模型；**混合搜尋**（關鍵字 + 語意）；**重新排序（rerank）** |
| 段落缺少上下文 | 切塊時加上標題、文件名稱；增加重疊 |
| 模型還是亂回答 | 提示詞明確要求「沒有就說不知道」；要求引用來源 |
| 問題需要多份文件 | 增加 k；讓模型先把問題拆解成子問題 |
| 不知道好不好 | 建立**評估集**：問題 + 正確答案 + 應該找到的文件 |

> 💡 現在的 LLM 上下文長度很長（Claude 可以到一百萬個 token），如果你的文件**不多**（例如幾十頁），直接全部放進提示詞，有時比 RAG 更簡單、效果更好。文件很多時才需要 RAG。
