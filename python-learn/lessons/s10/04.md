傳統的搜尋是比對**關鍵字**：搜尋「便宜的筆電」，找不到寫著「平價 laptop」的文章。**語意搜尋**則是比對**意思**，這要靠 **Embeddings（嵌入向量）**。

## Embedding 是什麼？

把一段文字轉換成一個**向量**（一串數字，例如 1024 個）。訓練好的 embedding 模型會讓**意思相近的文字，向量也相近**。第 9 階段的「國王 − 男人 + 女人 ≈ 皇后」就是這個概念。

```text
「便宜的筆電」   → [0.12, -0.53, 0.88, …]  ┐
「平價 laptop」  → [0.10, -0.49, 0.91, …]  ┘ 很接近！
「今天天氣很好」 → [-0.71, 0.33, 0.02, …]    很遠
```

## 怎麼比較兩個向量？餘弦相似度

計算兩個向量的**夾角**：方向一樣是 1，完全無關是 0：

```python
import numpy as np

def cosine_similarity(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

a = np.array([1.0, 2.0, 3.0])
print(cosine_similarity(a, a * 10))            # 方向一樣 → 1
print(cosine_similarity(a, np.array([3.0, 2.0, 1.0])))
print(cosine_similarity(np.array([1.0, 0.0]), np.array([0.0, 1.0])))   # 垂直 → 0
```

## 在網頁上體驗：用 TF-IDF 做向量搜尋

真正的 embedding 模型需要下載或呼叫 API。為了在網頁上體驗**整個流程**，我們先用比較簡單的 **TF-IDF** 把文字變成向量（以字和詞的出現頻率計算）。流程和真正的語意搜尋**完全一樣**：

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer

docs = [
    "Python 是一種容易學習的程式語言，很適合初學者",
    "機器學習可以讓電腦從資料中自己學習規則",
    "台北 101 是台灣最高的建築，也是知名的觀光景點",
    "深度學習使用多層的神經網路來辨識圖片和語音",
    "珍珠奶茶起源於台灣，在世界各地都很受歡迎",
    "pandas 是 Python 處理表格資料最常用的套件",
]

# 中文沒有空白分詞，用「字元 1～2 個字一組」當作詞
vectorizer = TfidfVectorizer(analyzer="char", ngram_range=(1, 2))
doc_vectors = vectorizer.fit_transform(docs).toarray()     # 每篇文件 → 一個向量
print("向量的形狀：", doc_vectors.shape)

def search(query, k=2):
    q = vectorizer.transform([query]).toarray()[0]
    sims = doc_vectors @ q / (np.linalg.norm(doc_vectors, axis=1) * np.linalg.norm(q) + 1e-9)
    for i in np.argsort(-sims)[:k]:
        print(f"  {sims[i]:.3f}  {docs[i]}")

for q in ["怎麼用 Python 分析資料", "台灣有什麼好喝的飲料", "神經網路"]:
    print(f"🔍 {q}")
    search(q)
```

TF-IDF 只看「用了哪些字」，所以「好喝的飲料」能找到奶茶，是因為剛好都有「台灣」。真正的 embedding 模型理解**意思**，就算一個字都不一樣也找得到。

```py
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")    # 支援中文
sentences = ["便宜的筆電", "平價的 laptop", "今天天氣很好"]
vectors = model.encode(sentences, normalize_embeddings=True)
print(vectors.shape)                     # (3, 384)
print(vectors @ vectors.T)               # 正規化後，內積就是餘弦相似度
```

## 向量資料庫

文件有幾百萬篇時，一個一個比對太慢了。**向量資料庫**專門用來快速找出最相似的向量：

| 工具 | 特色 |
|---|---|
| **NumPy** | 幾千篇以內，直接矩陣運算就夠了 |
| **FAISS** | Meta 開發的函式庫，超快 |
| **Chroma** | 簡單易用，適合原型開發 |
| **pgvector** | PostgreSQL 的擴充，已經在用 Postgres 的首選 |
| Pinecone、Qdrant、Weaviate | 雲端或獨立的向量資料庫服務 |

## Embedding 的應用

- 🔍 **語意搜尋**：找出意思相關的文件
- 📚 **RAG**：讓 LLM 根據你的資料回答問題（下一課！）
- 🎯 **推薦系統**：找出相似的商品、文章
- 🗂️ **分群**：把大量文件自動分類（第 8 階段的 K-Means）
- 🔁 **去重複**：找出內容幾乎一樣的資料

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer

questions = [
    "如何重設密碼？", "忘記密碼怎麼辦", "密碼忘了要怎麼改",
    "運費怎麼計算", "寄到外島要多少運費", "可以貨到付款嗎",
]
v = TfidfVectorizer(analyzer="char", ngram_range=(1, 2)).fit_transform(questions).toarray()
v = v / np.linalg.norm(v, axis=1, keepdims=True)
sim = v @ v.T
for i in range(len(questions)):
    for j in range(i + 1, len(questions)):
        if sim[i, j] > 0.3:
            print(f"可能重複（{sim[i, j]:.2f}）：「{questions[i]}」≈「{questions[j]}」")
```
