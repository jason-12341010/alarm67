## Gradio：最快做出 AI Demo

Hugging Face 上幾萬個 AI Demo 都是用 Gradio 做的。核心概念：**一個函式 + 輸入元件 + 輸出元件**：

```py
import gradio as gr

def greet(name, intensity):
    return "哈囉，" + name + "！" * int(intensity)

demo = gr.Interface(
    fn=greet,
    inputs=[gr.Textbox(label="你的名字"), gr.Slider(1, 10, value=3, label="熱情程度")],
    outputs=gr.Textbox(label="結果"),
    title="打招呼產生器",
)
demo.launch()          # 打開 http://127.0.0.1:7860；加上 share=True 會產生公開網址
```

### 把 AI 模型包成 Demo

```py
import gradio as gr
from transformers import pipeline

clf = pipeline("sentiment-analysis", model="lxyuan/distilbert-base-multilingual-cased-sentiments-student")

def analyze(text):
    result = clf(text)[0]
    return {result["label"]: result["score"]}

gr.Interface(
    fn=analyze,
    inputs=gr.Textbox(lines=3, placeholder="輸入一則評論…"),
    outputs=gr.Label(),
    examples=["這家店的服務超好！", "東西壞掉了，很失望"],
    title="評論情緒分析",
).launch()
```

### 聊天機器人：ChatInterface

```py
import gradio as gr
import anthropic

client = anthropic.Anthropic()

def to_messages(history):
    """把 Gradio 的對話紀錄轉成 API 的格式（新版是字典、舊版是 [使用者, AI] 一對一對）"""
    messages = []
    for m in history:
        if isinstance(m, dict):
            messages.append({"role": m["role"], "content": m["content"]})
        else:
            user, bot = m
            messages.append({"role": "user", "content": user})
            if bot:
                messages.append({"role": "assistant", "content": bot})
    return messages

def respond(message, history):
    messages = to_messages(history)
    messages.append({"role": "user", "content": message})
    reply = ""
    with client.messages.stream(model="claude-opus-5-5", max_tokens=8000, messages=messages) as stream:
        for text in stream.text_stream:
            reply += text
            yield reply                      # 用 yield 一段一段更新，就有打字的效果

gr.ChatInterface(respond, title="我的 AI 助理").launch()
```

## Streamlit：做資料應用和儀表板

Streamlit 的寫法像在寫一般的腳本，**由上往下執行**，每次使用者操作都會**重新執行整個程式**。很適合做資料分析的儀表板（結合第 7 階段學的 pandas）：

```py
# 存成 app.py，執行：streamlit run app.py
import streamlit as st
import pandas as pd

st.title("📊 商店營收儀表板")
df = pd.read_csv("shop_orders.csv", parse_dates=["date"])
df["revenue"] = df["price"] * df["qty"]

city = st.sidebar.multiselect("選擇城市", df["city"].unique(), default=list(df["city"].unique()))
filtered = df[df["city"].isin(city)]

col1, col2, col3 = st.columns(3)
col1.metric("總營收", f"{filtered['revenue'].sum():,} 元")
col2.metric("訂單數", len(filtered))
col3.metric("平均客單價", f"{filtered['revenue'].mean():,.0f} 元")

st.line_chart(filtered.groupby(filtered["date"].dt.month)["revenue"].sum())
st.dataframe(filtered.head(20))
```

### Streamlit 聊天機器人

```py
import streamlit as st
import anthropic

client = anthropic.Anthropic()
st.title("💬 AI 助理")

if "messages" not in st.session_state:          # session_state：跨重新執行保存資料
    st.session_state.messages = []

for m in st.session_state.messages:              # 顯示之前的對話
    with st.chat_message(m["role"]):
        st.write(m["content"])

if prompt := st.chat_input("想問什麼？"):
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.write(prompt)

    def stream_reply():
        with client.messages.stream(model="claude-opus-5-5", max_tokens=8000,
                                    messages=st.session_state.messages) as stream:
            yield from stream.text_stream

    with st.chat_message("assistant"):
        reply = st.write_stream(stream_reply())    # 邊產生邊顯示，並回傳完整文字
    st.session_state.messages.append({"role": "assistant", "content": reply})
```

## Gradio vs Streamlit

| | Gradio | Streamlit |
|---|---|---|
| 擅長 | **AI 模型的 Demo**（輸入 → 輸出） | **資料儀表板**、多頁面的工具 |
| 寫法 | 定義函式和元件 | 由上往下的腳本 |
| 分享 | `share=True` 一鍵產生公開網址；Hugging Face Spaces | Streamlit Community Cloud |

兩個都可以**免費部署**到網路上：Gradio 用 [Hugging Face Spaces](https://huggingface.co/spaces)，Streamlit 用 [Streamlit Community Cloud](https://streamlit.io/cloud)。部署時記得把 API 金鑰設定在平台的「Secrets」裡，不要寫進程式碼。

> 💡 Gradio 4～5 版的對話紀錄預設是「一對一對」的格式，Gradio 6 改成字典格式。上面的 `to_messages` 兩種都能處理（本課最後的練習就是在寫這個轉換！）。

## 在網頁上練習：串流的原理

Gradio 和 Streamlit 的串流，都是用 Python 的**產生器**（第 4 階段學過！）：

```python
import time

def fake_stream(text):
    for ch in text:
        time.sleep(0.03)        # 模擬模型一個字一個字產生
        yield ch

reply = ""
for piece in fake_stream("你好！我是你的 AI 助理，有什麼可以幫忙的嗎？"):
    reply += piece
print(reply)
print(f"共 {len(reply)} 個字")
```

:::exercise 轉換對話格式
不同的套件，對話紀錄的格式不一樣。舊版的 Gradio 用「**一對一對**」的格式：`[[使用者的話, AI 的回答], ...]`（AI 還沒回答時是 `None`）；API 則是 `[{"role": ..., "content": ...}, ...]`。

寫函式 `pairs_to_messages(pairs)`，把前者轉成後者。`None` 的回答要跳過。
@@starter
def pairs_to_messages(pairs):
    pass


print(pairs_to_messages([["你好", "哈囉！"], ["你是誰？", "我是 AI 助理"], ["再見", None]]))

`for user, bot in pairs:` 先 append 使用者的話，`if bot is not None:` 再 append AI 的回答。
@@solution
def pairs_to_messages(pairs):
    messages = []
    for user, bot in pairs:
        messages.append({"role": "user", "content": user})
        if bot is not None:
            messages.append({"role": "assistant", "content": bot})
    return messages
