開源模型很好，但最強大的大型語言模型（LLM），像 **Claude**、GPT、Gemini，通常是透過 **API** 使用：你的程式把文字傳到雲端，模型產生回答再傳回來。這一課以 Anthropic 的 **Claude API** 為例。

> 📄 這一課的程式需要 **API 金鑰**和網路，請在自己的電腦或 Colab 執行。網頁上的範例和練習會練習**組合訊息**、**處理回應**這些必備技巧。

## 準備工作

### 1. 取得 API 金鑰

1. 到 Claude 開發者平台（[platform.claude.com](https://platform.claude.com)）註冊帳號
2. 在 **API Keys** 頁面建立一把金鑰（長得像 `sk-ant-...`）
3. API 是**依用量計費**的，要先儲值少量金額（一般練習用幾美元就夠用很久）

> ⚠️ **API 金鑰就像密碼**：不要寫在程式碼裡、不要上傳到 GitHub、不要分享給別人。外洩的話別人可以用你的錢呼叫 API。

### 2. 把金鑰設成環境變數

```bash
# Windows（PowerShell）
$env:ANTHROPIC_API_KEY="sk-ant-你的金鑰"

# Mac / Linux
export ANTHROPIC_API_KEY="sk-ant-你的金鑰"
```

也可以把它寫在專案的 `.env` 檔，再用 `python-dotenv` 載入（記得把 `.env` 加進 `.gitignore`）。

### 3. 安裝 SDK

```bash
pip install anthropic
```

## 第一次呼叫

```py
import anthropic

client = anthropic.Anthropic()          # 自動讀取環境變數 ANTHROPIC_API_KEY

response = client.messages.create(
    model="claude-opus-5-5",            # 使用的模型
    max_tokens=4096,                    # 回答最多幾個 token
    messages=[
        {"role": "user", "content": "用一句話解釋什麼是機器學習"},
    ],
)
for block in response.content:          # 回應是一串「內容區塊」
    if block.type == "text":
        print(block.text)
print(response.usage)                   # 用了多少 token（決定費用）
```

## 訊息的格式

`messages` 是一個串列，每則訊息有 `role`（角色）和 `content`（內容）：
- `"user"`：使用者說的話
- `"assistant"`：模型的回答

**API 不會記得之前的對話！** 每次呼叫都要把**完整的對話紀錄**傳過去：

```py
import anthropic

client = anthropic.Anthropic()
history = []

def chat(user_text):
    history.append({"role": "user", "content": user_text})
    response = client.messages.create(model="claude-opus-5-5", max_tokens=4096, messages=history)
    reply = "".join(b.text for b in response.content if b.type == "text")
    history.append({"role": "assistant", "content": reply})      # 把回答也存進紀錄
    return reply

print(chat("我叫小明，我正在學 Python"))
print(chat("我叫什麼名字？我在學什麼？"))          # 因為有傳紀錄，它會記得
```

## 系統提示（System Prompt）

`system` 參數設定模型的**角色、規則、語氣**，影響整段對話：

```py
response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=4096,
    system="你是一位有耐心的 Python 老師，學生是高中生。用繁體中文回答，每次回答都附上一個簡短的程式範例。",
    messages=[{"role": "user", "content": "什麼是串列推導式？"}],
)
```

## 串流（Streaming）：一個字一個字顯示

回答比較長時，等全部產生完才顯示會等很久。**串流**可以邊產生邊顯示，就像 ChatGPT 和 Claude 網頁版的效果：

```py
with client.messages.stream(
    model="claude-opus-5-5",
    max_tokens=4096,
    messages=[{"role": "user", "content": "寫一首關於 Python 的短詩"}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

## 重要參數與概念

| 名詞 | 意思 |
|---|---|
| **token** | 模型處理文字的單位。中文大約一個字 1～2 個 token |
| **max_tokens** | 回答的長度上限（新模型會先「思考」，思考也算在裡面），到了就會被截斷（`stop_reason` 會是 `"max_tokens"`），不要設太小 |
| **上下文長度（context window）** | 一次能處理的 token 總數（輸入 + 輸出） |
| **stop_reason** | 為什麼停止：`"end_turn"` 正常結束、`"max_tokens"` 被截斷、`"tool_use"` 要使用工具 |
| **費用** | 依照輸入和輸出的 token 數計費，輸出通常比較貴 |

## 錯誤處理

網路服務一定會遇到錯誤：網路斷線、請求太頻繁、伺服器忙碌… SDK 會**自動重試**幾次，但你還是要處理最後的失敗：

```py
import anthropic

client = anthropic.Anthropic()
try:
    response = client.messages.create(
        model="claude-opus-5-5",
        max_tokens=4096,
        messages=[{"role": "user", "content": "你好"}],
    )
except anthropic.AuthenticationError:
    print("API 金鑰錯誤，檢查環境變數")
except anthropic.RateLimitError:
    print("請求太頻繁了，等一下再試")
except anthropic.APIConnectionError:
    print("連不上伺服器，檢查網路")
except anthropic.APIStatusError as e:
    print(f"API 錯誤：{e.status_code}")
else:
    if response.stop_reason == "max_tokens":
        print("⚠️ 回答被截斷了，可以把 max_tokens 調大")
    if response.stop_reason == "refusal":
        print("模型拒絕回答這個請求")
```

### 拒絕回答時自動換模型（進階）

模型的安全機制偶爾會**誤判**一般的請求而拒絕回答（`stop_reason` 是 `"refusal"`）。Claude API 有一個「**伺服器端備援**」功能：被拒絕時，自動改用其他模型回答，你的程式不用另外處理：

```py
response = client.beta.messages.create(
    model="claude-opus-5-5",
    max_tokens=4096,
    betas=["server-side-fallback-2026-07-01"],
    fallbacks="default",                    # 被拒絕時由 API 自動挑選備援模型
    messages=[{"role": "user", "content": "你好"}],
)
```

## 在網頁上練習：管理對話紀錄

在這個網站沒辦法真的呼叫 API，但**管理訊息**是每個 AI 應用都要寫的程式。用一個「假的模型」來練習：

```python
def fake_llm(messages):
    """假裝是 LLM：重複最後一句話，並說出這是第幾輪"""
    last = messages[-1]["content"]
    turn = sum(1 for m in messages if m["role"] == "user")
    return f"（第 {turn} 輪）你說了：「{last}」"

history = []
for text in ["你好", "我在學 Python", "掰掰"]:
    history.append({"role": "user", "content": text})
    reply = fake_llm(history)
    history.append({"role": "assistant", "content": reply})
    print(reply)

print("\n傳給 API 的完整紀錄：")
for m in history:
    print(f"  {m['role']:<10}{m['content']}")
```
