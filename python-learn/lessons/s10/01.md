## pipeline：一行使用 AI 模型

`pipeline` 會自動下載模型、處理前後的轉換：

```py
from transformers import pipeline

# 情緒分析
clf = pipeline("sentiment-analysis", model="lxyuan/distilbert-base-multilingual-cased-sentiments-student")
print(clf(["這家餐廳超好吃，服務也很棒！", "等了一個小時，東西還是冷的。"]))
# [{'label': 'positive', 'score': 0.97...}, {'label': 'negative', 'score': 0.93...}]
```

第一次執行會下載模型（幾百 MB），之後就會存在電腦裡。

## 常用的 pipeline 任務

| 任務 | 名稱 | 用途 |
|---|---|---|
| 情緒分析 | `"sentiment-analysis"` | 評論是正面還是負面 |
| 零樣本分類 | `"zero-shot-classification"` | **不用訓練**，直接給類別名稱就能分類 |
| 翻譯 | `"translation"` | 中翻英、英翻中… |
| 摘要 | `"summarization"` | 把長文章縮短 |
| 命名實體辨識 | `"ner"` | 找出人名、地名、組織 |
| 問答 | `"question-answering"` | 從文章裡找出答案 |
| 語音辨識 | `"automatic-speech-recognition"` | 語音轉文字（例如 Whisper） |
| 圖片分類 | `"image-classification"` | 認出圖片裡是什麼 |

### 零樣本分類：最實用的功能之一

不需要任何訓練資料，直接告訴模型有哪些類別：

```py
from transformers import pipeline

clf = pipeline("zero-shot-classification", model="MoritzLaurer/mDeBERTa-v3-base-mnli-xnli")
result = clf(
    "我的訂單已經過了一週還沒收到，客服電話也打不通",
    candidate_labels=["物流問題", "產品品質", "退款申請", "客服態度"],
)
for label, score in zip(result["labels"], result["scores"]):
    print(f"{label}：{score:.1%}")
```

### 翻譯與摘要

```py
from transformers import pipeline

translator = pipeline("translation", model="Helsinki-NLP/opus-mt-zh-en")
print(translator("機器學習是人工智慧的一個分支。")[0]["translation_text"])

summarizer = pipeline("summarization")
article = """Python is a high-level programming language known for its readability.
It is widely used in web development, data analysis, artificial intelligence and automation.
Its large ecosystem of libraries such as NumPy, pandas and PyTorch makes it the most popular
language for machine learning research and industry applications."""
print(summarizer(article, max_length=40, min_length=10)[0]["summary_text"])
```

## 怎麼挑模型？

到 [huggingface.co/models](https://huggingface.co/models)：
1. 左邊選**任務**（例如 Text Classification）
2. **語言**篩選中文（zh）
3. 依照**下載數**或**按讚數**排序，選熱門的
4. 點進去看**模型卡（Model Card）**：說明訓練資料、用途、限制、授權

> ⚠️ 注意**授權（License）**：有些模型不能商用。也要注意模型可能有**偏見**，例如對某些族群的判斷不公平。

## 直接使用 tokenizer 和 model

pipeline 背後其實是這兩個步驟：

```py
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

name = "lxyuan/distilbert-base-multilingual-cased-sentiments-student"
tokenizer = AutoTokenizer.from_pretrained(name)
model = AutoModelForSequenceClassification.from_pretrained(name)

inputs = tokenizer(["我很開心"], return_tensors="pt")      # 文字 → token 編號
print(inputs["input_ids"])
with torch.no_grad():
    logits = model(**inputs).logits                        # 模型輸出原始分數
probs = logits.softmax(dim=-1)                              # softmax 轉成機率（第 7 階段學過！）
print({model.config.id2label[i]: round(p.item(), 3) for i, p in enumerate(probs[0])})
```

是不是和第 9 階段學的完全一樣？**tokenize → 模型 → softmax**。

## 微調（Fine-tuning）

預訓練模型已經學會了語言，只要用**少量自己的資料**再訓練一下，就能適應特定任務（例如分類你公司的客服信件）。這叫**微調**，比從零訓練便宜幾千倍。Hugging Face 的 `Trainer` 和 `datasets` 套件可以幫你完成，有興趣可以參考官方的 [LLM Course](https://huggingface.co/learn)。

## 在網頁上練習：處理模型的輸出

模型跑出來的結果是 Python 的串列和字典，接下來的處理就是一般的 Python。下面用 Hugging Face 真實的**輸出格式**練習：

```python
results = [
    {"label": "positive", "score": 0.97},
    {"label": "negative", "score": 0.93},
    {"label": "positive", "score": 0.55},
    {"label": "neutral", "score": 0.81},
]
reviews = ["超好吃！", "東西是冷的", "還可以吧", "普普通通"]
for review, r in zip(reviews, results):
    confident = "✅" if r["score"] >= 0.8 else "🤔 不太確定"
    print(f"{review:<8} → {r['label']:<9} {r['score']:.0%} {confident}")
```

def summarize(outputs, threshold=0.7):
    counts = {"positive": 0, "negative": 0, "neutral": 0, "uncertain": 0}

        else:
            counts["uncertain"] += 1
    return counts
