**封裝（encapsulation）**：把物件內部的細節藏起來，只開放安全的方式讓外面使用。這樣可以避免資料被改成不合理的值。

## 問題：屬性可以被隨便改

```python
class Account:
    def __init__(self, balance):
        self.balance = balance

a = Account(1000)
a.balance = -999999      # 沒有任何檢查，餘額變成負的！
print(a.balance)
```

## Python 的慣例：底線

Python 沒有真正的「私有」，而是用**命名慣例**告訴別人「這個不要直接碰」：

| 寫法 | 意思 |
|---|---|
| `name` | 公開，可以自由使用 |
| `_name` | **內部使用**，請不要從外面直接存取（只是約定） |
| `__name` | 名稱改編（name mangling），更難從外面存取 |

```python
class Account:
    def __init__(self, balance):
        self._balance = balance      # 單底線：「請不要直接改我」
        self.__pin = "1234"          # 雙底線：會被改名

a = Account(1000)
print(a._balance)                    # 還是看得到，只是約定不要這樣做
# print(a.__pin)                     # AttributeError
print(a._Account__pin)               # 其實被改名成這樣
```

> 💡 Python 的哲學是「**大家都是成年人**」：用底線表達意圖，而不是強制禁止。實務上單底線 `_` 最常用。

## property：像屬性一樣使用的方法

`@property` 讓你可以**用存取屬性的寫法，執行方法裡的檢查邏輯**：

```python
class Account:
    def __init__(self, balance):
        self.balance = balance          # 這裡也會經過下面的 setter 檢查！

    @property
    def balance(self):                  # 讀取 a.balance 時執行
        return self._balance

    @balance.setter
    def balance(self, value):           # 設定 a.balance = ... 時執行
        if value < 0:
            raise ValueError("餘額不能是負的")
        self._balance = value

a = Account(1000)
print(a.balance)          # 看起來像屬性，其實呼叫了方法
a.balance = 500
print(a.balance)
try:
    a.balance = -1
except ValueError as e:
    print("❌", e)
```

## 唯讀屬性與計算屬性

只寫 getter、不寫 setter，就是**唯讀**屬性。也很適合用來表示「**由其他屬性算出來的值**」：

```python
class Rectangle:
    def __init__(self, w, h):
        self.w = w
        self.h = h

    @property
    def area(self):            # 不用加括號就能用，而且永遠是最新的值
        return self.w * self.h

r = Rectangle(3, 4)
print(r.area)
r.w = 10
print(r.area)                  # 自動更新
try:
    r.area = 100               # 沒有 setter → 不能設定
except AttributeError as e:
    print("❌", e)
```

```python
class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @property
    def fahrenheit(self):
        return self.celsius * 9 / 5 + 32

    @fahrenheit.setter
    def fahrenheit(self, f):
        self.celsius = (f - 32) * 5 / 9

t = Temperature(25)
print(t.fahrenheit)
t.fahrenheit = 212
print(t.celsius)
```

## 為什麼不直接寫 get_xxx / set_xxx？

其他語言（像 Java）習慣寫 `getBalance()`、`setBalance()`。在 Python 裡，**先用普通屬性**，等到需要檢查時再改成 `property`。使用者的程式**完全不用改**，因為寫法一樣都是 `a.balance`。

class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @property
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        value = value.strip()
        if not value:
            raise ValueError("名字不能是空的")
        self._name = value

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if not isinstance(value, int) or not 0 <= value <= 150:
            raise ValueError("年齡必須是 0～150 的整數")
        self._age = value

    @property
    def is_adult(self):
        return self.age >= 18
