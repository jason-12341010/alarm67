**抽象類別（abstract class）** 是「**不能直接建立物件**、只能被繼承」的類別。它用來**規定子類別必須實作哪些方法**，就像一份合約。

## 問題：子類別忘了實作

第 4 課我們用 `raise NotImplementedError` 提醒子類別實作方法。但這個錯誤要等到**真的呼叫時**才會發現：

```python
class Payment:
    def pay(self, amount):
        raise NotImplementedError

class ApplePay(Payment):
    def pya(self, amount):          # 打錯字了！
        return "付款成功"

p = ApplePay()                       # 建立時沒有任何錯誤…
p.pay(100)                           # 等到使用時才爆炸
```

## abc 模組：在建立物件時就檢查

```python
from abc import ABC, abstractmethod

class Payment(ABC):                  # 繼承 ABC
    @abstractmethod
    def pay(self, amount):
        """付款，回傳結果字串"""

    def receipt(self, amount):       # 抽象類別也可以有一般方法
        return f"🧾 收據：{self.pay(amount)}"

class ApplePay(Payment):
    def pya(self, amount):           # 一樣打錯字
        return "付款成功"

try:
    ApplePay()                       # 建立物件時就直接報錯！
except TypeError as e:
    print("❌", e)

try:
    Payment()                        # 抽象類別本身也不能建立物件
except TypeError as e:
    print("❌", e)
```

```python
from abc import ABC, abstractmethod

class Payment(ABC):
    @abstractmethod
    def pay(self, amount): ...

    def receipt(self, amount):
        return f"🧾 收據：{self.pay(amount)}"

class ApplePay(Payment):
    def pay(self, amount):           # 正確實作
        return f"Apple Pay 付款 {amount} 元"

print(ApplePay().receipt(250))
```

> 💡 `...`（Ellipsis）和 `pass` 一樣，可以當作「這裡沒有內容」。在抽象方法裡很常見。

## 抽象屬性

`@property` 和 `@abstractmethod` 可以一起用：

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @property
    @abstractmethod
    def sound(self): ...

    def speak(self):
        return f"{type(self).__name__} 說：{self.sound}"

class Dog(Animal):
    @property
    def sound(self):
        return "汪汪"

class Duck(Animal):
    sound = "呱呱"                    # 用類別屬性實作也可以

print(Dog().speak())
print(Duck().speak())
```

## 實際例子：資料匯出器

抽象類別定義**流程**，子類別只負責**細節**。這種設計叫做「**樣板方法模式**」（Template Method）：

```python
from abc import ABC, abstractmethod
import json

class Exporter(ABC):
    def export(self, rows):                 # 固定的流程
        header = self.header(rows)
        body = [self.format_row(r) for r in rows]
        return "\n".join(([header] if header else []) + body)

    def header(self, rows):                 # 預設沒有標頭，子類別可以覆寫
        return None

    @abstractmethod
    def format_row(self, row): ...          # 每種格式一定要實作

class CsvExporter(Exporter):
    def header(self, rows):
        return ",".join(rows[0].keys())

    def format_row(self, row):
        return ",".join(str(v) for v in row.values())

class JsonLinesExporter(Exporter):
    def format_row(self, row):
        return json.dumps(row, ensure_ascii=False)

data = [{"name": "小明", "score": 85}, {"name": "小美", "score": 92}]
for exporter in [CsvExporter(), JsonLinesExporter()]:
    print(f"--- {type(exporter).__name__} ---")
    print(exporter.export(data))
```

## 什麼時候需要抽象類別？

- 你在設計一套**框架或函式庫**，希望別人照規則擴充
- 有好幾個子類別，而且**一定要**實作某些方法

小專案用鴨子型別通常就夠了。之後在 scikit-learn、Django 的原始碼裡會看到很多抽象類別。

子類別的 `__init__` 用 `super().__init__(name)`，再存自己的屬性。`payslip` 裡用 `f"{self.name}：{self.monthly_pay():,} 元"`。

from abc import ABC, abstractmethod


class Employee(ABC):
    def __init__(self, name):
        self.name = name

    @abstractmethod
    def monthly_pay(self): ...

    def payslip(self):
        return f"{self.name}：{self.monthly_pay():,} 元"


class FullTime(Employee):
    def __init__(self, name, salary):
        super().__init__(name)
        self.salary = salary

    def monthly_pay(self):
        return self.salary


class PartTime(Employee):
    def __init__(self, name, hourly, hours):
        super().__init__(name)
        self.hourly, self.hours = hourly, hours

    def monthly_pay(self):
        return self.hourly * self.hours


class Sales(Employee):
    def __init__(self, name, base, sales):
        super().__init__(name)
        self.base, self.sales = base, sales

    def monthly_pay(self):
        return self.base + int(self.sales * 0.05)


staff = [FullTime("小明", 48000), PartTime("小美", 190, 80), Sales("阿華", 30000, 500000)]
for e in staff:
    print(e.payslip())
