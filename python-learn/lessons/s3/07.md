類別裡的方法有三種：

| 種類 | 第一個參數 | 用途 |
|---|---|---|
| 一般方法（實例方法） | `self`（物件） | 操作「這個物件」的資料 |
| `@classmethod` 類別方法 | `cls`（類別） | 操作「類別」本身，最常用來**建立物件的其他方式** |
| `@staticmethod` 靜態方法 | 沒有 | 跟類別有關的工具函式，不需要物件也不需要類別 |

## @classmethod：替代建構子

一個類別通常只有一個 `__init__`，但資料可能有好幾種來源（字串、字典、檔案…）。用 classmethod 提供**不同的建立方式**：

```python
from datetime import date

class Person:
    def __init__(self, name, birth_year):
        self.name = name
        self.birth_year = birth_year

    @classmethod
    def from_string(cls, text):          # "小明,2005"
        name, year = text.split(",")
        return cls(name, int(year))      # cls 就是 Person

    @classmethod
    def from_dict(cls, d):
        return cls(d["name"], d["birth_year"])

    @property
    def age(self):
        return 2026 - self.birth_year

    def __repr__(self):
        return f"Person({self.name!r}, {self.birth_year})"

people = [
    Person("小美", 2000),
    Person.from_string("小明,2005"),
    Person.from_dict({"name": "阿華", "birth_year": 1995}),
]
for p in people:
    print(p, p.age)
```

Python 內建的類別也大量使用這種寫法：

```python
from datetime import datetime
print(dict.fromkeys(["a", "b"], 0))
print(datetime.fromisoformat("2026-11-04T09:30"))
print(int.from_bytes(b"\x01\x00", "big"))
```

## 為什麼用 cls 而不是直接寫類別名稱？

因為 `cls` 會跟著**子類別**變化，繼承時也能建立正確的類型：

```python
class Shape:
    def __init__(self, size):
        self.size = size

    @classmethod
    def unit(cls):
        return cls(1)                  # 子類別呼叫時，cls 就是子類別

class Square(Shape): pass
class Circle(Shape): pass

print(type(Square.unit()).__name__, type(Circle.unit()).__name__)
```

## @classmethod 操作類別屬性

```python
class Config:
    settings = {"debug": False, "lang": "zh-TW"}

    @classmethod
    def set(cls, key, value):
        cls.settings[key] = value

    @classmethod
    def get(cls, key, default=None):
        return cls.settings.get(key, default)

Config.set("debug", True)
print(Config.get("debug"), Config.get("lang"), Config.get("theme", "light"))
```

## @staticmethod：放在類別裡的工具函式

不需要 `self` 也不需要 `cls`，只是**邏輯上屬於這個類別**，放在一起比較好找：

```python
class Validator:
    @staticmethod
    def is_email(s):
        return "@" in s and "." in s.split("@")[-1]

    @staticmethod
    def is_tw_phone(s):
        return s.isdigit() and len(s) == 10 and s.startswith("09")

print(Validator.is_email("amy@mail.com"), Validator.is_email("amy@mail"))
print(Validator.is_tw_phone("0912345678"), Validator.is_tw_phone("12345"))
```

> 💡 如果一個 staticmethod 和類別沒什麼關係，直接寫成**模組裡的一般函式**通常更好。Python 不像 Java 規定所有東西都要放在 class 裡。

## 三種方法放在一起

```python
class Pizza:
    def __init__(self, toppings):
        self.toppings = toppings

    def describe(self):                      # 實例方法：用到這個披薩的配料
        return f"披薩配料：{'、'.join(self.toppings)}"

    @classmethod
    def margherita(cls):                     # 類別方法：建立特定口味
        return cls(["番茄", "起司", "羅勒"])

    @classmethod
    def hawaiian(cls):
        return cls(["火腿", "鳳梨", "起司"])

    @staticmethod
    def slice_angle(n):                      # 靜態方法：純計算
        return 360 / n

print(Pizza.margherita().describe())
print(Pizza.hawaiian().describe())
print(Pizza.slice_angle(8), "度")
```

class Date:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, s):
        y, m, d = map(int, s.split("-"))
        return cls(y, m, d)

    @classmethod
    def from_slash(cls, s):
        m, d, y = map(int, s.split("/"))
        return cls(y, m, d)

    @staticmethod
    def is_leap(year):
        return (year % 4 == 0 and year % 100 != 0) or year % 400 == 0

    def __repr__(self):
        return f"Date({self.year}, {self.month}, {self.day})"


print(Date.from_string("2026-11-04"))
print(Date.from_slash("12/25/2026"))
print(Date.is_leap(2024), Date.is_leap(1900))
