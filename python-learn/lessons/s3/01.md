到目前為止，我們用**變數存資料**、用**函式處理資料**，兩者是分開的。**物件導向（Object-Oriented Programming, OOP）** 則是把「資料」和「處理資料的函式」**包在一起**，變成一個**物件**。

## 其實你一直在用物件

Python 裡**所有東西都是物件**。字串有自己的資料（文字內容），也有自己的方法（`.upper()`、`.split()`）：

```python
s = "hello"
print(type(s))          # s 是 str 這個「類別」的物件
print(s.upper())        # 呼叫物件的「方法」

nums = [3, 1, 2]
nums.sort()             # 方法會改變物件自己的資料
print(nums, type(nums))
```

## 類別與物件

- **類別（class）**：設計圖、模板。例如「狗」這個概念。
- **物件（object）/ 實例（instance）**：照著設計圖做出來的東西。例如「小白」、「小黑」這兩隻狗。

```python
class Dog:
    pass

a = Dog()     # 建立物件：類別名稱加上括號
b = Dog()
print(a)
print(type(a), a is b)
```

## 屬性：物件的資料

可以直接在物件上加屬性（下一課會學更好的寫法）：

```python
class Dog:
    pass

a = Dog()
a.name = "小白"
a.age = 3
b = Dog()
b.name = "小黑"
print(a.name, a.age)
print(b.name)
```

## 方法：物件的函式

定義在類別裡的函式叫做**方法（method）**。第一個參數 `self` 代表「這個物件自己」：

```python
class Dog:
    def bark(self):
        print(f"{self.name}：汪汪！")

    def birthday(self):
        self.age += 1
        print(f"{self.name} 現在 {self.age} 歲了")

a = Dog()
a.name, a.age = "小白", 3
a.bark()          # Python 會自動把 a 傳給 self
a.birthday()
Dog.bark(a)       # 跟上面 a.bark() 完全一樣（只是沒人這樣寫）
```

> 💡 `a.bark()` 其實就是 `Dog.bark(a)`。這就是 `self` 的由來：方法需要知道「是哪一個物件」在呼叫它。

## 為什麼要用物件導向？

比較兩種寫法：

```python
# 不用 class：資料和函式分散，要自己記得哪個函式配哪種資料
account = {"owner": "小明", "balance": 1000}

def deposit(acc, amount):
    acc["balance"] += amount

deposit(account, 500)
print(account)
```

```python
# 用 class：資料和操作包在一起，用起來更直覺
class Account:
    def deposit(self, amount):
        self.balance += amount

acc = Account()
acc.owner, acc.balance = "小明", 1000
acc.deposit(500)
print(acc.owner, acc.balance)
```

當程式變大（像遊戲有幾百種角色、網站有幾十種資料），物件導向能讓程式**更好組織、更好擴充**。你之後會學的 Django、PyTorch、scikit-learn 全部都大量使用 class。

## 命名慣例

- 類別名稱用 **PascalCase**（每個字首大寫）：`Dog`、`BankAccount`、`HttpRequest`
- 方法和屬性用 **snake_case**：`bark`、`get_balance`
