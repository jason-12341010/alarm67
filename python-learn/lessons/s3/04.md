**多型（polymorphism）**：不同類型的物件，可以用**同樣的方式**操作，各自做出不同的反應。

## 同一個方法名稱，不同的行為

```python
class Dog:
    def speak(self):
        return "汪汪"

class Cat:
    def speak(self):
        return "喵～"

class Robot:
    def speak(self):
        return "嗶嗶 0101"

def make_noise(things):
    for t in things:
        print(f"{type(t).__name__}: {t.speak()}")   # 不用管它是什麼，只要會 speak 就好

make_noise([Dog(), Cat(), Robot()])
```

注意 `Robot` 根本沒有繼承任何動物類別，但一樣可以使用 `make_noise`。

## 鴨子型別（Duck Typing）

> 「如果它走起路來像鴨子、叫起來也像鴨子，那它就是鴨子。」

Python 不在乎物件是**什麼類型**，只在乎它**能不能做到**需要的事。這讓程式非常有彈性：

```python
class Logger:
    def __init__(self):
        self.lines = []

    def write(self, text):          # 只要有 write 方法，就可以當作檔案使用
        self.lines.append(text)

log = Logger()
print("哈囉", file=log)              # print 只要求 file 物件有 write()
print("Python", file=log)
print(log.lines)
```

內建函式也是這樣運作的。`len()` 可以用在任何定義了 `__len__` 的物件上（下兩課會學到）：

```python
for thing in ["abc", [1, 2], {"a": 1}, range(10)]:
    print(type(thing).__name__, len(thing))
```

## 多型 + 繼承：統一介面

實務上常見的寫法：父類別定義「介面」，子類別各自實作：

```python
class Payment:
    def pay(self, amount):
        raise NotImplementedError("子類別必須實作 pay()")

class CreditCard(Payment):
    def pay(self, amount):
        return f"信用卡付款 {amount} 元（手續費 {amount * 0.02:.0f} 元）"

class LinePay(Payment):
    def pay(self, amount):
        return f"LINE Pay 付款 {amount} 元，回饋 {amount * 0.01:.0f} 點"

class Cash(Payment):
    def pay(self, amount):
        return f"現金付款 {amount} 元"

def checkout(method: Payment, amount):
    print(method.pay(amount))         # 結帳流程完全不用改

for m in [CreditCard(), LinePay(), Cash()]:
    checkout(m, 1000)
```

以後要新增「街口支付」，只要寫一個新類別，**結帳的程式完全不用動**。這就是多型最大的好處：**擴充容易**。

## 用多型取代一大堆 if

```python
# ❌ 每新增一種形狀，就要改這個函式
def area_bad(shape):
    if shape["type"] == "circle":
        return 3.14 * shape["r"] ** 2
    elif shape["type"] == "square":
        return shape["side"] ** 2

# ✅ 每種形狀自己知道怎麼算面積
class Circle:
    def __init__(self, r): self.r = r
    def area(self): return 3.14 * self.r ** 2

class Square:
    def __init__(self, s): self.s = s
    def area(self): return self.s ** 2

print(area_bad({"type": "circle", "r": 1}))
print(sum(s.area() for s in [Circle(1), Square(2), Circle(2)]))
```

## EAFP：先做再說

Python 社群偏好「**先試試看，出錯再處理**」（Easier to Ask Forgiveness than Permission），而不是事先檢查型別：

```python
def total_length(items):
    total = 0
    for x in items:
        try:
            total += len(x)
        except TypeError:          # 沒有長度的東西就跳過
            pass
    return total

print(total_length(["abc", [1, 2, 3], 42, {"k": "v"}, None]))
```

class Email:
    def __init__(self, address):
        self.address = address

    def send(self, msg):
        return f"寄信給 {self.address}：{msg}"


class SMS:
    def __init__(self, phone):
        self.phone = phone

    def send(self, msg):
        if len(msg) > 10:
            msg = msg[:10] + "…"
        return f"簡訊到 {self.phone}：{msg}"


class Push:
    def send(self, msg):
        return f"推播：{msg}"


def notify_all(channels, msg):
    return [c.send(msg) for c in channels]


for r in notify_all([Email("amy@mail.com"), SMS("0912345678"), Push()], "你的訂單已經出貨，請注意查收"):
    print(r)
