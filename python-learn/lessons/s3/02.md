## `__init__`：建立物件時自動執行

上一課要手動設定屬性很麻煩，而且容易忘記。`__init__` 是一個特殊方法，**建立物件時會自動呼叫**，用來設定初始值：

```python
class Dog:
    def __init__(self, name, age=1):
        self.name = name        # 把參數存成物件的屬性
        self.age = age
        print(f"🐶 {name} 誕生了！")

    def bark(self):
        print(f"{self.name}：汪汪！")

a = Dog("小白", 3)      # 參數會傳給 __init__（self 不用傳）
b = Dog("小黑")
a.bark()
print(b.age)
```

> 💡 `__init__` 前後各有兩個底線，唸作 "dunder init"（double underscore）。

## self 再說明

`self.name` 是**物件的屬性**，會一直跟著物件；`name` 只是 `__init__` 的**區域變數**，函式結束就消失了：

```python
class Person:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print(f"我是 {self.name}")   # ✅ 用 self.name
        # print(name)               # ❌ NameError：name 只存在於 __init__

p = Person("小明")
p.hello()
```

## 類別屬性 vs 實例屬性

- **實例屬性**（`self.xxx`）：每個物件各自一份
- **類別屬性**（寫在 class 底下）：所有物件**共用**一份

```python
class Dog:
    species = "犬科"       # 類別屬性：所有狗都一樣
    count = 0              # 用來計算總共建立了幾隻狗

    def __init__(self, name):
        self.name = name   # 實例屬性：每隻狗不一樣
        Dog.count += 1

a = Dog("小白")
b = Dog("小黑")
print(a.species, b.species, Dog.species)
print("總共", Dog.count, "隻狗")
```

> ⚠️ 不要用**可變物件**（例如串列）當類別屬性，否則所有物件會共用同一個串列：

```python
class Bad:
    tricks = []                     # ❌ 所有物件共用
    def add(self, t):
        self.tricks.append(t)

class Good:
    def __init__(self):
        self.tricks = []            # ✅ 每個物件一份
    def add(self, t):
        self.tricks.append(t)

a, b = Bad(), Bad()
a.add("握手")
print("Bad:", b.tricks)             # b 也有握手？！
c, d = Good(), Good()
c.add("握手")
print("Good:", d.tricks)
```

## 方法可以呼叫其他方法

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

    def describe(self):
        return f"{self.width}x{self.height} 的長方形，面積 {self.area()}，周長 {self.perimeter()}"

r = Rectangle(3, 4)
print(r.describe())
r.width = 10           # 屬性可以修改
print(r.describe())
```

## 物件可以放進串列、字典

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

students = [Student("小明", 85), Student("小美", 92), Student("阿華", 78)]
best = max(students, key=lambda s: s.score)
print("最高分：", best.name)
for s in sorted(students, key=lambda s: s.score, reverse=True):
    print(f"{s.name:<4}{s.score}")
```

## 查看物件的屬性

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(3, 4)
print(vars(p))                 # 所有實例屬性（字典）
print(hasattr(p, "x"), getattr(p, "y"), getattr(p, "z", "沒有 z"))
```

:::exercise 銀行帳戶
建立類別 `BankAccount`：
- `__init__(self, owner, balance=0)`：設定 `owner` 和 `balance`
- `deposit(self, amount)`：存款，金額 ≤ 0 時 `raise ValueError`
- `withdraw(self, amount)`：提款，餘額不足時 `raise ValueError("餘額不足")`
- 存款和提款都要**回傳新的餘額**
@@starter
class BankAccount:
    pass


acc = BankAccount("小明", 1000)
print(acc.deposit(500))
print(acc.withdraw(200))
@@check
B = ns.get("BankAccount")
assert isinstance(B, type), "找不到類別 BankAccount"
a = B("小美")
assert a.owner == "小美" and a.balance == 0, "沒有給 balance 時，預設應該是 0"
a = B("小明", 1000)
assert a.deposit(500) == 1500, "deposit(500) 應該回傳 1500"
assert a.withdraw(200) == 1300, "withdraw(200) 應該回傳 1300"
assert a.balance == 1300, "balance 屬性也要更新"
for bad in (lambda: a.withdraw(99999), lambda: a.deposit(0), lambda: a.deposit(-5)):
    try:
        bad()
    except ValueError:
        pass
    else:
        raise AssertionError("餘額不足或存款金額 ≤ 0 時，應該 raise ValueError")
assert a.balance == 1300, "失敗的操作不應該改變餘額"
@@hint
在 `withdraw` 裡先檢查 `if amount > self.balance: raise ValueError("餘額不足")`，通過檢查後再修改 `self.balance`。
@@solution
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金額必須大於 0")
        self.balance += amount
        return self.balance

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError("餘額不足")
        self.balance -= amount
        return self.balance


acc = BankAccount("小明", 1000)
print(acc.deposit(500))
print(acc.withdraw(200))

:::exercise 購物車
建立類別 `Cart`：
- `__init__`：建立空的 `self.items` 字典（品名 → `(單價, 數量)`）
- `add(self, name, price, qty=1)`：加入商品；同樣的商品再加入時，數量要累加
- `total(self)`：回傳總金額
- `count(self)`：回傳商品總件數
@@starter
class Cart:
    pass


cart = Cart()
cart.add("蘋果", 30, 3)
cart.add("牛奶", 65)
cart.add("蘋果", 30, 2)
print(cart.total(), cart.count())
@@check
C = ns.get("Cart")
assert isinstance(C, type), "找不到類別 Cart"
c = C()
assert c.total() == 0 and c.count() == 0, "空的購物車：total() 和 count() 都應該是 0"
c.add("蘋果", 30, 3); c.add("牛奶", 65); c.add("蘋果", 30, 2)
assert c.total() == 215, f"total() 應該是 215，你的是 {c.total()}"
assert c.count() == 6, f"count() 應該是 6，你的是 {c.count()}"
d = C()
assert d.count() == 0, "每個購物車要各自獨立（items 要在 __init__ 裡建立）"
@@hint
`add` 裡可以寫：`old_qty = self.items.get(name, (price, 0))[1]`，再 `self.items[name] = (price, old_qty + qty)`。
@@solution
class Cart:
    def __init__(self):
        self.items = {}

    def add(self, name, price, qty=1):
        old_qty = self.items.get(name, (price, 0))[1]
        self.items[name] = (price, old_qty + qty)

    def total(self):
        return sum(price * qty for price, qty in self.items.values())

    def count(self):
        return sum(qty for _, qty in self.items.values())


cart = Cart()
cart.add("蘋果", 30, 3)
cart.add("牛奶", 65)
cart.add("蘋果", 30, 2)
print(cart.total(), cart.count())
