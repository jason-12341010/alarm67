很多類別主要只是用來**裝資料**。這種類別要寫一大堆重複的程式：`__init__`、`__repr__`、`__eq__`… **dataclass** 可以自動幫你產生這些。

## 不用 dataclass 的寫法

```python
class Product:
    def __init__(self, name, price, qty=0):
        self.name = name
        self.price = price
        self.qty = qty

    def __repr__(self):
        return f"Product(name={self.name!r}, price={self.price!r}, qty={self.qty!r})"

    def __eq__(self, other):
        return (self.name, self.price, self.qty) == (other.name, other.price, other.qty)

print(Product("筆", 20, 5))
```

## 用 dataclass

```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str               # 型別提示（type hint）：說明這個欄位應該是什麼型別
    price: float
    qty: int = 0            # 預設值

    def total(self):        # 一樣可以加自己的方法
        return self.price * self.qty

p = Product("筆", 20, 5)
print(p)                                  # 自動產生的 __repr__
print(p == Product("筆", 20, 5))          # 自動產生的 __eq__
print(p.total())
```

短短幾行就完成了！`name: str` 這種寫法叫**型別提示**，第 4 階段會詳細介紹。注意：dataclass **不會**在執行時檢查型別。

## 可變的預設值：field(default_factory=...)

還記得「不要用串列當預設值」嗎？dataclass 會直接阻止你：

```python
from dataclasses import dataclass, field

@dataclass
class Student:
    name: str
    scores: list = field(default_factory=list)     # 每個物件建立新的串列
    tags: dict = field(default_factory=dict)

a = Student("小明")
b = Student("小美")
a.scores.append(90)
print(a, b)
```

## 常用選項

```python
from dataclasses import dataclass, asdict, astuple, replace

@dataclass(frozen=True, order=True)      # frozen：不能修改；order：可以排序
class Version:
    major: int
    minor: int
    patch: int = 0

v = Version(1, 2)
print(v, asdict(v), astuple(v))
print(sorted([Version(2, 0), Version(1, 10), Version(1, 2, 5)]))

v2 = replace(v, minor=3)                  # 建立修改過的新物件
print(v2)

try:
    v.major = 9
except Exception as e:
    print("❌", type(e).__name__, e)

print({v, Version(1, 2)})                 # frozen 的物件可以放進 set、當字典的鍵
```

## __post_init__：建立後的檢查與計算

```python
from dataclasses import dataclass, field

@dataclass
class Rectangle:
    width: float
    height: float
    area: float = field(init=False)       # 不出現在 __init__ 參數裡

    def __post_init__(self):
        if self.width <= 0 or self.height <= 0:
            raise ValueError("寬和高必須大於 0")
        self.area = self.width * self.height

print(Rectangle(3, 4))
try:
    Rectangle(-1, 2)
except ValueError as e:
    print("❌", e)
```

## 實際應用：讀取 CSV 成物件

```python
import csv, io
from dataclasses import dataclass

@dataclass
class Order:
    id: int
    customer: str
    amount: float

    @classmethod
    def from_row(cls, row):
        return cls(int(row["id"]), row["customer"], float(row["amount"]))

text = """id,customer,amount
1,小明,320
2,小美,1250.5
3,小明,80
"""
orders = [Order.from_row(r) for r in csv.DictReader(io.StringIO(text))]
for o in orders:
    print(o)
print("小明總共花了", sum(o.amount for o in orders if o.customer == "小明"))
```

> 💡 **dataclass vs 一般 class**：主要用來存資料 → dataclass；有複雜行為、需要封裝 → 一般 class。另外第 6 階段會介紹 **Pydantic**，它像是「會檢查型別的 dataclass」，FastAPI 就是用它。

from dataclasses import dataclass, field


@dataclass
class Task:
    title: str
    priority: int = 3
    done: bool = False
    tags: list = field(default_factory=list)


@dataclass
class TodoList:
    name: str
    tasks: list = field(default_factory=list)

    def add(self, title, priority=3, *tags):
        self.tasks.append(Task(title, priority, tags=list(tags)))

    def pending(self):
        return sorted([t for t in self.tasks if not t.done], key=lambda t: t.priority)
