**繼承（inheritance）** 讓一個類別可以「接收」另一個類別的屬性和方法，再加上自己的東西。這樣共同的程式只要寫一次。

## 基本繼承

```python
class Animal:                       # 父類別（parent / base class）
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} 在吃東西")

class Dog(Animal):                  # 子類別：括號裡放父類別
    def bark(self):
        print(f"{self.name}：汪汪！")

class Cat(Animal):
    def meow(self):
        print(f"{self.name}：喵～")

d = Dog("小白")
d.eat()       # 從 Animal 繼承來的
d.bark()      # Dog 自己的
Cat("咪咪").eat()
```

## 覆寫（override）方法

子類別可以重新定義父類別的方法：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):            # 覆寫
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵～"

for a in [Dog("小白"), Cat("咪咪"), Animal("???")]:
    print(a.name, a.speak())
```

## super()：呼叫父類別的方法

子類別的 `__init__` 想**在父類別的基礎上加東西**時，用 `super()`：

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def info(self):
        return f"{self.name}，月薪 {self.salary:,}"

class Manager(Employee):
    def __init__(self, name, salary, team_size):
        super().__init__(name, salary)        # 先讓父類別設定 name、salary
        self.team_size = team_size            # 再加上自己的屬性

    def info(self):
        base = super().info()                 # 重複使用父類別的結果
        return f"{base}，管理 {self.team_size} 人"

print(Employee("小明", 45000).info())
print(Manager("王經理", 80000, 6).info())
```

> ⚠️ 子類別寫了 `__init__` 卻忘了呼叫 `super().__init__()`，父類別設定的屬性就不會存在，之後會出現 `AttributeError`。

## isinstance 與 issubclass

```python
class Animal: pass
class Dog(Animal): pass

d = Dog()
print(isinstance(d, Dog), isinstance(d, Animal))   # 狗也是動物
print(issubclass(Dog, Animal), issubclass(Animal, Dog))
print(Dog.__mro__)        # 方法解析順序：找方法時的搜尋順序
```

所有類別最終都繼承自 `object`。

## 多層繼承

```python
class Vehicle:
    wheels = 0
    def describe(self):
        return f"{type(self).__name__} 有 {self.wheels} 個輪子"

class Car(Vehicle):
    wheels = 4

class SportsCar(Car):
    def describe(self):
        return super().describe() + "，而且跑很快！"

for v in [Vehicle(), Car(), SportsCar()]:
    print(v.describe())
```

## 多重繼承與 Mixin

Python 允許同時繼承多個類別。常見用法是 **Mixin**：一個只提供某種小功能的類別：

```python
import json

class JsonMixin:
    def to_json(self):
        return json.dumps(vars(self), ensure_ascii=False)

class ReprMixin:
    def __repr__(self):
        fields = ", ".join(f"{k}={v!r}" for k, v in vars(self).items())
        return f"{type(self).__name__}({fields})"

class User(JsonMixin, ReprMixin):
    def __init__(self, name, age):
        self.name = name
        self.age = age

u = User("小明", 18)
print(u.to_json())
print(u)
```

> 💡 繼承不要太深。如果只是「**有一個**」關係（汽車**有**引擎），用**組合**（把物件當屬性）通常比繼承更好；繼承適合「**是一個**」關係（狗**是**動物）。

```python
class Engine:
    def start(self):
        return "引擎啟動 🔥"

class Car:
    def __init__(self):
        self.engine = Engine()       # 組合：Car 有一個 Engine

    def drive(self):
        return self.engine.start() + " → 出發！"

print(Car().drive())
```

class Shape:
    def __init__(self, name):
        self.name = name

    def area(self):
        return 0

    def describe(self):
        return f"{self.name} 面積 {self.area():.1f}"


class Circle(Shape):
    def __init__(self, r):
        super().__init__("圓形")
        self.r = r

    def area(self):
        return 3.14159 * self.r * self.r


class Square(Shape):
    def __init__(self, side):
        super().__init__("正方形")
        self.side = side

    def area(self):
        return self.side * self.side


for s in [Circle(1), Square(3)]:
    print(s.describe())
