**遞迴（recursion）**：函式**呼叫自己**。它把大問題拆成**同樣形式的小問題**，直到小到可以直接回答。

## 兩個要素

1. **終止條件（base case）**：最小的問題，直接回答，不再呼叫自己
2. **遞迴步驟**：把問題縮小，呼叫自己

```python
def countdown(n):
    if n == 0:                 # 終止條件
        print("發射！🚀")
        return
    print(n)
    countdown(n - 1)           # 遞迴：問題變小

countdown(5)
```

## 經典例子：階乘

`5! = 5 × 4!`，`4! = 4 × 3!`，… `1! = 1`

```python
def factorial(n, depth=0):
    indent = "  " * depth
    print(f"{indent}factorial({n})")
    if n <= 1:
        print(f"{indent}→ 1")
        return 1
    result = n * factorial(n - 1, depth + 1)
    print(f"{indent}→ {result}")
    return result

factorial(5)
```

每次呼叫都會疊在**呼叫堆疊（call stack）** 上，等到最底層回傳之後，再一層一層算回來。

## ⚠️ 遞迴太深會出錯

Python 預設最多遞迴約 1000 層：

```python
import sys
print(sys.getrecursionlimit())

def forever(n):
    return forever(n + 1)      # 沒有終止條件！

forever(0)
```

> 💡 Python 不擅長很深的遞迴。能用迴圈簡單寫出來的，通常用迴圈比較好。

## 遞迴擅長的問題：樹狀結構

遞迴真正的威力在於處理**巢狀、樹狀**的資料，用迴圈會很難寫：

```python
folder = {
    "name": "專案", "files": ["README.md"],
    "children": [
        {"name": "src", "files": ["main.py", "utils.py"], "children": [
            {"name": "models", "files": ["user.py"], "children": []},
        ]},
        {"name": "tests", "files": ["test_main.py"], "children": []},
    ],
}

def show(node, depth=0):
    print("  " * depth + "📁 " + node["name"])
    for f in node["files"]:
        print("  " * (depth + 1) + "📄 " + f)
    for child in node["children"]:
        show(child, depth + 1)          # 子資料夾用一樣的方式處理

def count_files(node):
    return len(node["files"]) + sum(count_files(c) for c in node["children"])

show(folder)
print("總共", count_files(folder), "個檔案")
```

## 費氏數列與記憶化

```python
import time
from functools import lru_cache

calls = 0
def fib(n):
    global calls
    calls += 1
    return n if n < 2 else fib(n - 1) + fib(n - 2)

t = time.perf_counter()
print(fib(25), f"呼叫了 {calls:,} 次，{time.perf_counter() - t:.2f} 秒")

@lru_cache(maxsize=None)          # 記住算過的結果
def fib_memo(n):
    return n if n < 2 else fib_memo(n - 1) + fib_memo(n - 2)

t = time.perf_counter()
print(fib_memo(25), f"{time.perf_counter() - t:.5f} 秒")
print(fib_memo(300))
```

沒有快取時，`fib(n-2)` 會被重複計算非常多次，複雜度是 O(2ⁿ)。加上快取後變成 O(n)。這個想法就是**動態規劃**（第 12 課）的基礎。

## 回溯（Backtracking）：列出所有可能

遞迴很適合「**做選擇 → 繼續 → 撤銷選擇**」的問題：

```python
def permutations(items):
    if len(items) <= 1:
        return [items[:]]
    result = []
    for i, x in enumerate(items):
        rest = items[:i] + items[i + 1:]
        for p in permutations(rest):        # 剩下的元素做全排列
            result.append([x] + p)
    return result

print(permutations([1, 2, 3]))

def subsets(items):
    """所有子集合：每個元素都有「選」或「不選」兩種"""
    if not items:
        return [[]]
    rest = subsets(items[1:])
    return rest + [[items[0]] + s for s in rest]

print(subsets(["A", "B", "C"]))
```

## 河內塔

把 n 個盤子從 A 移到 C，一次只能移一個，大盤子不能放在小盤子上。想法：
1. 把上面 n-1 個移到 B（遞迴）
2. 把最大的移到 C
3. 把 B 的 n-1 個移到 C（遞迴）

```python
def hanoi(n, src="A", dst="C", via="B"):
    if n == 0:
        return 0
    moves = hanoi(n - 1, src, via, dst)
    print(f"盤子 {n}：{src} → {dst}")
    moves += 1
    moves += hanoi(n - 1, via, dst, src)
    return moves

print("總共", hanoi(3), "步")
```

def deep_sum(data):
    if isinstance(data, (int, float)):
        return data
    if isinstance(data, list):
        return sum(deep_sum(x) for x in data)
    if isinstance(data, dict):
        return sum(deep_sum(v) for v in data.values())
    return 0
