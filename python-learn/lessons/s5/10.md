## 堆疊（Stack）：後進先出（LIFO）

像一疊盤子：**最後放上去的，最先拿走**。

| 操作 | Python list |
|---|---|
| 放入（push） | `stack.append(x)` — O(1) |
| 取出（pop） | `stack.pop()` — O(1) |
| 看最上面 | `stack[-1]` |

```python
stack = []
for page in ["首頁", "商品列表", "商品頁", "購物車"]:
    stack.append(page)
    print("前往", page, stack)

while stack:
    print("⬅ 上一頁，離開", stack.pop())
```

堆疊的應用：瀏覽器的上一頁、編輯器的**復原（Ctrl+Z）**、函式呼叫堆疊、括號配對…

### 經典題：括號配對

```python
def is_balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack            # 最後堆疊要是空的

for s in ["(a + b) * [c]", "{[()]}", "(]", "((", "print(len([1, 2]))"]:
    print(f"{s:<22}{is_balanced(s)}")
```

### 經典題：計算後序表達式

`3 4 + 2 *` 等於 `(3 + 4) * 2`。遇到數字就 push，遇到運算子就 pop 兩個出來算：

```python
def eval_rpn(tokens):
    stack = []
    ops = {"+": lambda a, b: a + b, "-": lambda a, b: a - b,
           "*": lambda a, b: a * b, "/": lambda a, b: a / b}
    for t in tokens.split():
        if t in ops:
            b, a = stack.pop(), stack.pop()
            stack.append(ops[t](a, b))
        else:
            stack.append(float(t))
    return stack[0]

print(eval_rpn("3 4 + 2 *"))
print(eval_rpn("5 1 2 + 4 * + 3 -"))
```

## 佇列（Queue）：先進先出（FIFO）

像排隊：**先來的先服務**。

> ⚠️ 不要用 `list.pop(0)`，它是 O(n)。用 `collections.deque`：

```python
from collections import deque

queue = deque()
for customer in ["小明", "小美", "阿華"]:
    queue.append(customer)          # 排到隊伍最後
    print("加入", customer, list(queue))

while queue:
    print("服務", queue.popleft(), "，剩下", list(queue))   # 從前面取出：O(1)
```

佇列的應用：印表機工作、訊息佇列、**廣度優先搜尋（下一課）**、爬蟲的待抓網址…

### 模擬：客服中心

```python
from collections import deque
import random

random.seed(5)
waiting = deque()
served = 0
for minute in range(1, 11):
    for _ in range(random.randint(0, 2)):          # 每分鐘有 0～2 個新客人
        waiting.append(f"客人{minute}-{random.randint(1, 99)}")
    if waiting and minute % 2 == 0:                # 每 2 分鐘服務一位
        waiting.popleft()
        served += 1
    print(f"第 {minute:>2} 分鐘：排隊 {len(waiting)} 人 {'▮' * len(waiting)}")
print(f"服務了 {served} 人，還有 {len(waiting)} 人在等")
```

## 優先佇列（Priority Queue）

不是先來先服務，而是**優先權最高的先**。用 `heapq`，每次取出最小值是 O(log n)：

```python
import heapq

er = []                            # 急診室：數字越小越緊急
heapq.heappush(er, (3, "小明：感冒"))
heapq.heappush(er, (1, "小美：心臟病"))
heapq.heappush(er, (2, "阿華：骨折"))
heapq.heappush(er, (1, "小強：大出血"))
while er:
    level, patient = heapq.heappop(er)
    print(f"等級 {level}：{patient}")
```

## 單調堆疊：進階技巧

找出「每個元素右邊**第一個比它大**的元素」，用單調堆疊可以 O(n) 解決：

```python
def next_greater(nums):
    result = [-1] * len(nums)
    stack = []                     # 存索引，對應的值由下往上遞減
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            result[stack.pop()] = x
        stack.append(i)
    return result

temps = [73, 74, 75, 71, 69, 72, 76, 73]
print(next_greater(temps))         # 每天之後第一個更熱的溫度
```

@@solution
class Browser:
    def __init__(self, home):
        self.current = home
        self.back_stack = []
        self.forward_stack = []

    def visit(self, url):
        self.back_stack.append(self.current)
        self.current = url
        self.forward_stack.clear()

    def back(self):
        if self.back_stack:
            self.forward_stack.append(self.current)
            self.current = self.back_stack.pop()
        return self.current

    def forward(self):
        if self.forward_stack:
            self.back_stack.append(self.current)
            self.current = self.forward_stack.pop()
        return self.current


b = Browser("google.com")
b.visit("youtube.com")
b.visit("python.org")
print(b.back(), b.back(), b.back())
print(b.forward())
b.visit("pypi.org")
print(b.forward(), b.current)
