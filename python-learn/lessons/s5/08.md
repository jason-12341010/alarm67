## 線性搜尋 — O(n)

一個一個找，最簡單，資料**沒有排序**時只能這樣做：

```python
def linear_search(nums, target):
    for i, x in enumerate(nums):
        if x == target:
            return i
    return -1

print(linear_search([5, 3, 8, 1], 8), linear_search([5, 3, 8, 1], 9))
```

## 二分搜尋 — O(log n)

如果資料**已經排序**，可以每次看中間，**把搜尋範圍砍半**。還記得第 1 階段的猜數字遊戲嗎？

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    step = 0
    while lo <= hi:
        mid = (lo + hi) // 2
        step += 1
        print(f"  第 {step} 步：範圍 [{lo}, {hi}]，看中間 nums[{mid}] = {nums[mid]}")
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1          # 答案在右半邊
        else:
            hi = mid - 1          # 答案在左半邊
    return -1

data = list(range(0, 1000, 3))     # 334 個排好的數字
print("找到位置：", binary_search(data, 699))
```

334 個數字只需要最多 9 步。**10 億**筆資料也只需要大約 **30 步**！

```python
import math
for n in [100, 10_000, 1_000_000, 1_000_000_000]:
    print(f"{n:>13,} 筆資料：線性搜尋最多 {n:>13,} 步，二分搜尋最多 {math.ceil(math.log2(n + 1)):>2} 步")
```

## ⚠️ 二分搜尋很容易寫錯

`lo <= hi` 還是 `lo < hi`？`hi = mid` 還是 `mid - 1`？這些細節很容易造成無窮迴圈或漏掉答案。實務上**用標準函式庫的 `bisect`**：

```python
import bisect

scores = [55, 60, 72, 80, 88, 95]
print(bisect.bisect_left(scores, 80))    # 80 應該插入的位置（最左邊）
print(bisect.bisect_right(scores, 80))   # 插入在相同值的右邊

bisect.insort(scores, 77)                # 插入並保持排序
print(scores)

def contains(sorted_list, x):            # 用 bisect 判斷是否存在
    i = bisect.bisect_left(sorted_list, x)
    return i < len(sorted_list) and sorted_list[i] == x

print(contains(scores, 88), contains(scores, 89))
```

### 實用：分數轉等級

```python
import bisect

def grade(score, breakpoints=[60, 70, 80, 90], grades="FDCBA"):
    return grades[bisect.bisect_right(breakpoints, score)]

print([grade(s) for s in [33, 60, 75, 89, 90, 100]])
```

## 二分搜尋的進階應用：對「答案」做二分

很多問題可以轉換成「**找到滿足條件的最小值**」，只要條件具有單調性（某個值以上都成立、以下都不成立），就能二分搜尋答案：

```python
def sqrt_int(n):
    """不用 math.sqrt，找出 x * x <= n 的最大整數 x"""
    lo, hi = 0, n
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if mid * mid <= n:
            lo = mid               # mid 可行，答案 >= mid
        else:
            hi = mid - 1
    return lo

print(sqrt_int(10), sqrt_int(16), sqrt_int(10 ** 18))
```

```python
import math

def min_speed(piles, hours):
    """吃香蕉問題：每小時最少要吃幾根，才能在 hours 小時內吃完所有堆？"""
    def can_finish(speed):
        return sum(math.ceil(p / speed) for p in piles) <= hours

    lo, hi = 1, max(piles)
    while lo < hi:
        mid = (lo + hi) // 2
        if can_finish(mid):
            hi = mid               # 可以，試試看更慢的
        else:
            lo = mid + 1
    return lo

print(min_speed([3, 6, 7, 11], 8))
print(min_speed([30, 11, 23, 4, 20], 6))
```

## 雜湊搜尋 — O(1)

如果要**大量重複查詢**，最快的方法是先建好 `set` 或 `dict`：

```python
users = [("u001", "小明"), ("u002", "小美"), ("u003", "阿華")]
index = {uid: name for uid, name in users}    # 建立索引：O(n)，只做一次
print(index["u002"], index.get("u999", "查無此人"))  # 之後每次查詢：O(1)
```

這就是**資料庫索引**的基本概念。

## 搜尋方法比較

| 方法 | 時間 | 前提 |
|---|---|---|
| 線性搜尋 | O(n) | 無 |
| 二分搜尋 | O(log n) | 資料已排序 |
| 雜湊（set / dict） | O(1) | 先花 O(n) 建立，並使用額外記憶體 |

import bisect


def search_range(nums, target):
    left = bisect.bisect_left(nums, target)
    if left == len(nums) or nums[left] != target:
        return [-1, -1]
    return [left, bisect.bisect_right(nums, target) - 1]


print(search_range([5, 7, 7, 8, 8, 8, 10], 8))
