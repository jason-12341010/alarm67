到目前為止我們都在瀏覽器裡寫 Python。但真正的專案（網站、AI 模型、自動化腳本）都要在**自己的電腦**上開發。這一課一步一步帶你安裝好開發環境。

## 第 1 步：安裝 Python

### Windows

1. 到 [python.org/downloads](https://www.python.org/downloads/) 下載最新版的 Python 3（例如 3.13）
2. 執行安裝程式，**一定要勾選最下面的 ✅ Add python.exe to PATH**（這步最重要！）
3. 按 **Install Now**
4. 開啟「**命令提示字元**」或「**PowerShell**」（開始選單搜尋 `cmd` 或 `PowerShell`），輸入：

```bash
python --version
```

看到 `Python 3.13.x` 就成功了。

> ⚠️ 如果出現「找不到命令」或跳出 Microsoft Store，表示沒有勾選 Add to PATH。重新執行安裝程式，選 **Modify**，或解除安裝後重裝並記得勾選。

### macOS

Mac 內建的 Python 版本通常很舊。建議：

1. 到 [python.org/downloads](https://www.python.org/downloads/) 下載 macOS 安裝檔，雙擊安裝
2. 開啟「**終端機**」（Terminal，用 Spotlight 搜尋），輸入：

```bash
python3 --version
```

> 💡 在 Mac 和 Linux 上，指令通常是 `python3` 和 `pip3`；Windows 上是 `python` 和 `pip`。之後的課程如果寫 `python`，Mac 使用者請改成 `python3`。

## 第 2 步：安裝 VS Code

[Visual Studio Code](https://code.visualstudio.com/) 是目前最多人使用的免費程式編輯器。

1. 下載並安裝 VS Code
2. 開啟 VS Code，點左邊的**擴充功能**圖示（四個方塊），搜尋並安裝：
   - **Python**（Microsoft 出的，會一起裝好 Pylance）
   - **Chinese (Traditional) Language Pack**（選用，介面變中文）

## 第 3 步：寫第一個程式

1. 在桌面建立一個資料夾，例如 `python-practice`
2. VS Code 選 **檔案 → 開啟資料夾**，選這個資料夾
3. 新增檔案 `hello.py`，輸入：

```py
name = input("你叫什麼名字？")
print(f"哈囉，{name}！歡迎來到 Python 的世界")
```

4. 按右上角的 **▶ 執行按鈕**，或在終端機輸入：

```bash
python hello.py
```

程式會在 VS Code 下方的**終端機**面板執行，在那裡輸入名字。

## 第 4 步：認識終端機的基本指令

開發時會常常用到終端機（VS Code 裡按 <kbd>Ctrl</kbd> + <kbd>`</kbd> 開啟）：

| 功能 | Windows | Mac / Linux |
|---|---|---|
| 目前在哪個資料夾 | `cd` | `pwd` |
| 列出檔案 | `dir` | `ls` |
| 進入資料夾 | `cd 資料夾名稱` | `cd 資料夾名稱` |
| 回上一層 | `cd ..` | `cd ..` |
| 清除畫面 | `cls` | `clear` |
| 停止正在執行的程式 | <kbd>Ctrl</kbd> + <kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>C</kbd> |

> 💡 按 <kbd>Tab</kbd> 鍵可以自動補完檔名和資料夾名稱，按 <kbd>↑</kbd> 可以叫出上一個指令。

## 第 5 步：互動模式（REPL）

直接輸入 `python`（不加檔名）會進入**互動模式**，適合快速測試：

```bash
python
```

```py
>>> 2 ** 10
1024
>>> "python".upper()
'PYTHON'
>>> exit()
```

| 功能 | 快捷鍵（Windows） | 快捷鍵（Mac） |
|---|---|---|
| 命令選擇區 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> |
| 快速開啟檔案 | <kbd>Ctrl</kbd>+<kbd>P</kbd> | <kbd>⌘</kbd>+<kbd>P</kbd> |
| 註解 / 取消註解 | <kbd>Ctrl</kbd>+<kbd>/</kbd> | <kbd>⌘</kbd>+<kbd>/</kbd> |
| 跳到定義 | <kbd>F12</kbd> | <kbd>F12</kbd> |

| 格式化程式碼 | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> | <kbd>Shift</kbd>+<kbd>⌥</kbd>+<kbd>F</kbd> |

### 除錯器（Debugger）

比到處加 `print` 更強大的除錯方式：

1. 在行號左邊點一下，出現**紅點**（中斷點）
2. 按 <kbd>F5</kbd> 開始除錯
3. 程式會停在紅點那一行，左邊可以看到**所有變數目前的值**
4. 按 <kbd>F10</kbd> 執行下一行、<kbd>F11</kbd> 進入函式

## 常見問題

| 問題 | 解決方法 |
|---|---|
| `'python' 不是內部或外部命令` | 安裝時沒勾 Add to PATH，重新安裝 |
| VS Code 找不到 Python | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> → `Python: Select Interpreter` → 選你安裝的版本 |
| 中文印出來是亂碼（Windows） | 檔案用 UTF-8 存檔（VS Code 右下角可以看到編碼）；或在終端機執行 `chcp 65001` |
| `SyntaxError` 但程式看起來沒錯 | 檢查是不是用到全形符號，例如 `（`、`：`、`"` |
