排序是最基本的演算法問題。實務上直接用 `sorted()` 就好，但**學會排序演算法**能訓練你的演算法思維，而且面試很常考。

## 1. 氣泡排序（Bubble Sort）— O(n²)

相鄰的兩個比較，大的往後換。每一輪都會把最大的「冒泡」到最後面：

```python
def bubble_sort(nums):
    a = nums[:]                        # 複製一份，不改原本的
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):     # 最後 i 個已經排好了
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        print(f"第 {i + 1} 輪：{a}")
        if not swapped:                # 沒有交換 → 已經排好，提早結束
            break
    return a

print(bubble_sort([5, 1, 4, 2, 8, 3]))
```

## 2. 選擇排序（Selection Sort）— O(n²)

每一輪找出**剩下的最小值**，放到前面：

```python
def selection_sort(nums):
    a = nums[:]
    for i in range(len(a)):
        min_i = min(range(i, len(a)), key=lambda k: a[k])
        a[i], a[min_i] = a[min_i], a[i]
    return a

print(selection_sort([64, 25, 12, 22, 11]))
```

## 3. 插入排序（Insertion Sort）— O(n²)，但對「幾乎排好」的資料很快

像整理撲克牌：拿起一張，插到前面已經排好的牌裡正確的位置：

```python
def insertion_sort(nums):
    a = nums[:]
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:   # 比 key 大的往後挪
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

print(insertion_sort([12, 11, 13, 5, 6]))
```

## 4. 合併排序（Merge Sort）— O(n log n)

**分治法（Divide and Conquer）**：把串列切成兩半，各自排好，再**合併**：

```python
def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    return result + left[i:] + right[j:]

def merge_sort(nums, depth=0):
    if len(nums) <= 1:
        return nums
    mid = len(nums) // 2
    left = merge_sort(nums[:mid], depth + 1)
    right = merge_sort(nums[mid:], depth + 1)
    merged = merge(left, right)
    print("  " * depth + f"合併 {left} + {right} → {merged}")
    return merged

print(merge_sort([38, 27, 43, 3, 9, 82, 10]))
```

為什麼是 O(n log n)？切一半要切 **log n 層**，每一層合併總共要處理 **n 個元素**。

## 5. 快速排序（Quick Sort）— 平均 O(n log n)

選一個**基準值（pivot）**，比它小的放左邊、大的放右邊，再對兩邊遞迴：

```python
def quick_sort(nums):
    if len(nums) <= 1:
        return nums
    pivot = nums[len(nums) // 2]
    less = [x for x in nums if x < pivot]
    equal = [x for x in nums if x == pivot]
    greater = [x for x in nums if x > pivot]
    return quick_sort(less) + equal + quick_sort(greater)

print(quick_sort([3, 6, 8, 10, 1, 2, 1]))
```

## 比較速度

```python
import random, time

def bubble(a):
    a = a[:]
    for i in range(len(a)):
        for j in range(len(a) - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a

def merge_sort(a):
    if len(a) <= 1:
        return a
    m = len(a) // 2
    l, r = merge_sort(a[:m]), merge_sort(a[m:])
    out, i, j = [], 0, 0
    while i < len(l) and j < len(r):
        if l[i] <= r[j]: out.append(l[i]); i += 1
        else: out.append(r[j]); j += 1
    return out + l[i:] + r[j:]

for n in [500, 1000, 2000]:
    data = [random.random() for _ in range(n)]
    for f in (bubble, merge_sort, sorted):
        t = time.perf_counter()
        f(data)
        print(f"n={n:<5}{f.__name__:<12}{(time.perf_counter() - t) * 1000:8.1f} ms")
    print()
```

Python 內建的 `sorted()` 使用 **Timsort**（合併排序 + 插入排序的混合），用 C 實作，最壞情況 O(n log n)，對真實世界的資料特別快。

## 穩定排序

**穩定（stable）**：相等的元素，排序後**保持原本的先後順序**。Python 的 `sorted()` 是穩定的，所以可以**分多次排序**：

```python
students = [("小明", "B"), ("小美", "A"), ("阿華", "B"), ("小強", "A")]
by_name = sorted(students, key=lambda s: s[0])
by_grade = sorted(by_name, key=lambda s: s[1])     # 同等級的，保持名字順序
print(by_grade)
```

## 總整理

| 演算法 | 平均 | 最壞 | 額外空間 | 穩定 |
|---|---|---|---|---|
| 氣泡 | O(n²) | O(n²) | O(1) | ✅ |
| 選擇 | O(n²) | O(n²) | O(1) | ❌ |
| 插入 | O(n²) | O(n²) | O(1) | ✅ |
| 合併 | O(n log n) | O(n log n) | O(n) | ✅ |
| 快速 | O(n log n) | O(n²) | O(log n) | ❌ |
| Timsort（Python） | O(n log n) | O(n log n) | O(n) | ✅ |
