從這一課開始進入**演算法**。演算法是解決問題的步驟，而**時間複雜度**是評估演算法好壞最重要的工具。這也是軟體工程師面試**必考**的內容。

## 同一個問題，速度差很多

問題：判斷一個串列裡有沒有重複的數字。

```python
import time, random

def has_dup_slow(nums):              # 每兩個都比一次
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] == nums[j]:
                return True
    return False

def has_dup_sort(nums):              # 先排序，重複的會相鄰
    s = sorted(nums)
    return any(a == b for a, b in zip(s, s[1:]))

def has_dup_set(nums):               # 用 set 記錄看過的
    seen = set()
    for n in nums:
        if n in seen:
            return True
        seen.add(n)
    return False

for n in [1000, 2000, 4000]:
    data = random.sample(range(10 ** 9), n)      # 沒有重複（最壞情況）
    for f in (has_dup_slow, has_dup_sort, has_dup_set):
        t = time.perf_counter()
        f(data)
        print(f"n={n:<5} {f.__name__:<14} {(time.perf_counter() - t) * 1000:8.2f} ms")
    print()
```

注意：資料量**變 2 倍**時，`slow` 的時間大約變 **4 倍**，`set` 版本只變 **2 倍**。

## Big-O 表示法

Big-O 描述的是：**當資料量 n 變大時，執行時間成長的速度**。我們只在乎「成長的趨勢」，忽略常數和小項。

| 複雜度 | 名稱 | n = 1,000 時的步數 | 例子 |
|---|---|---|---|
| O(1) | 常數 | 1 | 串列用索引取值、dict / set 查詢 |
| O(log n) | 對數 | ~10 | 二分搜尋 |
| O(n) | 線性 | 1,000 | 走過一次串列、`x in list` |
| O(n log n) | | ~10,000 | 好的排序（`sorted()`） |
| O(n²) | 平方 | 1,000,000 | 兩層巢狀迴圈 |
| O(2ⁿ) | 指數 | 天文數字 | 暴力列舉所有子集合 |

```python
import math

print(f"{'n':>8}{'log n':>8}{'n log n':>12}{'n²':>16}{'2ⁿ':>12}")
for n in [10, 100, 1000, 10_000, 1_000_000]:
    two_n = f"{2 ** n:.1e}" if n <= 1000 else "∞"
    print(f"{n:>8}{math.log2(n):>8.0f}{n * math.log2(n):>12,.0f}{n * n:>16,}{two_n:>12}")
```

## 怎麼分析複雜度？

```py
def example(nums):            # n = len(nums)
    total = 0                 # O(1)
    for x in nums:            # 迴圈 n 次
        total += x            #   每次 O(1)  → 合計 O(n)
    for x in nums:            # 外層 n 次
        for y in nums:        #   內層 n 次 → 合計 O(n²)
            pass
    return total
# 總共 O(1) + O(n) + O(n²) = O(n²)（只留最大的那一項）
```

規則：
1. **一層迴圈**跑 n 次 → O(n)
2. **巢狀迴圈** → 相乘，兩層是 O(n²)
3. **依序執行**的部分 → 相加，只保留最大的
4. **每次砍半** → O(log n)

## Python 常見操作的複雜度

| 操作 | list | dict / set |
|---|---|---|
| 取值 `a[i]` / `d[k]` | O(1) | O(1) |
| `x in` | **O(n)** | **O(1)** |
| `append` / 加入 | O(1) | O(1) |
| `insert(0, x)` / `pop(0)` | **O(n)**（用 deque） | — |
| `pop()` 最後一個 | O(1) | — |
| `sorted()` / `.sort()` | O(n log n) | — |
| 切片 `a[i:j]` | O(j - i) | — |

> ⚠️ 隱藏的 O(n)：在迴圈裡寫 `if x in some_list`、`some_list.index(x)`、`some_list.pop(0)`，整個程式就悄悄變成 O(n²) 了。

## 空間複雜度

除了時間，也要考慮**額外使用的記憶體**：

```python
def reverse_copy(nums):       # O(n) 額外空間：建立新串列
    return nums[::-1]

def reverse_in_place(nums):   # O(1) 額外空間：原地交換
    i, j = 0, len(nums) - 1
    while i < j:
        nums[i], nums[j] = nums[j], nums[i]
        i, j = i + 1, j - 1
    return nums

print(reverse_copy([1, 2, 3, 4]), reverse_in_place([1, 2, 3, 4]))
```

用空間換時間是很常見的技巧（例如上面用 set 加速、用快取加速）。

## 經典題：Two Sum

找出串列中**相加等於 target 的兩個數字的索引**。這是 LeetCode 第 1 題：

```python
def two_sum_slow(nums, target):          # O(n²)
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]

def two_sum(nums, target):               # O(n)：用字典記住「看過的數字 → 索引」
    seen = {}
    for i, n in enumerate(nums):
        need = target - n
        if need in seen:
            return [seen[need], i]
        seen[n] = i

print(two_sum_slow([2, 7, 11, 15], 9), two_sum([2, 7, 11, 15], 9))
print(two_sum([3, 2, 4], 6))
```
