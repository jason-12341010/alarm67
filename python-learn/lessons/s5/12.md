**動態規劃（Dynamic Programming, DP）**：把大問題拆成**重疊的小問題**，每個小問題**只算一次**並記下來，最後組合出答案。

適用 DP 的問題有兩個特徵：
1. **最佳子結構**：大問題的最佳解，可以由小問題的最佳解組成
2. **重疊子問題**：同樣的小問題會被重複計算很多次

## 從遞迴到 DP：爬樓梯

> 每次可以爬 1 階或 2 階，爬到第 n 階有幾種方法？

想法：要到第 n 階，最後一步不是從 n-1 階跨 1 步，就是從 n-2 階跨 2 步。所以 `ways(n) = ways(n-1) + ways(n-2)`。

```python
from functools import lru_cache

# 方法 1：由上而下（遞迴 + 記憶化）
@lru_cache(maxsize=None)
def ways_memo(n):
    if n <= 1:
        return 1
    return ways_memo(n - 1) + ways_memo(n - 2)

# 方法 2：由下而上（填表）
def ways_table(n):
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

# 方法 3：只保留需要的值（省空間）
def ways(n):
    a, b = 1, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

print([ways_table(n) for n in range(1, 11)])
print(ways_memo(50), ways(50))
```

## DP 解題四步驟

1. **定義狀態**：`dp[i]` 代表什麼？
2. **找出轉移式**：`dp[i]` 怎麼由更小的狀態算出來？
3. **初始值**：最小的狀態是多少？
4. **計算順序**：由小到大填表

## 找零錢：最少要幾個硬幣？

> 硬幣面額 `[1, 5, 10, 50]`，要湊出 n 元，最少需要幾個硬幣？

1. 狀態：`dp[x]` = 湊出 x 元最少要幾個硬幣
2. 轉移：`dp[x] = min(dp[x - c] + 1)`，c 是每一種硬幣
3. 初始：`dp[0] = 0`

```python
def min_coins(coins, amount):
    INF = float("inf")
    dp = [0] + [INF] * amount
    for x in range(1, amount + 1):
        for c in coins:
            if c <= x and dp[x - c] + 1 < dp[x]:
                dp[x] = dp[x - c] + 1
    return dp[amount] if dp[amount] != INF else -1

print(min_coins([1, 5, 10, 50], 68))       # 50 + 10 + 5 + 1 + 1 + 1 = 6 個
print(min_coins([1, 3, 4], 6))             # 3 + 3 = 2 個（貪心法會選 4+1+1 = 3 個，錯！）
print(min_coins([5, 10], 3))
```

> 💡 第二個例子說明了為什麼需要 DP：「每次都拿最大的」這種**貪心法**不一定能得到最佳解。

## 背包問題（0/1 Knapsack）

> 背包最多裝 W 公斤，每個物品有重量和價值，每個物品只能拿一次。怎麼拿總價值最高？

```python
def knapsack(items, W):
    # dp[w] = 容量 w 時的最高價值
    dp = [0] * (W + 1)
    for name, weight, value in items:
        for w in range(W, weight - 1, -1):          # 倒著跑，確保每個物品只用一次
            dp[w] = max(dp[w], dp[w - weight] + value)
    return dp[W]

items = [
    ("筆電", 3, 2000),
    ("相機", 1, 1500),
    ("吉他", 4, 3000),
    ("手錶", 1, 800),
]
print("最高價值：", knapsack(items, 4))
```

## 最長共同子序列（LCS）

兩個字串中，**順序相同**（不一定要連續）的最長共同部分。用來比較文件差異（`git diff`）、DNA 序列比對：

```python
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    # 從表格倒推出實際的子序列
    result, i, j = [], m, n
    while i and j:
        if a[i - 1] == b[j - 1]:
            result.append(a[i - 1]); i -= 1; j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1
    return "".join(reversed(result))

print(lcs("ABCBDAB", "BDCABA"))
print(lcs("我喜歡學習 Python 程式", "我很喜歡寫 Python"))
```

## 編輯距離

把一個字串變成另一個，最少要幾次「插入、刪除、替換」？這就是**拼字檢查**和**模糊搜尋**的原理：

```python
def edit_distance(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if a[i - 1] == b[j - 1] else 1
            dp[i][j] = min(dp[i - 1][j] + 1,        # 刪除
                           dp[i][j - 1] + 1,        # 插入
                           dp[i - 1][j - 1] + cost) # 替換
    return dp[m][n]

words = ["python", "pandas", "pytorch", "numpy", "flask"]
typo = "pyhton"
print(sorted(words, key=lambda w: edit_distance(typo, w))[:2], "← 你是不是要找這個？")
print(edit_distance("kitten", "sitting"))
```

`cur = max(x, cur + x)`：要嘛接在前面的子陣列後面，要嘛從 x 重新開始。同時記錄看過的最大 `cur`。
@@solution
def max_subarray(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)
        best = max(best, cur)
    return best
