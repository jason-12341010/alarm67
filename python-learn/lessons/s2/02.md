## 預設值

參數可以設定預設值，呼叫時沒有傳就用預設值：

```python
def greet(name, greeting="哈囉"):
    return f"{greeting}，{name}！"

print(greet("小明"))
print(greet("小明", "早安"))
```

> ⚠️ 有預設值的參數要放在**後面**：`def f(a=1, b)` 是錯的。

## 關鍵字引數

呼叫時可以指定參數名稱，順序就不重要了，而且更好讀：

```python
def make_coffee(size, sugar, ice):
    return f"{size}杯，{sugar}，{ice}"

print(make_coffee("大", "半糖", "少冰"))
print(make_coffee(ice="去冰", size="中", sugar="無糖"))
```

## ⚠️ 預設值的陷阱：不要用可變物件

預設值只會在**定義函式時**建立一次。如果用串列當預設值，每次呼叫都會共用同一個串列：

```python
def add_item(item, cart=[]):     # ❌ 危險
    cart.append(item)
    return cart

print(add_item("蘋果"))
print(add_item("香蕉"))           # 蘋果怎麼還在？！

def add_item_ok(item, cart=None):  # ✅ 正確寫法
    if cart is None:
        cart = []
    cart.append(item)
    return cart

print(add_item_ok("蘋果"))
print(add_item_ok("香蕉"))
```

## *args：接收任意數量的位置引數

參數前面加 `*`，多出來的引數會被收集成一個 **tuple**：

```python
def total(*nums):
    print("收到：", nums)
    return sum(nums)

print(total(1, 2))
print(total(1, 2, 3, 4, 5))
print(total())
```

## **kwargs：接收任意數量的關鍵字引數

參數前面加 `**`，多出來的關鍵字引數會被收集成一個 **dict**：

```python
def profile(name, **info):
    print(f"名字：{name}")
    for key, value in info.items():
        print(f"  {key}：{value}")

profile("小明", age=18, city="台北", hobby="程式")
```

## 全部組合

順序是：一般參數 → `*args` → 關鍵字參數 → `**kwargs`

```python
def demo(a, b=2, *args, c=3, **kwargs):
    print(f"{a=} {b=} {args=} {c=} {kwargs=}")

demo(1)
demo(1, 20, 300, 400, c=30, d=40)
```

> 💡 放在 `*args` 後面的參數（上面的 `c`）**只能用關鍵字傳入**。

## 反過來：用 * 和 ** 拆開傳入

```python
def add3(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add3(*nums))               # 等於 add3(1, 2, 3)

opts = {"a": 10, "b": 20, "c": 30}
print(add3(**opts))              # 等於 add3(a=10, b=20, c=30)
```

## 只能用位置 / 只能用關鍵字

```python
def f(a, b, /, c, *, d):
    # a, b 只能用位置傳；d 只能用關鍵字傳；c 都可以
    return a + b + c + d

print(f(1, 2, 3, d=4))
print(f(1, 2, c=3, d=4))
```

@@solution
def average(*nums, digits=2):
    if not nums:
        return 0
    return round(sum(nums) / len(nums), digits)


print(average(1, 2, 3, 4))
print(average(1, 2, 2, digits=3))
print(average())

:::exercise 建立 HTML 標籤
寫 `tag(name, content, **attrs)`，回傳 HTML 字串。例如：

`tag("a", "首頁", href="/", target="_blank")` → `<a href="/" target="_blank">首頁</a>`

`tag("p", "hi")` → `<p>hi</p>`
@@starter
def tag(name, content, **attrs):
    pass


print(tag("a", "首頁", href="/", target="_blank"))
print(tag("p", "hi"))
@@check
f = ns.get("tag")
assert callable(f), "找不到函式 tag"
assert f("p", "hi") == "<p>hi</p>", f"tag('p', 'hi') 應該是 '<p>hi</p>'，你的是 {f('p', 'hi')!r}"
got = f("a", "首頁", href="/", target="_blank")
assert got == '<a href="/" target="_blank">首頁</a>', f"結果不對：{got!r}"
assert f("img", "", src="x.png") == '<img src="x.png"></img>', "只有一個屬性時也要正確"
@@hint
先用迴圈把 attrs 組成 `' href="/" target="_blank"'` 這樣的字串（每個屬性前面有一個空白），再組合起來。
@@solution
def tag(name, content, **attrs):
    attr_text = ""
    for key, value in attrs.items():
        attr_text += f' {key}="{value}"'
    return f"<{name}{attr_text}>{content}</{name}>"


print(tag("a", "首頁", href="/", target="_blank"))
print(tag("p", "hi"))
