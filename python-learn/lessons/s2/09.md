**模組（module）** 就是一個 `.py` 檔案。Python 內建了上百個模組（叫做**標準函式庫**），另外還有幾十萬個第三方套件。會用模組，才能真正發揮 Python 的威力。

## import 的寫法

```python
import math                       # 匯入整個模組
print(math.sqrt(16), math.pi)

from math import sqrt, pi         # 只匯入需要的名稱
print(sqrt(25), pi)

import datetime as dt             # 取別名
print(dt.date.today())

from random import randint as ri
print(ri(1, 6))
```

> ⚠️ 避免 `from math import *`：會把一大堆名稱倒進來，很容易跟自己的變數撞名。

## 常用標準函式庫一覽

### math：數學

```python
import math
print(math.ceil(3.2), math.floor(3.8))    # 無條件進位 / 捨去
print(math.gcd(12, 18), math.lcm(4, 6))   # 最大公因數 / 最小公倍數
print(math.factorial(5))
print(math.log10(1000), math.log(math.e))
print(math.isclose(0.1 + 0.2, 0.3))       # 比較浮點數的正確方式
```

### random：隨機

```python
import random
print(random.random())                    # 0～1 的小數
print(random.uniform(1, 10))
print(random.sample(range(1, 50), 6))     # 不重複抽 6 個（樂透！）
print(random.choices(["A", "B"], weights=[9, 1], k=10))   # 加權抽樣
```

### datetime：日期與時間

```python
from datetime import datetime, date, timedelta

now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M"))      # 格式化成字串
d = datetime.strptime("2026-12-25", "%Y-%m-%d")   # 字串轉成日期
print(d.weekday())                         # 0 是星期一

today = date(2026, 11, 4)
xmas = date(2026, 12, 25)
print((xmas - today).days, "天後是聖誕節")
print(today + timedelta(weeks=2))
```

### collections：進階容器

```python
from collections import Counter, defaultdict

words = "the cat and the dog and the bird".split()
c = Counter(words)
print(c)
print(c.most_common(2))

groups = defaultdict(list)                 # 不存在的鍵會自動建立空串列
for w in words:
    groups[len(w)].append(w)
print(dict(groups))
```

## 建立自己的模組

把函式寫在一個 `.py` 檔，其他程式就可以 import。這裡用程式先建立檔案來示範：

```python
from pathlib import Path

Path("mytools.py").write_text('''
"""我的工具模組"""
PI = 3.14159

def circle_area(r):
    return PI * r ** 2

def greet(name):
    return f"哈囉，{name}"
''', encoding="utf-8")

import sys, importlib
if "" not in sys.path:
    sys.path.insert(0, "")         # 網頁版才需要：讓 Python 從目前資料夾找模組
importlib.invalidate_caches()

import mytools
importlib.reload(mytools)          # 確保拿到最新版本（一般情況不需要）
print(mytools.circle_area(2))
print(mytools.greet("小明"))
```

在自己的電腦上，只要把 `mytools.py` 和主程式放在**同一個資料夾**，就可以直接 `import mytools`。

## `if __name__ == "__main__":`

這是 Python 程式裡很常見的一行。意思是：**只有直接執行這個檔案時**才執行下面的程式，被別人 import 時不會執行：

```python
def main():
    print("主程式開始")

if __name__ == "__main__":
    main()

print("__name__ 的值是：", __name__)
```

@@solution
from datetime import date, datetime

START = date(2026, 1, 1)

def days_until(target):
    d = datetime.strptime(target, "%Y-%m-%d").date()
    return (d - START).days


print(days_until("2026-12-25"))
