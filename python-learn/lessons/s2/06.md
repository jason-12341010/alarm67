Python 內建了很多好用的函式，善用它們可以讓程式更短、更清楚。

## enumerate：索引 + 值

```python
fruits = ["蘋果", "香蕉", "芒果"]

# ❌ 不夠 Pythonic
for i in range(len(fruits)):
    print(i, fruits[i])

# ✅ 用 enumerate
for i, f in enumerate(fruits, start=1):
    print(i, f)
```

## zip：把多個串列配對

```python
names = ["小明", "小美", "阿華"]
scores = [85, 92, 78]
for name, score in zip(names, scores):
    print(f"{name}: {score}")

d = dict(zip(names, scores))      # 快速建立字典
print(d)

# 長度不同時，以最短的為準
print(list(zip([1, 2, 3], "ab")))

# 「解壓縮」：zip(*...) 可以把配對拆回來
pairs = [("a", 1), ("b", 2), ("c", 3)]
letters, nums = zip(*pairs)
print(letters, nums)
```

## any / all

```python
nums = [3, 8, 12, 5]
print(any(n > 10 for n in nums))     # 有任何一個 > 10？
print(all(n > 0 for n in nums))      # 全部都 > 0？

passwords = "Abc12345"
checks = [
    len(passwords) >= 8,
    any(c.isupper() for c in passwords),
    any(c.isdigit() for c in passwords),
]
print("密碼強度合格" if all(checks) else "密碼太弱")
```

## sum / min / max / abs / round

```python
nums = [3, -7, 2, 9]
print(sum(nums), min(nums), max(nums))
print(max(nums, key=abs))          # 絕對值最大的
print(sum([0.1] * 10))             # 浮點數誤差
print(round(2.675, 2))             # 也是浮點數誤差造成的
print(round(2.5), round(3.5))      # 銀行家捨入：取最近的偶數！
print(divmod(17, 5))               # 同時得到商和餘數
print(pow(2, 10), abs(-3.5))
```

> 💡 Python 的 `round()` 遇到剛好 .5 時，會取**最近的偶數**（2.5 → 2，3.5 → 4），這叫「銀行家捨入」，可以減少統計上的偏差。


## 型別檢查：type / isinstance

```python
x = 3.14
print(type(x) == float)
print(isinstance(x, (int, float)))   # 可以一次檢查多種型別
print(isinstance(True, int))         # True 其實是 int 的子類別！
```

凱薩密碼把每個英文字母往後移 `shift` 位（z 之後回到 a）。寫 `caesar(text, shift)`，只轉換**小寫英文字母**，其他字元保持不變。

提示：用 `ord()` 和 `chr()`。
@@starter
def caesar(text, shift):
    pass


print(caesar("hello, world!", 3))
@@check
f = ns.get("caesar")
assert callable(f), "找不到函式 caesar"
assert f("abc", 1) == "bcd", f"caesar('abc', 1) 應該是 'bcd'，你的是 {f('abc', 1)!r}"
assert f("xyz", 3) == "abc", f"caesar('xyz', 3) 應該是 'abc'（要繞回去），你的是 {f('xyz', 3)!r}"
assert f("hello, world!", 3) == "khoor, zruog!", "標點和空白要保持不變"
assert f(f("python", 10), -10) == "python", "shift 是負數時要能解密"
@@hint
對每個字元 `c`：如果 `"a" <= c <= "z"`，就算 `chr((ord(c) - ord("a") + shift) % 26 + ord("a"))`。
@@solution
def caesar(text, shift):
    result = ""
    for c in text:
        if "a" <= c <= "z":
            result += chr((ord(c) - ord("a") + shift) % 26 + ord("a"))
        else:
            result += c
    return result


print(caesar("hello, world!", 3))
