Python 3.10 加入了 `match` 語法，可以根據資料的**值**或**結構**做不同的處理。它比一長串 `if / elif` 更清楚，而且功能強大很多。

## 基本用法：比對值

```python
def http_status(code):
    match code:
        case 200:
            return "成功"
        case 404:
            return "找不到頁面"
        case 500 | 502 | 503:          # | 表示「或」
            return "伺服器錯誤"
        case _:                        # _ 代表「其他所有情況」
            return "未知狀態"

for c in [200, 404, 502, 418]:
    print(c, http_status(c))
```

## 比對結構：拆解序列

`match` 真正強大的地方是**同時檢查形狀、拆出變數**：

```python
def handle(command):
    match command.split():
        case ["quit"]:
            return "離開程式"
        case ["go", direction]:
            return f"往 {direction} 走"
        case ["take", item, "from", place]:
            return f"從 {place} 拿起 {item}"
        case ["drop", *items]:
            return f"丟下 {', '.join(items)}"
        case _:
            return "看不懂的指令"

for cmd in ["go north", "take key from table", "drop sword shield", "quit", "dance"]:
    print(f"{cmd!r:25} → {handle(cmd)}")
```

## 加上條件：guard

`case` 後面可以加 `if`：

```python
def classify(point):
    match point:
        case (0, 0):
            return "原點"
        case (x, 0):
            return f"在 x 軸上，x = {x}"
        case (0, y):
            return f"在 y 軸上，y = {y}"
        case (x, y) if x == y:
            return f"在 y = x 這條線上"
        case (x, y):
            return f"一般的點 ({x}, {y})"

for p in [(0, 0), (3, 0), (0, -2), (4, 4), (1, 5)]:
    print(p, classify(p))
```

## 比對字典

處理 JSON / API 資料時特別好用。字典只要**包含**指定的鍵就算符合：

```python
def process(event):
    match event:
        case {"type": "click", "x": x, "y": y}:
            return f"點擊 ({x}, {y})"
        case {"type": "key", "key": "Enter" | "Return"}:
            return "按下 Enter"
        case {"type": "key", "key": k}:
            return f"按下 {k}"
        case {"type": t}:
            return f"不支援的事件：{t}"

events = [
    {"type": "click", "x": 10, "y": 20, "button": "left"},
    {"type": "key", "key": "Enter"},
    {"type": "key", "key": "A"},
    {"type": "scroll"},
]
for e in events:
    print(process(e))
```

## 比對型別

```python
def describe(value):
    match value:
        case bool():                   # bool 要放在 int 前面（因為 True 也是 int）
            return "布林值"
        case int() | float() if value < 0:
            return "負數"
        case int():
            return "整數"
        case float():
            return "小數"
        case str() if not value:
            return "空字串"
        case str():
            return f"字串，長度 {len(value)}"
        case [first, *_]:
            return f"序列，第一個是 {first!r}"
        case _:
            return "其他"

for v in [True, -3, 42, 3.14, "", "hi", [9, 8], None]:
    print(repr(v), "→", describe(v))
```

## 用 as 綁定

```python
match ("go", "north"):
    case ("go", ("north" | "south") as d):
        print("南北向：", d)
```

> 💡 什麼時候用 match？資料有**不同的形狀**、需要**拆解**時，match 特別適合。單純比較數值大小時，用 if / elif 就好。

:::exercise 計算機
寫 `calc(expr)`：`expr` 是像 `"3 + 4"` 這樣的字串（數字和運算子之間用空白隔開）。用 `match` 處理 `+`、`-`、`*`、`/`：
- 除以 0 回傳 `"不能除以 0"`
- 其他運算子回傳 `"不支援的運算"`
- 格式不對（不是三個部分）回傳 `"格式錯誤"`

數字用 `float()` 轉換。
@@starter
def calc(expr):
    match expr.split():
        case [a, "+", b]:
            return float(a) + float(b)


print(calc("3 + 4"), calc("10 / 0"), calc("2 ^ 3"), calc("1 +"))

@@hint
除以 0 可以用 guard：`case [a, "/", b] if float(b) == 0:` 放在一般除法的前面。不支援的運算子：`case [_, _, _]:`；其他：`case _:`。
@@solution
def calc(expr):
    match expr.split():
        case [a, "+", b]:
            return float(a) + float(b)
        case [a, "-", b]:
            return float(a) - float(b)
        case [a, "*", b]:
            return float(a) * float(b)
        case [a, "/", b] if float(b) == 0:
            return "不能除以 0"
        case [a, "/", b]:
            return float(a) / float(b)
        case [_, _, _]:
            return "不支援的運算"
        case _:
            return "格式錯誤"


print(calc("3 + 4"), calc("10 / 0"), calc("2 ^ 3"), calc("1 +"))
