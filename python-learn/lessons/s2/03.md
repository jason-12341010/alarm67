**作用域（scope）** 決定了一個變數「在哪裡看得到」。

## 區域變數 vs 全域變數

- 在函式**裡面**建立的變數是**區域變數**，只在函式裡有效
- 在函式**外面**建立的變數是**全域變數**

```python
x = "全域"

def f():
    y = "區域"
    print(x)    # 函式裡可以「讀」全域變數
    print(y)

f()
print(x)
print(y)        # NameError：y 只存在於函式裡
```

## 同名的變數

函式裡賦值的變數，就算和全域變數同名，也是**另一個新的區域變數**：

```python
count = 0

def f():
    count = 100      # 這是新的區域變數，不會改到外面
    print("裡面", count)

f()
print("外面", count)
```

## UnboundLocalError

只要函式裡**任何地方**對變數賦值，Python 就會把它當成區域變數。所以下面這樣會出錯：

```python
count = 0

def add():
    count = count + 1    # 想讀全域的 count，但它被當成區域變數了
    return count

add()
```

## global：修改全域變數

```python
count = 0

def add():
    global count
    count += 1

add()
add()
print(count)
```

> ⚠️ **盡量少用 `global`**。函式改到外面的變數，程式會很難追蹤。比較好的做法是用參數傳進去、用 return 傳出來：

```python
def add(count):
    return count + 1

count = 0
count = add(count)
count = add(count)
print(count)
```

## nonlocal：修改外層函式的變數

函式裡面可以再定義函式。內層要修改外層函式的變數時，用 `nonlocal`：

```python
def counter():
    n = 0
    def increase():
        nonlocal n
        n += 1
        return n
    return increase

c = counter()
print(c(), c(), c())
c2 = counter()        # 新的計數器，從 0 開始
print(c2())
```

這種「記住外層變數的內層函式」叫做**閉包（closure）**，第 4 階段學裝飾器時會再用到。

## LEGB 規則

Python 找變數時，依照這個順序找：

1. **L**ocal：目前函式裡
2. **E**nclosing：外層函式裡
3. **G**lobal：模組最外層
4. **B**uilt-in：Python 內建（像 `print`、`len`）

```python
x = "G"

def outer():
    x = "E"
    def inner():
        x = "L"
        print(x)
    inner()

outer()
```

試著把 `x = "L"` 刪掉，再把 `x = "E"` 刪掉，觀察印出什麼。

> ⚠️ 不要用內建函式的名字當變數，例如 `list = [1, 2]` 或 `sum = 0`，這樣會蓋掉內建的 `list` 和 `sum`！
