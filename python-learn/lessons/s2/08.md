程式常常需要讀取或儲存資料到檔案。這個網站的 Python 有一個**虛擬的檔案系統**，所以可以直接練習檔案操作（重新整理頁面後檔案就會消失）。

## 寫入檔案

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
    print("Python", "很好玩", file=f)   # print 也可以寫進檔案

print("寫入完成")
```

## 讀取檔案

```python
with open("hello.txt", encoding="utf-8") as f:
    content = f.read()           # 一次讀完整個檔案
print(content)

with open("hello.txt", encoding="utf-8") as f:
    for line in f:               # 一行一行讀（大檔案用這個，省記憶體）
        print(repr(line))

with open("hello.txt", encoding="utf-8") as f:
    lines = f.read().splitlines()   # 讀成串列，自動去掉 \n
print(lines)
```

> 💡 `with` 會在區塊結束時**自動關閉檔案**，即使中間發生錯誤也一樣。永遠用 `with` 開檔案！

## 開檔模式

| 模式 | 意思 |
|---|---|
| `"r"` | 讀取（預設），檔案不存在會出錯 |
| `"w"` | 寫入，**會清空原本的內容** |
| `"a"` | 附加，寫在檔案最後面 |
| `"x"` | 建立新檔，檔案已存在會出錯 |
| `"b"` | 二進位模式，例如 `"rb"`（圖片、影片） |

```python
with open("log.txt", "w", encoding="utf-8") as f:
    f.write("開始\n")
for i in range(3):
    with open("log.txt", "a", encoding="utf-8") as f:
        f.write(f"第 {i} 筆紀錄\n")
print(open("log.txt", encoding="utf-8").read())
```

> ⚠️ 中文檔案一定要加 `encoding="utf-8"`，不然在 Windows 上可能會出現亂碼或錯誤。

## 處理找不到檔案

```python
try:
    with open("不存在.txt", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("找不到檔案")
```

## pathlib：現代的路徑處理

```python
from pathlib import Path

p = Path("data")
p.mkdir(exist_ok=True)                   # 建立資料夾
(p / "notes.txt").write_text("筆記內容", encoding="utf-8")   # 用 / 組合路徑

f = p / "notes.txt"
print(f.exists(), f.name, f.suffix, f.stem)
print(f.read_text(encoding="utf-8"))
print([x.name for x in p.iterdir()])
```

## CSV：表格資料

CSV 是最常見的資料格式之一，資料分析時天天會用到：

```python
import csv

rows = [
    ["姓名", "科目", "分數"],
    ["小明", "數學", 85],
    ["小美", "數學", 92],
    ["小明", "英文", 78],
]
with open("scores.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)

with open("scores.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):        # 每一列變成字典
        print(row["姓名"], row["分數"])
```

## JSON：程式之間交換資料

JSON 的格式幾乎和 Python 的字典、串列一模一樣，是網路 API 最常用的格式：

```python
import json

data = {"name": "小明", "age": 18, "skills": ["Python", "AI"], "married": False}

text = json.dumps(data, ensure_ascii=False, indent=2)   # Python → JSON 字串
print(text)

with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False)                # 直接寫入檔案

with open("user.json", encoding="utf-8") as f:
    loaded = json.load(f)                                 # 從檔案讀回來
print(loaded["skills"])
```

import csv
with open("sales.csv", "w", newline="", encoding="utf-8") as f:
    f.write("name,amount\nAmy,300\nBob,150\nAmy,200\nCat,500\nBob,50\n")

totals = {}
with open("sales.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        totals[row["name"]] = totals.get(row["name"], 0) + int(row["amount"])
