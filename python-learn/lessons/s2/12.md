## 功能規劃

| 指令 | 功能 |
|---|---|
| `add 金額 分類 說明` | 新增一筆支出 |
| `list` | 列出所有紀錄 |
| `sum` | 各分類的總金額 |
| `del 編號` | 刪除一筆 |
| `save` / `load` | 存到 / 讀取 JSON 檔 |
| `quit` | 離開 |

## 設計資料結構

每一筆紀錄是一個字典，所有紀錄放在一個串列裡：

```py
records = [
    {"amount": 120, "category": "餐飲", "note": "午餐"},
    {"amount": 30, "category": "交通", "note": "捷運"},
]
```

## 把功能拆成函式

每個函式只做一件事，這樣比較好寫、好測試：

```python
import json
from collections import defaultdict

FILE = "ledger.json"


def add_record(records, amount, category, note=""):
    amount = float(amount)
    if amount <= 0:
        raise ValueError("金額必須大於 0")
    records.append({"amount": amount, "category": category, "note": note})


def list_records(records):
    if not records:
        print("（目前沒有紀錄）")
        return
    for i, r in enumerate(records, start=1):
        print(f"{i:>3}. {r['category']:<4} {r['amount']:>8,.0f} 元  {r['note']}")


def summary(records):
    totals = defaultdict(float)
    for r in records:
        totals[r["category"]] += r["amount"]
    return dict(sorted(totals.items(), key=lambda kv: -kv[1]))


def delete_record(records, index):
    i = int(index) - 1
    if not 0 <= i < len(records):
        raise IndexError(f"沒有第 {index} 筆紀錄")
    return records.pop(i)


def save(records, path=FILE):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(records, f, ensure_ascii=False, indent=2)


def load(path=FILE):
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []


def main():
    records = load()
    print("💰 記帳本（輸入 help 看指令）")
    while True:
        try:
            line = input("> ").strip()
        except EOFError:
            break
        try:
            match line.split(maxsplit=3):
                case ["add", amount, category, *note]:
                    add_record(records, amount, category, " ".join(note))
                    print("✓ 已新增")
                case ["list"]:
                    list_records(records)
                case ["sum"]:
                    for cat, total in summary(records).items():
                        print(f"  {cat}: {total:,.0f} 元")
                    print(f"  總計: {sum(r['amount'] for r in records):,.0f} 元")
                case ["del", index]:
                    r = delete_record(records, index)
                    print(f"✓ 已刪除：{r['note'] or r['category']}")
                case ["save"]:
                    save(records)
                    print(f"✓ 已儲存 {len(records)} 筆到 {FILE}")
                case ["load"]:
                    records = load()
                    print(f"✓ 已讀取 {len(records)} 筆")
                case ["help"]:
                    print("指令：add 金額 分類 說明 / list / sum / del 編號 / save / load / quit")
                case ["quit"]:
                    break
                case []:
                    continue
                case _:
                    print("看不懂的指令，輸入 help 看說明")
        except (ValueError, IndexError) as e:
            print(f"⚠ {e}")
    print("掰掰！")


main()
```

## 程式設計的重點

1. **資料和介面分開**：`add_record`、`summary` 這些函式不負責 `input` 和 `print`，只處理資料。以後要改成網頁版（第 6 階段），這些函式可以直接重複使用。
2. **錯誤用例外處理**：函式遇到不合理的資料就 `raise`，由 `main` 統一接住並顯示訊息。
3. **match 解析指令**：每種指令的格式一目了然。

from collections import defaultdict

def summary(records):
    totals = defaultdict(float)
    for r in records:
        totals[r["category"]] += r["amount"]
    return dict(totals)


def budget_report(records, budgets):
    spent = summary(records)
    report = []
    for cat, budget in budgets.items():
        used = spent.get(cat, 0)
        if used > budget:
            status = "超支"
        elif used >= budget * 0.8:
            status = "注意"
        else:
            status = "正常"
        report.append((cat, used, budget, status))
    return report


records = [
    {"amount": 120, "category": "餐飲", "note": "午餐"},
    {"amount": 30, "category": "交通", "note": "捷運"},
    {"amount": 1500, "category": "餐飲", "note": "聚餐"},
    {"amount": 900, "category": "購物", "note": "衣服"},
]
for row in budget_report(records, {"餐飲": 1500, "交通": 1000, "購物": 1000, "娛樂": 500}):
