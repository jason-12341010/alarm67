程式執行時發生的錯誤叫做**例外（exception）**。如果不處理，程式就會直接停掉。用 `try / except` 可以「接住」錯誤，讓程式繼續執行。

## 基本寫法

```python
text = "abc"
try:
    n = int(text)
    print("轉換成功", n)
except ValueError:
    print(f"'{text}' 不是數字")
print("程式繼續執行")
```

## 處理多種錯誤

```python
def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("不能除以 0")
    except TypeError:
        print("只能用數字相除")

print(safe_divide(10, 2))
print(safe_divide(10, 0))
print(safe_divide(10, "2"))
```

也可以一次接多種：`except (ValueError, TypeError):`

## 取得錯誤訊息：as

```python
try:
    [1, 2, 3][10]
except IndexError as e:
    print("錯誤類型：", type(e).__name__)
    print("錯誤訊息：", e)
```

## else 與 finally

- `else`：**沒有**發生錯誤時才執行
- `finally`：**不管有沒有錯誤**都會執行（常用來關閉檔案、釋放資源）

```python
def parse(s):
    try:
        n = int(s)
    except ValueError:
        print(f"  {s!r} 轉換失敗")
    else:
        print(f"  {s!r} 轉換成功：{n}")
    finally:
        print("  （檢查完畢）")

parse("42")
parse("4.2")
```

## 實用範例：一直問到輸入正確

```python
while True:
    try:
        age = int(input("請輸入年齡："))
        if age < 0:
            print("年齡不能是負的")
            continue
        break
    except ValueError:
        print("請輸入整數！")
print(f"你 {age} 歲")
```

## raise：主動丟出錯誤

當函式收到不合理的資料時，應該**主動丟出錯誤**，而不是默默回傳奇怪的值：

```python
def withdraw(balance, amount):
    if amount <= 0:
        raise ValueError("提款金額必須大於 0")
    if amount > balance:
        raise ValueError(f"餘額不足：只剩 {balance} 元")
    return balance - amount

print(withdraw(1000, 300))
try:
    withdraw(1000, 5000)
except ValueError as e:
    print("提款失敗：", e)
```

## 自訂例外

建立自己的錯誤類型（`class` 會在第 3 階段詳細介紹）：

```python
class InsufficientFunds(Exception):
    pass

try:
    raise InsufficientFunds("餘額不足")
except InsufficientFunds as e:
    print("捕捉到自訂錯誤：", e)
```

## 好習慣

- ✅ **只接你預期會發生的錯誤**（例如 `ValueError`）
- ❌ 不要寫空的 `except:` 或 `except Exception: pass`，這會把所有 bug 都藏起來
- ✅ `try` 區塊裡**只放可能出錯的那幾行**

```python
# ❌ 壞習慣：連打錯字的 bug 都被藏起來了
try:
    reslt = 10 / 2
    print(result)
except:
    print("出錯了")     # 你永遠不會知道其實是變數名稱打錯
```

## 例外的家族

所有例外都繼承自 `Exception`。`except` 父類別也會接住子類別：

```python
print(ZeroDivisionError.__mro__)
try:
    1 / 0
except ArithmeticError:        # ZeroDivisionError 是 ArithmeticError 的子類別
    print("接住了")
```

def to_int(s, default=0):
    try:
        return int(s)
    except (ValueError, TypeError):
        return default


print(to_int("42"), to_int("abc"), to_int(None, -1))

def set_age(age):
    if not isinstance(age, int):
        raise TypeError("年齡必須是整數")
    if age < 0 or age > 150:
        raise ValueError("年齡超出範圍")
    return age


print(set_age(20))
