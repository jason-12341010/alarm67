**推導式（comprehension）** 是 Python 最有特色的語法之一，用一行建立串列、字典或集合。

## 串列推導式

```python
# 一般寫法
squares = []
for x in range(1, 6):
    squares.append(x ** 2)
print(squares)

# 推導式：[運算式 for 變數 in 可迭代物件]
squares = [x ** 2 for x in range(1, 6)]
print(squares)
```

## 加上條件篩選

```python
nums = [5, 12, 7, 20, 3, 18]
big = [n for n in nums if n > 10]
print(big)

words = ["Python", "is", "an", "awesome", "language"]
long_upper = [w.upper() for w in words if len(w) > 3]
print(long_upper)
```

## if / else 放在前面

注意位置不同，意思也不同：
- `[x for x in ... if 條件]` → **篩選**（不符合的直接丟掉）
- `[A if 條件 else B for x in ...]` → **轉換**（每個都保留，但值不同）

```python
nums = [1, 2, 3, 4, 5]
print(["偶" if n % 2 == 0 else "奇" for n in nums])
print([n if n > 2 else 0 for n in nums])
```

## 巢狀推導式

```python
# 等同於兩層 for 迴圈
pairs = [(x, y) for x in range(1, 4) for y in "ab"]
print(pairs)

# 把二維串列攤平
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [n for row in matrix for n in row]
print(flat)

# 轉置矩陣（列變行）
transposed = [[row[i] for row in matrix] for i in range(3)]
print(transposed)
```

## 字典推導式

```python
names = ["Amy", "Bob", "Christina"]
lengths = {name: len(name) for name in names}
print(lengths)

prices = {"咖啡": 65, "紅茶": 35, "蛋糕": 90}
discounted = {k: v * 0.8 for k, v in prices.items() if v > 50}
print(discounted)

swapped = {v: k for k, v in prices.items()}   # 鍵值互換
print(swapped)
```

## 集合推導式

```python
words = ["apple", "Avocado", "banana", "Blueberry", "cherry"]
first_letters = {w[0].lower() for w in words}
print(first_letters)
```

## 產生器運算式

用小括號，不會一次建立整個串列，**省記憶體**。直接傳給 `sum`、`max` 這類函式時很好用：

```python
total = sum(x ** 2 for x in range(1_000_000))
print(total)
print(any(n > 100 for n in [5, 50, 500]))
```

## 什麼時候不要用推導式？

推導式很方便，但**太長、太複雜時就該改回 for 迴圈**。程式是寫給人看的，好讀最重要：

```python
# ❌ 太難讀
result = [x * y for x in range(5) if x % 2 for y in range(5) if y > x if (x + y) % 3]
print(result)
```
