處理文字是程式最常做的事之一：清理資料、解析檔案、分析文章… 這一課整理最常用的字串方法。

## 切割與合併

```python
csv_line = "小明,18,台北,工程師"
parts = csv_line.split(",")
print(parts)

print("a  b   c".split())          # 不給參數：用任何空白切，自動忽略多餘空白
print("2026-11-04".split("-", 1))  # 最多切 1 次

words = ["Python", "is", "fun"]
print(" ".join(words))
print("-".join(["2026", "11", "04"]))
print("\n".join(["第一行", "第二行"]))
```

> 💡 `join` 只能接**字串**的串列。數字要先轉換：`",".join(map(str, [1, 2, 3]))`

## 清理空白

```python
s = "   hello world   \n"
print(repr(s.strip()))       # 兩邊
print(repr(s.lstrip()))      # 左邊
print(repr(s.rstrip()))      # 右邊
print("***hi***".strip("*")) # 指定要去掉的字元
print("file.txt".removesuffix(".txt"), "Mr. Wang".removeprefix("Mr. "))
```

## 搜尋

```python
s = "I love Python. Python is great."
print(s.find("Python"))       # 第一次出現的位置，找不到回傳 -1
print(s.rfind("Python"))      # 從右邊找
print(s.count("Python"))
print(s.startswith("I"), s.endswith("."))
print(s.startswith(("http", "I")))   # 可以給 tuple，符合任一個就好
print("Java" in s)
```

## 替換與大小寫

```python
s = "hello world"
print(s.replace("o", "0"))
print(s.replace("o", "0", 1))   # 只換第一個
print(s.upper(), s.title(), s.capitalize())
print("PyThOn".swapcase(), "PYTHON".lower())
print("Straße".casefold() == "strasse")   # 比較時更徹底的忽略大小寫
```

## 判斷字串內容

```python
for s in ["123", "12.3", "abc", "abc123", "   ", "ABC"]:
    print(f"{s!r:10} 數字:{s.isdigit()!s:5} 字母:{s.isalpha()!s:5} 英數:{s.isalnum()!s:5} 空白:{s.isspace()!s:5} 大寫:{s.isupper()}")
```

## 對齊與填充

```python
print("42".zfill(5))
print("標題".center(20, "="))
print("左".ljust(6, ".") + "右".rjust(6, "."))
```

## 多行文字處理

```python
text = """姓名: 小明
年齡: 18
城市: 台北"""

info = {}
for line in text.splitlines():
    key, value = line.split(": ")
    info[key] = value
print(info)

# 一行搞定
info = dict(line.split(": ") for line in text.splitlines())
print(info)
```

## 字元替換表 translate

一次替換很多字元，比連續呼叫 replace 快：

```python
table = str.maketrans("，。！？", ",.!?")
print("你好，世界！真的嗎？".translate(table))

remove = str.maketrans("", "", "aeiou")   # 第三個參數：要刪除的字元
print("programming".translate(remove))
```

## 編碼：str 和 bytes

電腦裡存的其實是位元組（bytes），文字要經過**編碼**才能存檔或傳輸。現在幾乎都用 UTF-8：

```python
s = "Python 中文"
b = s.encode("utf-8")
print(b, len(s), len(b))      # 一個中文字在 UTF-8 是 3 個位元組
print(b.decode("utf-8"))
```

:::exercise 清理資料
`raw` 是從網頁抓下來的一份髒資料。寫 `clean(raw)` 回傳一個字典串列：
- 每一行格式是 `名字 | email | 年齡`，前後和中間可能有多餘空白
- 名字要變成**首字大寫**（`title()`）、email 全部**小寫**、年齡轉成**整數**
- **空白行要跳過**
@@starter
raw = """
  amy chen |  AMY@Mail.com | 25
BOB LIN|bob@MAIL.com|31

  cathy wu  | Cathy@mail.COM |  19
"""

def clean(raw):
    pass


for person in clean(raw):
    print(person)
@@check
f = ns.get("clean")
assert callable(f), "找不到函式 clean"
got = f(ns["raw"])
want = [
    {"name": "Amy Chen", "email": "amy@mail.com", "age": 25},
    {"name": "Bob Lin", "email": "bob@mail.com", "age": 31},
    {"name": "Cathy Wu", "email": "cathy@mail.com", "age": 19},
]
assert isinstance(got, list), "clean 應該回傳串列"
assert len(got) == 3, f"應該有 3 筆資料，你的有 {len(got)} 筆（空白行要跳過）"
for g, w in zip(got, want):
    assert g == w, f"資料不對：應該是 {w}，你的是 {g}"
@@hint
`for line in raw.splitlines():` 先 `if not line.strip(): continue`，再 `name, email, age = [x.strip() for x in line.split("|")]`。
@@solution
raw = """
  amy chen |  AMY@Mail.com | 25
BOB LIN|bob@MAIL.com|31

  cathy wu  | Cathy@mail.COM |  19
"""

def clean(raw):
    result = []
    for line in raw.splitlines():
        if not line.strip():
            continue
        name, email, age = [x.strip() for x in line.split("|")]
        result.append({"name": name.title(), "email": email.lower(), "age": int(age)})
    return result


for person in clean(raw):
    print(person)

:::exercise 單字統計
寫 `word_stats(text)`，回傳一個字典：
- `"words"`：總單字數
- `"unique"`：不重複的單字數（忽略大小寫）
- `"longest"`：最長的單字（如果有好幾個一樣長，取第一個出現的）

單字前後的標點符號 `.,!?` 要去掉。
@@starter
def word_stats(text):
    pass


print(word_stats("Hello world! Hello, Python. Programming is fun!"))
@@check
f = ns.get("word_stats")
assert callable(f), "找不到函式 word_stats"
got = f("Hello world! Hello, Python. Programming is fun!")
assert got == {"words": 7, "unique": 6, "longest": "Programming"}, f"結果不對：{got}"
got = f("a bb cc A")
assert got == {"words": 4, "unique": 3, "longest": "bb"}, f"word_stats('a bb cc A') 結果不對：{got}"
@@hint
`words = [w.strip(".,!?") for w in text.split()]`，不重複用 `len({w.lower() for w in words})`，最長用 `max(words, key=len)`。
@@solution
def word_stats(text):
    words = [w.strip(".,!?") for w in text.split()]
    return {
        "words": len(words),
        "unique": len({w.lower() for w in words}),
        "longest": max(words, key=len),
    }


print(word_stats("Hello world! Hello, Python. Programming is fun!"))
