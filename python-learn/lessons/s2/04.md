## 函式也是一種值

在 Python 裡，函式和數字、字串一樣，可以**存進變數、放進串列、當作引數傳遞**：

```python
def shout(text):
    return text.upper() + "!"

say = shout             # 注意沒有括號：這是函式本身，不是呼叫
print(say("hello"))

ops = [len, str.upper, shout]
for f in ops:
    print(f("python"))
```

**接收函式當參數**（或回傳函式）的函式，叫做**高階函式**：

```python
def apply_twice(f, x):
    return f(f(x))

def shout(text):
    return text.upper() + "!"

def add10(n):
    return n + 10

print(apply_twice(add10, 1))
print(apply_twice(shout, "hi"))   # shout 了兩次 → "HI!!"
```

## lambda：一行的小函式

`lambda 參數: 運算式`，自動回傳運算式的結果。適合**很短、只用一次**的函式：

```python
square = lambda x: x ** 2
add = lambda a, b: a + b
print(square(5), add(2, 3))

# 等同於
def square(x):
    return x ** 2
```

> 💡 lambda 最常見的用法是**直接當作引數**，而不是存進變數。

## sorted / max / min 的 key

`key` 參數接收一個函式，決定「依照什麼來比較」：

```python
words = ["banana", "Kiwi", "apple", "fig"]
print(sorted(words))                       # 預設：大寫字母排前面
print(sorted(words, key=str.lower))        # 不分大小寫
print(sorted(words, key=len))              # 依長度
print(max(words, key=len))                 # 最長的字
```

```python
students = [
    {"name": "小明", "score": 85, "age": 18},
    {"name": "小美", "score": 92, "age": 17},
    {"name": "阿華", "score": 85, "age": 16},
]
by_score = sorted(students, key=lambda s: s["score"], reverse=True)
for s in by_score:
    print(s["name"], s["score"])

# 先依分數（高到低），同分再依年齡（小到大）
both = sorted(students, key=lambda s: (-s["score"], s["age"]))
print([s["name"] for s in both])
```

## map 與 filter

```python
nums = [1, 2, 3, 4, 5, 6]

squares = list(map(lambda x: x ** 2, nums))         # 每個都套用函式
evens = list(filter(lambda x: x % 2 == 0, nums))    # 只留下符合條件的
print(squares, evens)

print(list(map(int, ["10", "20", "30"])))           # 一次轉換型別
print(list(map(str.strip, ["  a ", " b"])))
```

> 💡 `map` 和 `filter` 回傳的是「惰性」物件，要用 `list()` 才會真的算出來。下一課的**推導式**通常比 map / filter 更好讀。

## functools.reduce

把串列「累積」成一個值：

```python
from functools import reduce

nums = [1, 2, 3, 4, 5]
product = reduce(lambda acc, x: acc * x, nums)
print(product)    # ((((1*2)*3)*4)*5)
```

    for x in items:

    return result
